# v0.2.0-preview.5：活动会话与资料库浏览、普通文件预览

应用及安装包版本仍为0.2.0。本版继续对齐固定官方Windows Store26.1027.3384.0，未达到整软件1:1，未完成逐页用户验收。

## 相比preview.4

- 活动页按当前打开会话处理条目，补齐10项起步、每次增加10项的呈现。批量已读覆盖当前会话的完整已确认集合，归档后的条目及时退出活动集合；会话切换、旧回调与并发归档不能串扰新会话。
- 普通资料库接入真实目录和祖先路径读取，支持目录进入、面包屑和标题栏前后退。账号或身份代次改变时清理旧目录与历史；目录列表、路径和分页错误分别重试。
- 普通图片、文本、Markdown先重读文件元数据，再通过鉴权宿主读取真实字节，在右侧预览。空文件、Unicode和空白、图片解码错误、权限错误、取消与重试分别处理；关闭、切换和身份变化释放旧对象URL及监听。
- 文件内容通道按实际字节限制40MiB，保留其他现有通道限制；同源凭据刷新与外域签名URL分别处理。预览宽度按实际工作区计算和保存比例，窄窗切换全宽呈现，普通文本使用14px字号及28px行高。

## 验证与明确限制

本地61组前端回归、全量527项Rust测试、完整非Fast标准318段/32个隔离协议探针、类型检查及最终原生debug构建通过。远端安装包及发布是否完成，以本标签最终CI状态和实际资源为准，不能以本地结果替代。

浏览器与WebView2中的资料库预览交互使用明确的隔离reader夹具；最终生产EXE另测私有未登录入口、错误、重试与退出。这些不能证明真实账号文件HTTP或原生认证预览已实测。官方同环境配对像素、物理中文IME、多窗、完整资料库工作面及用户验收仍有缺口。

PDF、Office/Notebook、HTML和特殊artifact的专用工作面尚未实现。已知特殊文件暂不进入普通文本预览；官方writing_block存在受gate控制的编辑或只读回退，本版并未完整实现这些分派。Markdown自动远程图片暂只显示替代文本，受控媒体读取仍需补齐。文件保存、上传、下载、分享、版本历史及provider等完整能力不在本次新增支持范围。

PDF的独立引擎及许可方案已取证，未新增依赖或复制官方混合业务chunk，也未解除sandbox。发布成功不改变上述验收边界，preview.4及更早版本记录的其他页面限制继续适用。
