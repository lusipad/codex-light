# v0.2.0-preview.9：Sites URL与已有域名操作

应用和安装包版本仍为0.2.0，对齐固定官方Windows Store26.1027.3384.0。本版为阶段预览，未达到全软件1:1或逐页用户验收。仅本标签CI成功并核对实际资源后，才表示候选已发布。

## 相比preview.8

- Sites托管URL更改使用独立入口条件、400ms可用性查询和真实保存后读回；pending会继续确认，离页返回保留待确认状态，未知结果先读取，不自动重复提交。
- 已有自定义域名回到官方常规设置顺序，显示pending/failed状态、刷新及移除确认。刷新和删除均读取实际结果；未知结果需显式恢复，服务拒绝保留域名，active变更另更新站点信息与截图授权。
- 修复晚到读取复活已移除域名、写失败后丢失较新父数据、离页旧错误，以及恢复按钮默认动作造成重复提交。忙碌时阻止冲突操作和关闭确认框。
- 修复模型偏好协议探针对异步settings应用的确认，保留真实readback断言；修复附注发布标签与checkout临时轻量标签冲突的复核方式，不移动或覆盖既有发布标签。

## 范围与验证限制

添加域名接口已接入严格宿主/客户端，但添加与DNS设置弹窗尚未接入；公共/私有后缀解析的新依赖尚待明确决定，未安装。本版不含完整DNS设置、Work创建/编辑/发布、共享管理、转让、整站删除及数据库等详情子页。

本地的全库Rust、前端回归、完整非Fast协议检查、原生构建和浏览器证据各自记录，CI最终结果另核。正常交互夹具使用明确隔离bridge、禁止外网，不冒充真实账号HTTP；生产EXE未登录路径不能证明正常域名弹窗原生行为。

官方配对像素、真实账号HTTP与DNS、物理中文IME、多窗口及用户验收尚未完成。无像素评分或1px一致声明；默认取消聚焦及写后GET属于本项目适配。其他页面的既有未完范围保留。

## 下载

Windows x64便携ZIP、MSI、安装EXE和SHA256SUMS以本标签实际资源为准。需要可用Codex CLI/app-server及相应账号权限。发布成功不代表上述未验项通过。
