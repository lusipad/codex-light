# v0.2.0-preview.10：Sites 参与者与邀请流程

应用及安装包版本仍为0.2.0，参考固定官方Windows Store26.1027.3384.0。本版为阶段预览；仅本标签CI成功、实际发布资源及校验和核对后才算发布完成，不表示全软件1:1或用户验收。

## 相比preview.9

- Sites共享管理加入已有成员角色升降、成员/外部邮箱/群组移除及独立确认。所有者、编辑者和邀请者使用各自真实条件；群组不提供编辑者升级。
- 接入成员与群组搜索、完整团队分页建议及允许时的外部邮箱邀请。按固定来源验证账号、计划、独立开关与权限；团队不是群组查询别名。邮箱采用恢复的实际默认解析规则，未新增依赖。
- 候选按团队、群组、用户显示，保留独立加载/错误、150ms搜索防抖、取消、重试和身份隔离。选择候选后即时邀请查看者，界面须读回实际访问权限才确认。
- 修复过期移除确认、邮箱规范化/邀请接受后的误判、关闭重开丢未知锁造成重复邀请，以及重试按钮Escape误关父框。pending与未知结果只读恢复，不自动重复提交。
- 邀请弹层按来源对齐输入宽度与宽窄窗口；修复设置页通用样式污染。保留无动作群组的当前角色菜单，菜单可见不等于拥有写权限。

## 验证与限制

本地和CI的实际结果分别登记于 `docs/antigravity/acceptance/21J-sites-sharing-members.md`、`21K-sites-sharing-invitations.md`。候选版本只有在远端CI完成后才发布；不把本地绿灯冒充远端结果。

正常交互使用明确隔离bridge且禁止外网，不表示已发送真实账号邀请或核实邮件/限流。额外GET确认、用户/团队只读重试、Tauri dialog与本地碰撞布局是已说明适配；头像仍为首字/图标回退。

官方同环境配对像素、真实服务HTTP、正常共享原生弹层、物理IME、多窗口及用户验收尚未完成。Work创建/编辑/发布、profile/首次发布/转让、整站删除、数据库和完整添加域名/DNS仍保留在队列；相关解析依赖未获明确答复，未安装。本版不宣称完整Sites或全软件1:1。

## 下载

Windows x64便携ZIP、MSI、安装EXE和SHA256SUMS以此标签实际发布资源为准。需要可用Codex CLI/app-server及对应账号能力；发布成功不改变上述限制。
