## 验证与限制

本地回归、完整非Fast标准、协议探针、当前原生构建、浏览器和隔离原生检查分别记录；CI负责本标签的累计前端、全库Rust、通知适配器、Windows原生构建和资源上传。发布以最终作业及实际下载校验为准，不能只看本地构建。

正常组件夹具使用明确离线bridge并禁止外网，生产EXE未登录路径另行验证；这不证明真实账号HTTP写入已经通过。机密明文不能通过读取证明，仅核对服务确认、键及机密标志。官方同环境配对像素、物理中文IME、多窗口和用户验收仍未完成。

Sites完整Work创建/编辑/发布、URL/域名修改、共享、转让、整站永久删除及分析/数据库/插件/日程子页仍有缺口；其他页面与preview.7已有未完范围继续保留，不将本版当整页验收通过。
