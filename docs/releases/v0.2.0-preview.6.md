# v0.2.0-preview.6：资料库搜索、浏览布局与自动分页

应用及安装包版本仍为0.2.0，继续对齐固定官方Windows Store26.1027.3384.0。本版是阶段预览，未达到全软件1:1，也未完成逐页用户验收。

## 相比preview.5

- 普通资料库支持根/目录真实搜索、取消与分页、目录/历史返回和预览返回，保留原始输入与规范查询。
- 默认推荐、文件夹、图像、全部按实际读取合同请求；提供五类文件/来源筛选、网格/列表、三态排序与账号/用户隔离显示偏好。图像根强制网格，不覆盖已保存列表偏好；未知日期/大小不伪造数据。
- 标题恢复动态测量的滚动/折叠，按真实gate区分新旧布局和导航归属；普通页面通过底部哨兵自动续页，移除错误套用的常驻“加载更多”。分页失败保留旧内容、暂停自动派发并允许显式重试，身份变化阻止晚到结果串入。
- 修复隐藏筛选条件、错误创建空态、同节点更新后显示旧图、父ref提交时序及遗留顶部padding造成的吸顶状态偏移。复用已有真实读取、预览、取消和宿主身份边界，没有新增依赖。

## 验证与限制

本地66组前端回归、完整非Fast标准323段/32隔离协议探针、当前原生debug构建均退出0；647产品输入构建前后稳定。真实组件宽窄、限定原生WebView以及当前生产EXE私有未登录入口/重试/退出有证据。远端全库Rust、安装包和发布以本标签最终CI结果为准。

浏览器和原生组件使用明确的隔离reader，生产EXE另验私有未登录入口；真实账号搜索/文件HTTP、官方同环境像素、物理IME、多窗和用户验收仍缺。新旧布局均由真实快照决定，不强开当前账号能力。

非1x窗口zoom、标题栏inset、旧panel底部token、精确日期/图标/缩略图仍需校准；旧root工具条裁切只与官方静态规则对照，未取得官方GUI配对。收藏、外部provider/Pages、选择/写操作、完整URL路由、PDF/Office/HTML及特殊artifact预览矩阵未完整实现。preview.5及更早版本的其他页面限制继续适用。

图像页19E本版只有开发前研究和旧实现红例，尚未恢复正常主界面、真实生成或编辑链，不在本版新增支持范围。

## 下载

Windows x64便携ZIP、MSI、安装EXE及SHA256SUMS以本标签CI最终实际资源为准。需要可用Codex CLI/app-server及相应账号、工作区和权限。发布成功不表示上述未验项已通过。
