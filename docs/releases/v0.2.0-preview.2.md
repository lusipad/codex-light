# v0.2.0-preview.2：项目排序与归档来源预览

应用及安装包版本为0.2.0。本版继续按固定官方 Store 26.1027.3384.0取证，仍处于逐页对齐阶段，未达到整软件1:1或用户验收完成。

## 相比preview.1

- 项目中心：名称和更新时间排序、时间单位统一，排序只影响展示，不改项目持久顺序。
- 设置中的已归档聊天：本地聊天按项目分组、筛选和排序，保留真实恢复与删除；与全局归档侧栏分别处理。
- 新增云端任务和ChatGPT会话归档读取，各自分页、错误及重试；同ID不同来源独立。账号、连接或读取范围变化清理旧数据，未登录、无权限和读取失败分别呈现。
- 云端取消归档分别使用任务恢复和会话恢复接口；逐行等待和重复点击保护。发送后结果不确定时先重新读取，不将错误当成功，也不自动重复写入。

## 下载

Windows x64安装程序、MSI和含EXE及许可文件的便携ZIP来自同一次通过检查的CI构建，`SHA256SUMS.txt`提供校验值。仍需要可用的Codex CLI/app-server与相应账号、工作区及服务权限。

## 仍未完成或验证

云端永久删除、内部ChatGPT会话工作面与恢复后的“查看”、历史计划任务映射、远端主机归档及官方Fuse搜索尚未完成。当前按已读取的来源及页展示，不代表账号全部归档数量。

真实登录账号的归档HTTP与恢复持久化、组织gate/settings实测、官方同环境配对像素、物理IME、多窗和逐页用户验收仍未完成。隔离fixture及回放不代表真实账号操作；原生未登录验证不证明已登录写链已实测。

preview.1已有的其他页面差异仍适用，包括完整终端/编辑器工作面、复合执行呈现、通知缓存和toast、Activity及Images/Sites/Cloud等页面。发布成功不改变这些验收缺口。

详细范围见`docs/antigravity/acceptance/04E-project-sort.md`、`15E-settings-archive.md`、`15F-cloud-archive-read.md`、`15G-conversations-read.md`及`15H-cloud-unarchive.md`。构建与发布终态以对应GitHub Release和CI为准。
