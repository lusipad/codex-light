## 验证与限制

本轮增加真实客户端/组件回放、宿主边界回归、宽窄浏览器、限定原生组件及生产EXE隔离验证。CI负责当前标签的前端、全库Rust、通知适配器、原生构建、安装包和资源上传；以最终作业与实际下载资源核验为准，不能只看本地构建。

真实账号HTTP、官方同环境配对像素、物理中文IME、多窗口与用户验收仍未完成。浏览器和正常原生组件使用明确离线bridge；生产EXE未登录路径另行验证，不将夹具当真实服务成功。

图像完整生成/编辑/原图与下载、GPT工作空间目录/管理/迁移/真实会话、完整席位和不可用路由、菜单及官方缓存/懒加载细节尚有缺口。其他页面和preview.6已有未完范围继续保留，不把本版当整页验收通过。
