# v0.2.0-preview.13 云环境配置

应用版本为 0.2.0。参照的官方 Windows Codex App 版本为 26.1027.3384.0。

## 相比 preview.12

- 云环境草稿可调整互联网访问、包管理器域名和额外允许的域名。域名弹窗支持批量粘贴与校验，外层保存后才写入草稿。
- 环境名称、描述和共享范围可在侧栏编辑。有草稿和元数据两类变更时先保存草稿，再保存环境元数据。共享范围变更确认后即生效。
- 写入结果不明时先核对服务端状态。草稿已保存而元数据未确认时，显式重试只补交元数据。

## 验证范围

覆盖隔离浏览器、前端回归和 Rust 请求与读回测试。Windows 安装包由对应标签的 GitHub Actions 生成。

真实云端账号写入、原生界面操作和官方像素对照待验证。环境发布、仓库应用消息和敏感值编辑仍在开发。

## 下载

本页提供 Windows x64 便携 ZIP、MSI、安装 EXE 和 SHA-256 清单。需要可用的 Codex CLI 和对应账号能力。
