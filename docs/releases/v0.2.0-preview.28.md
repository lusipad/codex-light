# v0.2.0-preview.28 Windows 本地工作台

- 项目由 Codex Native 更名为 Codex Light，Windows 安装包和便携包使用新名称。
- 本地工作台支持项目会话与工作树、文件编辑和保存、Git 差异及暂存、终端命令，并在外部修改文件时保留冲突提示。
- 设置调整了导航、常规控件与外观预览。本地归档、钩子偏好和本地 MCP 连接已有原生操作与部分重启读回记录。

## 从旧版迁移

MSI 沿用原升级标识，应用继续使用原数据标识。旧版 NSIS（-setup.exe）用户请先退出并卸载 Codex Native，保持「删除应用数据」未勾选，再安装 Codex Light。原位安装迁移尚未实测。

这是 Windows 预览版。官方同条件像素对照、物理输入法和部分真实账号功能仍待验证，不代表全部功能或页面已验收。
