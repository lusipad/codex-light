应用及安装包版本仍为0.2.0。本版按固定官方Windows Store 26.1027.3384.0取证，属于逐页对齐预览，未达到整软件1:1或逐页用户验收完成。

## 相比preview.2

- 云端归档删除：任务和ChatGPT会话使用各自接口及确认状态；同ID不同来源隔离。任务失败提供真实重试，会话失败保留确认；结果不确定时先重新读取，不自动重发删除。
- 已安装技能目录：点击卡片进入独立Markdown预览，保留加载、失败和空内容状态；复制保留原始SKILL.md，包括frontmatter。
- 技能启禁按实际命名空间选择名称或路径；打开文件复用工作台真实读取和未保存修改保护，成功后交接焦点。
- “立即试用”按官方静态规则构造技能引用，只填入真实聊天草稿，不自动发送；已有草稿保留。

## 下载与限制

Windows x64便携ZIP、MSI、安装EXE及SHA256SUMS以对应CI最终发布产物为准。仍需要可用Codex CLI/app-server及对应账号、工作区和权限。

技能试用进入主聊天草稿。同版本官方宿主虽接收`startInSidebar`参数，但该本地调用路径未消费它，实际准备首页导航；不能以参数名推定侧栏呈现。官方按nonce区分Composer作用域并替换目标文本，当前保留已有草稿并追加，草稿作用域仍未对齐。本地模版编辑器作为兼容入口保留。项目技能卸载、远程技能读取和完整Markdown呈现仍有差异，不能把当前用户目录卸载扩称任意技能删除。

真实账号云端删除与持久化、官方同环境配对像素、物理中文IME、多窗、已登录原生写链和用户验收尚未完成。隔离回放不代表真实服务已实测。preview.2记载的其他工作面及页面缺口继续适用。

范围与证据见`docs/antigravity/acceptance/15I-cloud-delete.md`及`13E-skill-preview.md`。发布成功不改变页面验收状态。
