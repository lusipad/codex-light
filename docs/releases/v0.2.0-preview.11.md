# v0.2.0-preview.11：云端会话宿主与环境编辑前置

应用及安装包版本仍为 0.2.0，参考固定官方 Windows Store 26.1027.3384.0。本版为阶段预览，须对应提交及标签 CI 成功，并核对实际资源后才算发布完成。

## 相比 preview.10

- Sites 邀请收到服务端待处理回执后立即显示所选对象，按真实身份去重；重开后读取实际权限，保留未知结果的只读恢复。
- 云环境菜单按官方权限隐藏不可编辑用户的编辑入口，保留真实配置查看与焦点返回。
- 原生环境草稿创建使用固定路径、宿主凭证、600 秒传输和前后网络策略检查，未知结果阻止重复创建，同账号的已派发记录跨身份代次保留。
- 新增 Windows 云端持久会话宿主及固定模型读取原语，具备单次初始化、请求关联、身份退役、迟到通知保护和最终退出清理。无新增依赖。

## 验证与限制

云端阶段本地通过 650 项全库 Rust、93 项前端回放、完整标准检查 349 步及其中 32 个隔离协议探针。测试辅助接口收窄后复验 22 项宿主专项及原生构建。远端结果以此标签的实际 CI 为准。

Windows 联合用例使用自启回环服务，覆盖初始化能力、attestation 不可用回执、并发模型读取、乱序响应、UTF-8、大帧和关闭；未使用真实云端凭证或触发模型任务。真实服务、代理、官方心跳、自动重连及热连接应用退出尚待验证。

草稿恢复、聊天主链宿主分派、审批与工具交互、设置侧栏、保存和发布仍在开发，因此未开放未闭环的环境编辑入口。当前成果不能视为完整云端环境页面，也不代表官方配对像素或用户验收。

本地未知草稿记录尚不跨应用重启恢复。WinHTTP 保活与固定官方约 10 秒 ping 的差异已登记。此前页面的真实账号、原生交互与视觉差异继续按各阶段记录推进。

## 下载

Windows x64 便携 ZIP、MSI、安装 EXE 和 SHA256SUMS 以本标签实际发布资源为准。需要可用 Codex CLI/app-server 及对应账号能力。
