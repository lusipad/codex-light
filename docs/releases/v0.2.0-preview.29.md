# v0.2.0-preview.29 Windows 便携程序

- 下载 `Codex-Light_0.2.0_x64-portable.exe` 可直接启动，无需安装；第三方许可证见同版本的 `Codex-Light_0.2.0_licenses.zip`。
- 也可以下载便携 ZIP，解压后运行根目录中的 `Codex-Light.exe`；ZIP 包含主题许可证。
- `-setup.exe` 和 MSI 是安装版本。GitHub 自动提供的 Source code 压缩包只包含源码。

需要 Windows x64 和 Microsoft Edge WebView2 Runtime；使用 Codex 会话还需要已配置的 Codex CLI。应用仍是预览版，官方配对像素、物理输入法和部分真实账号功能尚未完整验收。
