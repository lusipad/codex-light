# v0.2.0-preview.12 云端环境草稿编辑

应用版本为 0.2.0。参照的官方 Windows Codex App 版本为 26.1027.3384.0。

## 相比 preview.11

- 有权限时可从独立云环境列表或设置进入编辑。应用沿用服务端回执中的会话 ID 恢复会话，显示文本历史和私有配置侧栏，并支持加载更早的轮次。
- 侧栏支持编辑安装脚本和启动技能。保存携带草稿版本和实际变更的字段，并在读回确认后更新界面。
- 保存结果不明时保留输入，先核对服务端草稿。确认版本未变化后，可手动重试。

## 验证范围

本地全库 Rust 656 项通过。隔离浏览器验证了恢复重试、历史分页、脚本保存、只读核对和手动重试。Windows 安装包由此标签的 GitHub Actions 生成。

聊天发送、环境发布和全局导航草稿保留仍在开发。真实云端账号写入、原生界面和官方像素对照待验证。

## 下载

本页提供 Windows x64 便携 ZIP、MSI、安装 EXE 和 SHA-256 清单。需要可用的 Codex CLI 和对应账号能力。
