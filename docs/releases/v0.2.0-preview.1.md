# v0.2.0-preview.1：官方界面对齐阶段预览

应用与安装包版本为 0.2.0，本标签是预览版。它不是官方 OpenAI Codex App，也没有达到整软件 1:1 或逐页用户验收完成。

## 本阶段改进

- 设置：外观颜色/主题编辑、真实 Windows 字体及字形、常规本地通知；独立 ChatGPT 账户通知使用个人资格校验、服务端渠道和单渠道保存/读回，并修复失效监听、断线与重试恢复。
- 文件与变更：当前项目多根、惰性递归目录、展开/搜索/失败重试和文件选择；保留脏稿、冲突及真实 Git 操作。
- 会话执行：读取/搜索/列文件使用专用摘要行，读取文件可打开，原始命令、输出与退出码仍可展开；未知、拒绝和中断保留真实状态。
- 交互终端：紧凑标签与操作菜单、键盘与焦点、字体/颜色随外观更新、回放时区分用户输入和终端自动应答，保留真实 PTY。
- 发布：前端生产回放加入 CI，保留完整 Rust、原生 SDK 和安装包构建；必需资产缺失即失败，附 SHA-256 清单与含主题许可的便携压缩包。

## 下载与使用

Windows x64：安装程序为 `Codex-Native_0.2.0_x64-setup.exe` 或 MSI。推荐便携包 `Codex-Native_0.2.0_windows-x64.zip`，其中包含 EXE 与许可目录。运行仍需要可用的 Codex CLI/app-server；真实功能依赖相应账号、工作区权限和服务能力。

`SHA256SUMS.txt` 对应同一次 CI 构建的三个下载文件（MSI、安装程序、便携 ZIP）。可用 PowerShell `Get-FileHash -Algorithm SHA256 <文件>` 核验；云端构建与本地构建的哈希不要求相同。单独 EXE 随 ZIP 及许可目录提供。
