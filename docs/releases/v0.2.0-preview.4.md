# v0.2.0-preview.4：推荐技能预览与草稿行为对齐

应用与安装包版本仍为0.2.0。本版继续按官方Windows Store26.1027.3384.0逐页对齐，未达到整软件1:1或逐页用户验收完成。

## 相比preview.3

- 推荐技能可先打开只读Markdown预览，再安装；保留真实加载、失败重试和空内容状态，页尾使用推荐专用安装动作。
- 安装成功、技能发现与父列表读回分别呈现。复制已成功而发现未确认时保留告警并阻止重复安装；真实元数据到达后换成已安装卡片，避免主列表重复展示。
- 推荐卡片与预览使用官方默认安装范围，本页不再额外展示项目/用户范围选择；底层项目安装能力保留。
- “立即试用”按已证普通首页行为替换目标首页草稿，其他会话草稿不变；确认期间账号、项目、连接或草稿发生变化后，旧请求不再覆盖新输入。仅填草稿，不自动发送模型。
- 项目新聊天等待选择结果期间，新增的未保存保护仍有效；确认不重复项目选择请求。

## 下载与验收范围

Windows x64便携ZIP、MSI、安装EXE及SHA256SUMS以本标签最终CI资源为准。仍需要可用Codex CLI/app-server及对应账号、工作区和权限。

本地隔离来源验证与受控回放不代表真实网络推荐仓库或账号功能全部实测。官方同环境配对像素、物理中文IME、多窗、完整目录图标/元数据和用户验收仍有缺口；preview.3记载的其他页面限制继续适用。发布成功不改变页面验收状态。

具体范围见`docs/antigravity/acceptance/13F-skill-trial-drafts.md`与`13G-recommended-preview.md`。
