# 全部页面、动作与呈现效果的执行队列

本文件是**逐页采证和展开规格的任务清单**，不是所有官方能力均已确认存在。控件、默认值、协议、菜单位置、动作结果必须针对固定版本/模式/账号取证后才能写入实施合同；候选能力不可凭本表添加到 UI。

各页进入开发前，必须达到 [首页规格](HOME-SPEC.md) 同等粒度：完整控件树、逐控件视觉参数、全部动作合同、状态图、宽窄窗锚点和实际验收步骤。不能以本文件的一段概述代替该页规格。

每页 `Pxx-Ann` 为动作 ID，`Pxx-Snn` 为画面/状态 ID，`Pxx-Vnn` 为视觉锚点。以下动作族至少分别拆一个 ID；官方还有其他可见入口时继续补齐。每页同时执行通用 N01–N12 的适用分支。

## 00 基准与现有改动纠偏

- 输入/操作：保存 dirty 工作树和未跟踪文件→核实官方包/截图→分类旧测试→核对完成声明→生成差异清单。
- 呈现结果：只交付证据包、已知/未知矩阵和首页纠偏范围，不改产品。
- 验收：参考可溯源，同条件可复现，未把路由/CSS存在作为行为/像素结果。用户确认 01A 取证基准后放行。

## 01 公共外壳、首页与 Composer

执行 [HOME-SPEC.md](HOME-SPEC.md) 的 01A–01F，逐控件/动作验收。候选代码：AppTitleBar、CodexSidebar、ComposerBox、ModelSelector、App/styles/shortcuts。

## 02 会话基础：建议拆 02A 顶栏、02B 消息、02C 长内容、02D 操作与恢复

- **界面采证**：顶栏标题/状态/分支/来源；用户/助手气泡的宽度、边距、字体、头像/图标；代码块、表格、列表、链接、图片、数学及不支持内容的真实呈现；复制/收藏等行内动作的出现条件；跳转导航与滚动按钮。
- **动作族**：新建并发送；流式追加；滚动离开底部/返回；复制提问/回答/代码/全会话；查找、上下命中、Escape；编辑/重新生成/分叉/回滚（仅官方存在且授权）；切会话、返回和重启恢复。
- **关键呈现**：流式时光标/占位/按钮；代码自动换行与横向滚动；表格宽度；长用户消息折叠；生成失败/中断/重试；首屏历史加载，不出现重复段或“闪空”。
- **验收序列**：等价样本发送→逐段观察→滚动离底→新段不抢滚动→复制独立读取剪贴板→查找命中内容→切 A/B/A→重启读历史；失败/取消后不出现成功回答。实际期望由官方同序列采证确定。
- **来源与范围**：App、MarkdownView、ThreadFindBar、threadText/threadTimeline、clipboard；纯渲染回放与真实模型任务分别出证据，图片/数学能力不可假定已完整支持。

## 03 执行与交互：按子范围分别交付

| 子范围 | 界面与动作合同 | 必须证明的结果 |
|---|---|---|
| 03A 思考摘要 | 展开/收起、段落/标题/Markdown、进行中与完成文案、摘要/raw支持边界 | 按索引合并、最终快照不重叠，重载/重复通知正确；不得自行生成思考内容 |
| 03B 命令卡 | 行/分组/图标、命令截断、cwd、输出折叠/滚动/复制、状态/耗时 | 真实命令输出、退出码/拒绝/失败/中断对应；空最终输出不残留旧缓冲 |
| 03C 文件变更卡 | 文件数/路径、类型、增删数、打开diff/文件、折叠、补丁变化 | 实际文件/补丁与显示一致；批次变化、删除/重命名、失败无假变更 |
| 03D MCP/动态/协作工具 | server/tool标题、参数/结果、图像/链接、进度、错误、子线程跳转 | 请求身份和状态对应，进度不等于完成，失败可见；真实工具与固定样本区分 |
| 03E Plan/Goal | 计划条目与状态、目标栏/弹窗、创建/编辑/暂停/恢复/清除 | 保存读回、事件更新和状态机一致；不拿本地计时器模拟自主执行 |
| 03F 队列/Steer | 队列行/顺序/编辑/移除/立即发送、默认行为和反向按键、投递未知 | 真实 ID/完整 input，成功清理/失败保留、无重复投递，默认设置和各入口一致 |
| 03G 中断 | 停止按钮、按键作用域、请求中/已停止/失败的呈现 | 发请求与最终中断分开；未到通知不假结束；新轮次不被旧响应污染 |
| 03H 审批/多问题 | 卡片层级、选项、输入、禁用、说明、焦点、提交/拒绝/取消 | 仅当前会话，generation/typed ID正确，IME不误提交、未知投递防重，真实执行结果独立核实 |
| 03I 附件 | 选择/拖入/粘贴、chip、预览、进度/错误、移除、纯附件发送 | 保存/列表/读取/移除往返；失败保留草稿和引用；发送/排队/Steer完整输入 |

每个子范围需正常/加载/空/失败/拒绝/取消/不可用/晚到等适用状态；已存在代码和前轮回归必须重新核对当前源码，不能当成自动通过。

## 04 会话组织与项目

- **界面**：项目中心卡片/列表、侧栏分区、置顶/最近、层级缩进、未读点、长名称、省略/tooltip、右键菜单、归档/恢复确认。
- **动作族**：选目录/创建或加入项目；展开/折叠；新会话归属；重命名；置顶；分区创建/改名/移动/排序；拖拽排序；搜索；归档/恢复；目录失效处理。
- **呈现**：拖拽落点/占位、选中/未读变化、排序即时反馈、错误后恢复原顺序、空/长列表。
- **验收**：隔离项目→组织会话→修改/移动→重新读取来源数据→离开重开/重启→归档再恢复。证明排序不增删条目、重名/失效/保存失败按官方处理。
- **代码线索**：ProjectsIndexView、CodexSidebar、App、项目/分区真实数据路径。

## 05 文件工作面

- **界面**：文件树/面包屑、文件图标、缩进、选中、展开箭头；预览/编辑区、标签、脏标记、图片/二进制/大文件状态；搜索与错误恢复入口。
- **动作族**：展开目录、选文件、切文件、编辑、选区/Tab、保存/Ctrl+S、关闭；搜索；外部修改；切目录/重开；目录丢失返回；官方若有新建/删除/重命名则另采证并补合同。
- **呈现**：加载、无法读取/编码、保存中/失败、脏草稿保护、图片缩放、长行滚动/换行、目录无内容和目录不存在区分。
- **验收**：隔离文件编辑→Ctrl+S→独立读磁盘字节→重开/重启；保存拒绝保留草稿；外改无草稿自动刷新/有草稿不覆盖；挂起 A 读取切 B 后不串；关闭后监听按规定释放。
- **代码线索**：DiffDrawer、FileExplorer.css、fsClient、真实 fs 接口。Tab 插入几空格必须来自官方观察，不沿用当前实现假设。

## 06 变更与 Git 工作面

- **界面**：来源选择、文件列表/状态、diff行号/色块/折叠、左右或统一布局、长行、空/二进制/重命名/冲突；评论、工具栏、分支/提交弹层。
- **动作族**：选择diff来源/文件、切布局/换行、展开上下文、评论定位；暂存/取消暂存、撤销、创建/切分支、提交、PR入口（仅实际支持范围）。
- **呈现**：选中行、hover动作、loading/error、确认撤销、提交成功/失败、文件状态变化；不可用动作按官方禁用或隐藏。
- **验收**：隔离 Git 仓库准备增删改/冲突/二进制→操作→git status/diff/提交对象独立读取→回页刷新。取消不得改文件；失败保留提交信息；撤销/推送等须明确授权边界。
- **代码线索**：DiffDrawer、TurnDiffPanel、git.rs；禁止使用真实项目测试撤销。

## 07 终端与面板布局

- **界面**：终端标签、字体/行距/光标、ANSI色、滚动条、右/底布局、分隔条、最大/最小尺寸、焦点状态、进程状态。
- **动作族**：开/关、新标签/切标签、输入命令、Ctrl+C、选择/复制/粘贴、清屏；拖动/键盘调整分隔；窗口缩放；关闭/重开与退出。
- **验收**：隔离目录运行无破坏命令→实际PTY输入输出→长输出滚动→调整尺寸验证PTY列行→中断→关闭检查进程/监听；终端快捷键不触发全局聊天动作，中文输入不乱码。
- **代码线索**：TerminalDock、terminal.rs、面板宿主布局。仅 CSS 有 resize 定义不证明拖动可用。

## 08 搜索与命令面板

- **界面**：遮罩/弹层、输入、分组/图标/描述/快捷键、加载/空态/错误、选中行、命中高亮与预览。
- **动作族**：鼠标/快捷键打开；输入/清除；方向键/Home/End/Enter/Escape；选择文件/会话/命令；切过滤；外点击关闭；快速连续搜索。
- **验收**：已知样本搜索→核对真实命中及排序→键盘选择跳正确目标→焦点返回；旧查询晚到不得覆盖新查询；禁用/不可用命令不假执行。
- **代码线索**：QuickSearchModal、slashCommands、真实文件/会话搜索路径；搜索排序预期需官方对照，不能照当前算法写测试。

## 09 Activity / Inbox

- **界面**：未读标记、列表/分组/时间、运行中/待审批/完成/失败、过滤、空态、详情入口。
- **动作族**：产生真实事件→列表更新；切过滤；选择通知→会话/卡片定位；读/未读；批量操作若官方存在则采证。
- **验收**：A/B两任务交错事件→去重/排序→正确跳转→标记读回→重启；后台完成、拒绝/失败不能统一叫“回复已完成”。
- **代码线索**：InboxView、App通知和存储；本地计时器造通知不计成功。

## 10 Scheduled / Automations

- **界面**：任务列表、模板/新建/编辑、时间与时区、状态、历史/错误、暂停/恢复/删除确认。
- **动作族**：创建、修改、预览下一运行、立即运行（若官方有）、暂停/恢复、历史详情、删除/取消。
- **验收**：隔离测试任务保存→调度读回→按指定时区实际触发→历史与通知对应→暂停后不再触发→恢复→重启；睡眠/错过触发/DST/重叠处理以官方策略为准。实际模型运行需要范围授权。
- **代码线索**：AutomationsView、automations.rs；保存RRULE/cron文字不等于调度真实执行。

## 11 Worktrees

- **界面**：列表、项目/分支/路径、创建/恢复进度、失败、关联会话、清理确认、空态。
- **动作族**：选项目/起点→创建→进度→打开；关联/交接；归档/恢复/清理；目录失效与冲突恢复。
- **验收**：隔离 Git 仓库核对分支/路径/HEAD与文件；操作中离开/重启不重复创建；失败无假条目；清理范围和可恢复内容对应。不可逆清理需确认授权。
- **代码线索**：WorktreesView、Git/本机工作树适配；不能把任意目录当工作树成功。

## 12 Plugins

- **界面**：目录/已安装、搜索/筛选、卡片/详情、图标、来源、能力/权限、安装进度、错误/限制、配置入口。
- **动作族**：加载/分页/搜索→详情→安装/取消→配置/连接→更新/卸载（范围许可时）。
- **验收**：真实可用目录与契约；安装后独立读安装状态/可用能力；拒绝/失败不显示已安装，卸载取消不改变；认证权限边界可解释。
- **代码线索**：SkillsMcpView、PluginsMarket.css、协议/插件服务。当前官方文档可能注明某些插件方法仍在开发，必须按固定版本兼容性核查，不能凭方法名自行生产接入。

## 13 Skills

- **界面**：来源/分类/列表、搜索、详情、路径、启停、编辑/安装入口、错误。
- **动作族**：真实扫描→搜索→详情→开文件；启停→读回；创建/安装/编辑（官方支持时）→重新扫描；损坏文件恢复。
- **验收**：隔离技能目录，核对真实文件和有效配置；禁用作用域与会话生效时机一致；写失败保留内容；用户原技能不被覆写。
- **代码线索**：SkillsMcpView、skills协议/配置；UI开关变化不等于真实启停。

## 14 Code Review

- **界面**：目标选择、未提交/分支/提交/PR等官方实际选项、进行中、结果分级、位置/上下文、空结果/失败。
- **动作族**：选真实目标→启动→取消/完成→定位文件行→查看详情/处理入口。
- **验收**：隔离有已知差异的仓库，实际请求目标正确；响应结果与渲染位置对应；空/失败/中断不能假造发现；长列表与失效行号有真实处理。
- **代码线索**：CodeReviewView、review/start路径。不得硬编码示例问题充当审查结果。

## 15 Archive

- **界面**：列表、搜索、日期/项目/标题、选择、恢复、永久删除确认及错误。
- **动作族**：真实会话归档→搜索→打开/恢复→重新出现；永久删除/取消（需授权）。
- **验收**：真实列表/状态读回，恢复后内容/归属/未读保持；取消删除无变化，失败条目不消失；重启保留。永久删除测试只用明确可删除测试会话。
- **代码线索**：ArchiveView、会话协议；与设置里的 archived-chats 使用同一语义。

## 16 设置中心：每个分区独立规格、独立验收

先采集官方设置导航和每个分区实际控件，当前项目的 26 个 slug 仅是候选映射。官方不存在或名称不同的项目先登记对应关系，不新增一个“合理的设置”充数。

每个设置项都必须填写：控件ID/官方中文/控件类型/单位/默认值/可选值/当前值来源/写入键与scope/保存时机/生效时机/重启要求/错误/取消/关联功能/官方证据/用例。开关、下拉、滑块、文本框分别测键鼠和禁用态。
