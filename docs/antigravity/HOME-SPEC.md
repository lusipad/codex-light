# 01 首页＋公共外壳：逐控件、逐动作执行规格

前置：[总执行计划](README.md) 的 AG-00 已完成，首页基准与 01A 范围经用户确认。本文的状态均为**待复核/待执行**，不是已有 PASS。

## 1. 先建立页面的准确图谱

把官方目标窗口分为以下区域，给每个可见节点分配稳定 ID。看不到的候选控件不自动添加，先登记模式/账号是否适用。

```text
01.WINDOW
├─ 01.TITLEBAR：历史导航、菜单、侧栏控制、窗口按钮
├─ 01.RAIL：产品入口、选中/悬停/不可用状态、资料入口
├─ 01.SIDEBAR：模式/活动/搜索、新聊天、项目、会话、滚动区
└─ 01.MAIN
   ├─ 01.HERO：Logo、欢迎语、项目链接
   └─ 01.COMPOSER
      ├─ CONTEXT：项目、执行位置、Worktree 等当前官方上下文
      ├─ ATTACHMENTS：图片/文件等已附加对象
      ├─ INPUT：空态、输入、多行、组合输入、拖入
      ├─ ACTIONS：附件、权限、模型/推理/速度、语音、发送/停止
      └─ OVERLAYS：上述触发的菜单、选择器、提示、错误、确认
```

### 1.1 每个节点必须记录的界面字段

| 字段组 | 必填内容 | 证据与检查 |
|---|---|---|
| 身份 | ID、官方可见中文、role/name、所属状态/产品模式 | 截图局部＋可访问性树；文案取语言包或运行时 |
| 几何 | 物理坐标 x/y、宽高、相邻距离、对齐点、padding、滚动容器 | 官方/实际同客户区测量；CSS px 与物理 px 分开 |
| 字体 | 实际字体/fallback、字重、字号、行高、字距、首行/多行基线 | computed style 可用时采集；截图测基线/换行 |
| 外观 | 前景/背景、透明度、边框、圆角、阴影、图标尺寸/线宽 | token 所属变体＋采样点；不只比 CSS 字符串 |
| 约束 | 固定/伸缩/最大宽、窄窗换行/隐藏、overflow、定位锚点 | 宽/窄窗及边界宽度分别采图 |
| 交互态 | normal、hover、pressed、selected、focused、disabled | 每个适用态独立图；不要用悬停色当默认色 |
| 动效 | 触发、延迟、时长、easing、位移/透明度、结束位置 | 官方录屏；未量出就待采证，不自行设计弹簧动画 |

数值必须写入测量表后再改 CSS。已有候选值如标题 28px/34px、Logo 56px、导航轨约 56px，只能作为取证线索；应确认当前变体、字体和截图实际边界，不直接全局套值。

### 1.2 首页场景数据

准备隔离的项目、短/长名称、少量/长列表、无项目状态、普通/长草稿、一个文本文件和一张无敏感信息图片。官方与本项目数据结构及长度需等价；不能拉伸图像弥补真实项目数量不同造成的差异。

官方无法安全构造某数据场景时，现有官方图仅验可对应区域；数据不等价部分列为待采证，不大面积遮罩。

## 3. 动作合同：逐项采证、实现和验收

下面定义**必须核实的动作**及检查维度，不把未经观察的行为宣称为官方事实。每行在实施前补齐官方画面/录像 ID 和准确预期；官方实际与候选预期不同，应以固定版本证据修订合同并记录原因，不能迁就当前实现。

| 动作 ID | 起点与输入 | 操作后的界面/状态检查 | 数据/副作用与验收 |
|---|---|---|---|
| A01 | 首页冷启动 | 加载→稳定；选中入口、欢迎语、Composer 均对应 | 无假模型/项目；记录加载序列，真实读取返回与空/错误分开 |
| A02 | 可拖拽标题栏拖动 | 窗口随指针移动，内部按钮不误触 | 原生操作，检查位置变化；拖拽区需平台实现，CSS 文本不足 |
| A03 | 最小化/还原/最大化 | 窗口状态、图标、圆角、内容尺寸按官方变化 | 原生窗口读回；恢复后无裁切、焦点不乱 |
| A04 | 后退/前进 | 有历史/无历史的启用状态、目标页、选中态对应 | 执行往返后草稿/会话位置按官方保留，不重复请求 |
| A05 | 侧栏按钮/对应快捷键 | 展开/收起、内容重排、tooltip/焦点对应 | 鼠标和键盘执行同动作，宽窄窗重验 |
| A06 | 导航轨入口 hover/click | hover/选中/未读态、提示和页面目标对应 | 未实现页面不能冒充成功；本批只核对入口/返回，不跨页开发 |
| A07 | 应用菜单打开/切换/关闭 | 菜单位置、选中、分隔线、禁用、Escape 对应 | 选一项可逆动作核对执行一次；菜单外点击不穿透 |
| A08 | 资料/模式入口 | 弹层锚点、当前模式、账号状态、退出方式对应 | 不自动登录/退出或改账号；敏感动作只采证，不擅自触发 |
| A09 | 新聊天按钮及快捷键 | 回到官方新建状态、项目/上下文继承、草稿语义对应 | 不把 UI 切页误计为创建真实会话；检查创建时机 |
| A10 | 项目行展开/收起 | 子会话可见性、缩进、箭头、滚动位置对应 | 重开后的持久化按官方核实；不写死样本列表 |
| A11 | 会话行 hover/选择/右键 | 行背景、截断、图标、上下文菜单与点击区域对应 | 点击目标会话正确；右键不触发错误跳转；完整操作归 04 |
| A12 | 侧栏滚动/长名称 | 固定头尾、滚动条、文本省略、tooltip 对应 | Tab/滚轮不进入错误面板；长列表不挤压 Composer |
| A13 | Hero 项目文字点击 | 是否可点击、下划线/hover、弹层目标对应 | 与 Composer 项目入口选同一上下文，无不一致选择 |
| A14 | 项目选择器鼠标选择/取消 | 当前项、列表、关闭时机、标题和上下文更新对应 | 选目录读回实际工作区；取消不改变数据；目录失效给实测错误 |
| A15 | 执行位置切换 | 本地/其他可见目标、禁用/说明、布局变化对应 | 后续请求 cwd/运行位置必须相同；无服务不模拟连接 |
| A16 | Worktree 开关 | 可用条件、选中态、确认和上下文标签对应 | 取消无创建；创建是否此时发生按官方取证；隔离仓库读回 |
| A17 | 模型菜单展开 | 锚点、当前模型、项目顺序/分组、长列表对应 | 模型来自该会话/账号实际能力，菜单展开不自行改选择 |
| A18 | 选择模型 | 标记与 Trigger 文案更新，关闭/焦点行为对应 | 最终请求模型正确；不支持的推理/速度组合正确归一，无静态档位 |
| A19 | 推理/速度选择 | 控件表现、说明、滑块或选项步长、禁用对应 | 改值后请求参数与能力一致；不把 UI 切换当服务生效 |
| A20 | 权限菜单选择/取消 | 官方描述、选中、警告、确认/取消流程对应 | 取消原权限保持；真实授权另核实范围，绝不绕过权限确认 |
| A21 | 附件菜单/系统选择器 | 菜单内容、图标、原生选择器、取消后焦点对应 | 隔离文件；取消不附加；成功显示名称/预览/实际引用 |
| A22 | 拖入/粘贴附件及移除 | 拖入提示、上传/持久化状态、chip、错误对应 | 支持类型按官方核实；失败不显示成功，移除仅作用对应附件 |
| A23 | 单行→多行→长输入 | 字体/placeholder、换行、增高上限、内部滚动对应 | 草稿内容/光标不丢，输入不触发发送；切页/返回按官方持久化 |
| A24 | 普通 Enter/Shift+Enter/发送偏好 | 发送/换行与官方设置一致，按钮可用态对应 | 实际发送次数及完整文本核对；不只检查 keydown 源码 |
| A25 | 中文候选中 Enter/空输入发送 | 选字只上屏；空态按钮/Enter 的反馈按官方 | 合成 IME 与 Windows 物理 IME 分开；服务器无多余请求 |
| A26 | 菜单方向键/Home/End/Escape | 当前焦点、滚动到可见项、选择/关闭、焦点返回对应 | 每一步采 activeElement；滑块按键不被菜单/全局抢走 |
| A27 | 菜单外点输入框/其他区域 | 弹层关闭范围、点击是否被消费、焦点去向对应 | 第二层子菜单/组合弹层检查，不出现点击穿透和双执行 |
| A28 | 连接失败时输入/重试/恢复 | 错误可见、禁用范围、草稿与附件保留对应 | 错误恢复后读真实状态；不能固定倒计时改成已连接 |
| A29 | 听写/语音开始/取消 | 权限请求、录音状态、停止、文本或错误对应 | 必须真实可用服务；权限拒绝后无假转写；未获授权不授予权限 |
| A30 | 首次点击发送 | 加载态、用户消息、页面过渡、草稿清理、失败回退对应 | 隔离测试任务；匹配 thread/turn ID；单击/双击只按官方语义投递 |

每行动作还要执行适用的重复点击、操作中离开、返回、断连和重启。未出现的官方动作按“未显示/能力受限”登记，不能由表格强制增加。

交付 CSV：`anchor_id,scene,viewport,reference_x,reference_y,actual_x,actual_y,dx,dy,reference_w,actual_w,dw,evidence,status`。只有宽高证据支持时再填对应量；未知不可写 0。

## 6. 01 页放行清单

- 控件清单覆盖：官方当前场景每个可见节点都有对应；当前新增节点有官方证据，否则登记移除/隐藏方案。
- A01–A30 所有适用动作补齐官方预期并实际通过；受限项没有冒报。
- S01–S14 所有适用状态截图/录屏齐全；静态图不能证明焦点返回或过渡动画。
- V01–V08 各状态/viewport 的关键锚点达标；未解释差异为 0 或用户明确接受为限定范围降级。
- 同源码原生 EXE 验证键鼠、Windows IME、窗口及首次真实发送/失败，服务授权缺失部分保持阻塞。
- 用户收到干净的产品界面，开发控制栏不能出现在正式交付画面；提供最短复现步骤和对照图。
- 用户明确验收本页后，才进入 02。只验收 01A 不等于整个 01 已验收。
