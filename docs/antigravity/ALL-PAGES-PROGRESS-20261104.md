# 全页面推进：2026-11-04开发计划与记录

基于用户“所有的页面都推进下”，在已提交阶段4a3047f之后执行。目标仍是官方可观察行为和界面一致；全页面推进不等于降低证据要求或本轮将所有页面标为完成。

## 本轮决策

- 页面按独立文件分组并行，每组先补当前Store原文合同，再改有明确依据的结构或行为。置信度高；若当前安装包发生变化，先登记版本差异再确定采用的基准。
- 保留真实文件、Git、调度和账号服务。不为补齐界面而填演示数据、强开gate或把禁用说明页当作功能完成。置信度高。
- UI纠偏仍优先；用户此次要求扩大现有页面覆盖，允许各页面独立进入开发，不等待其他页最终验收。新增远端写链、付费和发布不在本轮默认范围。置信度高。
- 缺少同环境官方截图的单元只报告结构与行为证据，不给像素一致评分。置信度高；官方配对图可取得时转入实际差异比较。

## 假设与偏差处理

使用已取证Store26.1027.3384.0及asar `6fbedf054a8d8cafaf5c745b40aa59176512e106e0bd6308275ae123b60fd074`，先复核来源。DPI、App缩放、账号gate仍未知。可逆且有来源的修复直接实施；缺证行为保留并登记，优先完成无依赖项。发现文档过时按当前源码纠正，不沿用旧通过结论。

本轮不新增依赖、不改官方配置、不触发真实账号HTTP/模型任务、不删除用户数据。共享App、全局样式和标准入口由主代理集成；子任务拥有各自文件，不能撤销其他修改。

## 验证与实施记录

各组在对应spec/acceptance中记录“原文→当前→动作→验证”，先跑相关回归，合并后统一类型/前端和适用原生检查。Cargo由主代理串行运行。浏览器隔离夹具须显著标注；原生与官方像素未跑即记未测。较大阶段验证后提交，检查远程后决定推送。

实施时在下方持续补充决策、偏差、意外与待审项，不等结束才追记。

### 决策

- 本轮先由六个独立工作组取证和实现，主代理处理公共集成及工作流页面，避免多人同时写App/styles。

### 偏差

- 07/09/14证实存在同名不同工作面，先完成当前版本归属合同而不盲改：交互终端可移动标签与后台输出不同；本地Activity/Priority侧栏与Pages mentions不同；私人review聊天与本地review/Changes不同。原文见`.ref/parity/all-pages-20261104/reference/07-09-14-contract.md`。
- Images正常页仍缺权限资产链，冻结19C未合入；没有为填页面套普通Library或生成假图库。

### 意外

旧UI纠偏总入口仍写10C构建中和16.18C未提交，与已推送4a3047f不符；本轮同步修正状态，保留原失败证据。

独立只读复核发现两个P2，并已先红后绿修复：技能新建清空ID时编辑器消失，改为独立新建状态保留正文；资料库合法空中间页误报整库为空，改为分页结束才显示空库。资料库订阅拒绝另补注册成功才读取、可见重试及晚到释放回归。

### 待审项

官方配对图、DPI/缩放、账号门控、原生GUI/IME和用户验收尚未闭环，不能用并行开发或构建成功代替。
