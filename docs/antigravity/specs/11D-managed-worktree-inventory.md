# 11D 设置中的托管工作树清单

参考 Windows Store `26.1103.4239.0`，使用 11C 已核验的 `851065.6d7fb580fa.js` 与中文包。定位为 UTF-16 偏移。

- `e2` 约 58,700 处把偏好与清单放到同一设置页。`e3` 约 59,750–62,900 处显示“托管的工作树”和刷新，分开处理加载、失败和空态，并从清单过滤已直接注册为工作区的工作树及其子目录。
- `eY` 和 `e0` 约 55,600–58,700 处分仓库，默认展开。分组与条目优先按关联聊天最近活动时间，路径作为同分顺序。`e$` 和 `eV` 约 48,300–54,500 处显示关联聊天、更多关联项、置顶保护和实际路径。
- 当前桌面已提供只读 `worktree_policy_inventory`，可读默认与自定义托管根，无需依赖当前 Git 项目。聊天沿用 `loadWorktreeConversations` 和已存在的聊天导航。只关联当前可确认的 cwd 数据；官方额外的 attachment owner、子代理分类与宿主扩展另行验证。

## 验收

1. 设置页展示真实库存，按仓库展开、折叠与刷新。主 checkout、外部非托管目录及已注册项目根由原库存或工作区筛选排除。
2. 核对聊天的路径边界、时间排序、实际标题与导航 ID。置顶保护提示基于已确认置顶记录。
3. 读取失败可见且可重试。部分库存可显示有效记录及警告；聊天读取失败时仍可核对库存。换连接或离开时旧结果不得回写。

本阶段交付清单与打开已有聊天。设置清单中的新聊天、删除确认和更多聊天菜单的精确呈现另验；原管理页的真实变更入口继续可用。
