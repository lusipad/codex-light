# 04A 项目页身份与异步合同

日期：2026-11-01。修改前建立。固定官方候选 26.928.21956/build12404；从 app.asar 直接提取 projects-index-page-36727c1c5eb8.js 并校验 archive integrity。参考与完整哈希在 `.ref/parity/04/runs/20261101-codex-project-identity/reference/manifest.json`。

官方静态页面区分 localProjectId/projectId，并以 `Ri(group)` 传递 `{projectId,rootPaths:kn(group)}`，不把目录当作唯一项目身份。新聊天具体运行时和完整页面样式仍待对照；本次复用本仓库已取证的侧栏实体选择/持久化合同，不凭该片段推断全部项目操作。

| ID | 场景 | 合同 |
|---|---|---|
| PI01 | 项目页在共享首目录的两个项目中新建聊天 | 传完整 Project；App 按 serverProjectId 对应的本地实体选择，保留身份和所有根目录 |
| PI02 | 未知实体映射 | 显示错误，不默默按目录进入错误项目；回退工作区入口保留原路径行为 |
| PI03 | 两次刷新逆序成功/失败 | 仅最新请求可写状态；过期结果不抹除当前项目 |
| PI04 | 卸载后列表返回 | 不写已卸载页面；监听释放 |
| PI05 | 新建表单连续提交/中文组合输入 | 只发送一次 create；组合输入 Enter 不提交；失败保留输入并允许重试 |
| PI06 | 新建进行中按 Escape | 不清空表单或制造另一次请求 |

本轮功能自验不代表官方页面布局、协议不可用回退规则、完整 CRUD 或用户验收通过。映射缺失项目的本地注册流程另需对齐，不以路径猜测弥补身份。
