# 22G 原生云端会话宿主

承接 [22F](22F-cloud-environment-editor.md) 的固定版本取证和 Windows 回环候选。本单元把传输迁入产品并建立原生会话生命周期，为 F04 的草稿恢复、模型目录和配置侧栏提供实际宿主。F01–F07 继续作为完整目标。

原生入口先提供固定 `model/list` 读取。请求只能携带请求 ID、当前身份和可选分页游标。凭证由宿主读取，固定 WSS 主机，调用前后核对应用网络策略及身份。模型目录来自当前远端会话，后续由云端 Composer 使用。

| 用例 | 预期与验证 |
|---|---|
| G01 | 并发读取同一身份时只有一次建连和初始化，初始化使用保留 ID，30 秒等待。明确服务错误或连接关闭使在途请求结束。 |
| G02 | 请求 ID 独立关联，乱序或迟到响应不交给另一请求。取消一项读取不重复发送，其他请求可完成。 |
| G03 | 远端通知携带 durable 宿主与 account/user/generation。账号失效取消旧连接，旧通知与结果不能跨身份发布。 |
| G04 | Windows WinHTTP 的固定主机、子协议、UTF-8 分帧、TLS 拒绝、重定向拒绝、取消及关闭回归进入产品测试，测试自身只启动回环服务。 |
| G05 | Windows 的 attestation 请求返回平台不可用回执，编码 error_code=1 和本应用 bundle ID。其他服务端请求返回明确不支持错误。 |
| G06 | 非 Windows 平台明确报告当前传输不可用。真实服务、企业代理、heartbeat、后台重连与最终云端页面仍分别验收。 |

连接由独占原生线程持有，UI 线程仅提交有界请求和接收结果。模型读取的超时、队列容量和本应用初始化元数据属于宿主适配，实际服务尚待验证。WinHTTP 保活与固定官方约 10 秒 ping 的差异继续登记。

生命周期回归还必须覆盖：旧请求晚收尾不能关闭新身份的连接；明确注销或凭证过期使匹配连接退役；通知发布按当前连接标识准入，与退役同步；应用最终退出显式停止宿主，多窗口中的单窗关闭不停止全局连接。完整 Windows 联合用例使用私有回环服务承载实际初始化能力、attestation 回执、并发模型读取与通知，不使用真实云端凭证。

完成本单元后，串联原生草稿回执、thread/resume、聊天宿主分派和设置侧栏。已有本地线程加载与模型缓存按宿主隔离后再接页面编辑入口。
