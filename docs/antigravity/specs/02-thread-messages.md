## 控件树与呈现

```text
P02.USER[turnId]
├─ BUBBLE：现有 70% 上限、22px 圆角、16px/10px 内距
│  ├─ CONTENT：完整文本保留，折叠仅改变可见高度
│  ├─ ELLIPSIS：折叠时单独一行，不进入复制内容
│  └─ TOGGLE：显示更多/收起，aria-expanded/controls
└─ ACTIONS：现有收藏/复制/编辑/分叉；图标、明确名称、键盘聚焦时可见
P02.PROMPT_NAV：已加载提问 >=4 时出现，目标为用户块
```

正文仍沿用当前纯文本渲染；官方 user-formatted-text 的富文本与附件是明确差距，进入 02C/03I，不以本轮折叠代表已对齐。保留既有业务回调；编辑仍是重新填入 Composer，不能描述成官方回滚编辑已实现。

## 场景与视觉锚点

- P02-S01：短中文、空文本、长英文无空格，检查边界和溢出。
- P02-S02：40 行文本，折叠/展开/重新收起，宽窄窗分别保存实际截图。
- P02-S03：一段长文本随窄窗换行，窗口恢复后重新测量。
- P02-S04：3/4 条提问、包含纯附件或尚无助手响应的轮次；导航目标检查。
- P02-V01 气泡边界；V02 正文行高与19行裁切；V03 单行省略号；V04 按钮行与操作可见性；V05 导航目标。
- 同条件官方截图缺失，几何测量仅证明实现符合静态合同；官方参考图、像素差异、原生物理输入与用户验收必须另证。

## 实施与偏离规则

新增组件只用于 map 内每条消息独立测量/展开状态，不引入通用折叠框架或依赖。仅改本轮正文、操作可达性和导航入口，不改服务请求、权限、附件持久化或共享 Markdown 行为。缺少官方运行时证据的样式不自行设计；临时浏览器 fixture 明确是组件回放，不模拟真实任务成功。
