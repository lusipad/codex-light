# 21L Sites 邀请的待处理状态

基准为 Windows Store 26.1027.3384.0，asar SHA-256 `6fbedf054a8d8cafaf5c745b40aa59176512e106e0bd6308275ae123b60fd074`。参考 21J/21K 的提取清单与原始文件，未重算整包。本轮无官方同环境截图和真实邀请。

`sites-share-query-3bfcb272daf5.js` SHA-256 `6a0dfe202eb3fcde0be17b5a9e2c2f42e23692ee21a2eb411f96f860ab7fb424`，UTF-16 `[622,2483)` 的 `h` 原函数回放表明，在缓存有效、无在途查询时，`pending` ACK 直接合并参与者并标记 `pending:true`，该分支无即时 GET。`appgen-share-dialog-778a71d62104.js` SHA-256 `2cbe3c3798b3295cbeb8f90c0169fa9ca2c117174874c25312b940fc57cd3ffc` 的 `Y-local-En` `[15566,16227)` 构造成员、邮箱、群组和团队的行数据，团队按群组 ID。`Cn` `[35269,35538)` 和 `gn` `[27545,33206)` 将状态渲染为「待处理」。`role_id=role-site-editor` 映射编辑者，其他值映射查看者，群组展示查看者。

| 用例 | 操作与预期 |
|---|---|
| L01 | 选中目录成员、团队或邮箱，收到 pending。一次 PATCH，立即显示所选对象与「待处理」，无即时 GET，不通知父页面访问权限已确认。 |
| L02 | 关闭并重开同一弹窗，ACK 晚到或读回暂缺时保留待处理行。重新读取命中真实记录时以服务字段替换显示。相同对象不可重复邀请，不同对象可依次邀请。 |
| L03 | 无效 ACK 不生成行。账号作用域取消、权限读取失败或管理员独享状态时，隐藏待处理投影。现有角色修改、删除和链接模式继续走原确认流程。 |

待处理行用于显示和候选去重。后续移除与角色操作使用读回的权限记录，和官方缓存行的可操作性存在差异。ACK 未知时维持原有写锁与只读恢复。真实账号状态、头像、像素、原生交互与用户验收单独验证。
