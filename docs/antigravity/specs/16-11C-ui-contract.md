# 16.11C 远程插件界面实施合同

2026-11-03。修改前合同；依据 `16-11C-remote-plugin-contract.md` 与固定 Store 26.1027.3384.0，沿用其 asar 哈希和原始锚点。此文不是功能、原生或像素验收结论。

## 范围与接线

- 保留 16.11B 本地启禁、技能编辑、推荐安装、市场移除及未知送达 journal 的语义。
- CLI 库存与账号服务库存独立加载、显示各自错误、独立重试。任何一侧失败不得清除另一侧已经成功读取的事实。
- 服务快照必须携带实际 ServiceIdentity；UI connectionIdentity 仅负责失效隔离，不能替代宿主身份核对。切账号/工作区/连接代次时取消旧请求，清旧服务快照、待核验展示与详情；旧请求不更新新视图。
- 合并依据真实 remotePluginId 或 shareContext.remotePluginId，无法取得 raw id 的 CLI 远程项不得按名称猜 id。同名本地项保留；管理插件数量取搜索前去重库存长度。
- 远程条目不加入 configured market 列表，不参与本地市场卸载；远程源不能调用 config/batchWrite 或本地 plugin/uninstall。

## 操作与状态

1. 启禁：服务快照有同 raw id 和真实身份、非管理员禁用、当前插件无在途/待核验操作时，调用固定服务 API。默认安装策略不禁止启禁。
2. 卸载：上述身份和单飞条件成立，且不是 remote+installed+INSTALLED_BY_DEFAULT，用户明确确认后调用固定卸载 API。取消确认不发请求。
3. HTTP 成功与库存确认分开。只有完整服务库存证实启禁值或目标已不存在，才能显示相应成功；pending/unknown 保留操作与身份，仅提供只读核验，禁止以重试方式再次 POST。
4. 同插件启禁/卸载共用单飞状态，其他插件不被整页锁住。账号切换、组件卸载、事件晚到不得恢复旧行或旧成功提示。
5. 服务确认后刷新本地 skills(forceReload)、apps、管理配置；刷新失败保留已确认的服务事实，并持续显示独立警告与真实只读刷新动作。
6. 不支持、未登录、目录资格未知/关闭时保留具体受限状态，不造服务身份、权限 gate 或演示库存。
