官方 delete-confirmation 约 UTF-16 254 起使用 isPending；dialog/row 使用 disabled 和独立 submit/cancel。静态证据证明在途操作状态，不证明本地调度器/目标类型与完整官方策略一致。当前项目保存与运行调用来自真实 Rust API。

| ID | 操作 | 预期 |
|---|---|---|
| AU01 | 保存/暂停/删除快速重复 | 同步写锁，只发一条写请求，失败不吞异常，允许重试 |
| AU02 | 保存失败或保存期间编辑 | 草稿不丢；在途禁改表单与切编辑对象，成功后关闭 |
| AU03 | 旧列表读取晚于写操作 | 旧成功/失败不得覆盖较新列表；卸载后读取失效 |
| AU04 | 立即运行重复点击 | 同步运行锁，只派发一次真实调度命令 |
| AU05 | 调度器不可用/调用失败 | 错误可见，不按固定延时在当前会话代执行，不声称已运行 |
| AU06 | 打开任务生成的会话 | 使用现有 selectThread 完成加载和工作区恢复，不只改 ID |

本批不改调度算法、RRULE 或真实任务文件协议；官方 UI/创建完整性/运行历史事件顺序/持久化原生验收继续保留。
