验收检查标题区的操作、编辑和关闭互相独立。运行、暂停或继续、删除从菜单进入现有真实处理器，操作中的禁用、运行失败、删除取消和错误提示继续生效。菜单关闭后返回触发器，聊天内详情只在菜单已关闭时处理 Escape。窄详情可访问所有动作，删除文字留在菜单内单行呈现。

运行详情打开时按单次运行 ID 自动标记已读的路径另行实现。当前本地批量或按聊天写入的接口范围比单次运行更广。
