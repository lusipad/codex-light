## 静态依据与动作

- `general-settings-5e6e6ad31bf0.js` 的 `to@39792`、`ao`、`oo`（0-based UTF-16 偏移）：颜色文字清除非十六进制字符、统一大写、补 #、截六位；完整六位立即调用保存，不完整输入仅草稿，失焦撤销草稿。颜色圆点独立打开 end 对齐 popover，打开不自动夺焦；内容 p-3、rounded-xl，色板 136×136 CSS px。
- `dist-804f302174db.js`：HSV 饱和度/明度面板、24px 色相轨，面板底部 12px 黑边、28px 圆形指针；方向键每步 5%，色相每步18度。鼠标/触摸连续移动调用 onChange；原生系统颜色窗口不是此控件。
- `general-settings...` 的 `ko@58515`：单行 code 输入、自动聚焦、关闭按钮；用 form 提交；有效性来自主题 parser，空值/损坏/不支持模式不能提交。保存期间禁用输入/取消，隐藏关闭按钮、忽略外点；提交前聚焦 dialog；取消和关闭清空未提交输入。中文来自同版本 zh-CN。

| ID | 操作 | 验证目标 |
|---|---|---|
| AF01 | 输入不足六位后失焦 | 不保存，恢复已读回颜色；无额外错误行 |
| AF02 | 输入或粘贴六位，含杂字符 | 清洗后完整立即保存；IME 选字中不保存，结束后处理 |
| AF03 | 圆点、拖动、方向键、Escape、外点 | 自绘136px色板；夹紧边界；连续更新最终值不被早到读回覆盖；关闭归焦 |
| AF04 | 导入空串、损坏串、异模式、未知预设 | 提交禁用，禁止调用写接口 |
| AF05 | 有效分享串 Enter/按钮提交 | 单次提交、保存忙时不可退出，读回确认才关闭；失败保留输入并显示错误 |
| AF06 | 导入 Tab/Shift+Tab、Escape、关闭、中文IME | 焦点不逃逸；关闭回原按钮；IME Enter/Escape 不触发提交/关闭 |
| AF07 | 1280/640窗口 | 弹层夹紧、无横向溢出；记录浏览器图及几何 |

保存复用现有 `saveTheme` 串行队列与真实读回，不新增协议、不修改全局配置、不新增依赖。颜色局部连续编辑必须保留完整主题字段，失效预设晚到保护保持。
