# 09G 撤销归档后的优先事项顺序

基准为 Windows Store 26.1103.4239.0，asar SHA-256 为 `fb47d6491dc3006b708cb1e14de479b882bf50f88b7daa81818f154c253266aa`。

`215515.1b6ca04e86.js` 的 UTF-16 偏移 45662 和 46539 处在归档时记住活动成员原索引，撤销时扣除仍归档的前序成员后插回，避免重复插入。44351 处为成功项登记撤销；`286353.2f2e9b098f.js` 41665 起的本地路径通过真实取消归档恢复原置顶位置。

当前本地实现应在撤销确认且目录读回后，向同一次活动快照补回恢复的成员，包括已读且空闲的成员。部分失败不能复活失败项，离开或重开活动后不重放旧顺序。继续使用共享恢复入口和现有提示，本阶段不引入全局撤销历史。
