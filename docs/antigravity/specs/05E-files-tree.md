## 回归合同

1. 三层嵌套展开只读取被展开节点；收起不丢当前文件草稿，父级兄弟不消失。
2. 子目录协议失败可本地回退；双失败显示该节点错误，重试重新读取；空目录有独立提示。
3. 延迟目录读取在收起、换根、换连接、卸载后不能提交旧状态；展开目录监听清理，失败不阻断手动浏览。
4. 两根选择不改 `cwd` 与 Git 请求参数；搜索按所选树根执行，过期结果不回写。
5. 文件单击不打开，双击/Enter 沿用原生命周期；保存失败/取消关闭/外部更新脏稿保护与 Git 生命周期原测试继续通过。
6. 专项 Node 执行真实树函数/回调与异步生命周期，类型检查由主线程统一执行。宽窄视觉、原生、同环境官方配对像素单列；缺少配对证据不评分，不记已验收。

未包含：多个独立文件标签、preview/permanent 标签生命周期、展开/滚动跨重启持久化、Changes 全部层级重组。它们继续属于 05/06 差距，不能据此宣称整页完成。

## 发布前文件打开闭环补充

审查发现外部文件入口只预热编辑器，仍停留 Changes；读取设为 silent，且按路径缓存，失败不可见、重复同路径不能重试。官方 `J1` 的 `revealAndFocus` 与真实文件标签语义要求明确打开后显示对应内容，沿用本单元既有来源，不新增未知动作。

新增 `previewRequestId?: number`，主应用每次显式文件打开递增。消费的是独立打开请求，不将失败路径当成功；切 Files 后调用原非 silent 读取，错误可见。脏稿依旧拒绝覆盖且说明原因，不在保存后自动执行旧点击。重复请求的新序号可重试同路径，已有同路径编辑只显示当前内容。专项回归必须执行真实外部 effect 与原打开回调，从 Changes、双失败、同路径重试、脏稿与旧请求清理验证。
