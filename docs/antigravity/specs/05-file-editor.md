# 05A 文件编辑异步身份合同

日期：2026-11-01。修改前建立。参考目录 `.ref/parity/05/runs/20261101-codex-file-editor/reference/`，从固定官方原包提取 6 项资源并校验 integrity。

`text-file-storage` 的读取在各异步阶段检查 AbortSignal，写入使用 expectedMtimeMs 返回 saved/conflict；实际文本编辑器的 getContentWithLineEndings 保留基础换行格式，关闭失败后的 discardConfirmation 明确警示草稿丢失。初次提取的 file-preview 是 ChatGPT library 预览，不能作为本地编辑器依据。

本轮只实现本地文件编辑异步身份与草稿保护：

| ID | 操作 | 预期 |
|---|---|---|
| FE01 | A读取未结束，打开B，随后A晚到 | 仅B可写当前预览；旧失败不弹新错误 |
| FE02 | 外部刷新开始后用户编辑 | 返回结果不得清空新草稿 |
| FE03 | 保存A时继续编辑 | 保存完成只确认提交的快照；新编辑仍脏 |
| FE04 | 保存未结束重复点击或快捷键 | 同一时间只派发一次写；失败保留草稿并允许重试 |
| FE05 | 关闭预览/卸载后异步返回 | 旧读取/保存不能恢复已关闭预览或更改另一文件状态 |
| FE06 | 直接切换脏文件 | 明确阻止覆盖并提示先保存，不静默丢弃 |

不以这些检查替代磁盘并发写冲突检测、关闭时保存/放弃弹窗、自动保存、官方多标签编辑器或像素验收。后续仍需实现这些官方差距。
