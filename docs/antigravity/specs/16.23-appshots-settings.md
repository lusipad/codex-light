# 16.23A Appshots限定纠偏

## 第04批开发前合同（2026-11-17）

本节为新增实现入口；下文2026-11-03为历史纠偏，不证明当前版本合同。固定官方Windows Store为26.1111.2228.0，asar SHA-256 `2551cba1057a05cdc5cf5d75b146fac4092bff4ce77a10c43e3286c88d24c82d`。现有主屏截图附件继续独立存在，不改名冒充Appshots。

### 本批范围和实现顺序

1. 同版源码确认支持、注册、偏好、触发、目标和Composer消费合同，保存原始锚点。不能把supported、isActive、configuredHotkey合并为单个开关。
2. 自有Windows捕获执行器：同一EXE的专用worker入口，在Tauri初始化前分派；C++20捕获/UIA仅在worker进程执行。复用现有编译链，不添加依赖或复制官方helper。
3. 父进程管理一次捕获的身份、私有输出和取消；超时/取消必须终止并等待自己创建的worker，不能仅停止等待同步UIA线程。worker未接入真实入口前不恢复设置开关或宣称可用。
4. 图片和可用文本按官方消费者合同进入原草稿作用域，随后接实际快捷键、设置读回与注册失败回滚。未知消费者字段先取证，不直接把AX文本塞进输入框。

### 内部宿主合同

当前消费者精确取证在`.ref/parity/16/desktop-host-r1-20261116-current/appshots-product-contract.md`及对应anchors中。Windows资格要求正向gate1304276663、2124127696及真实requirements.allowAppshots未禁用；没有已读config不视为允许。renderer向主进程发送资格，宿主另计算supported，实际registration决定isActive；不从probe成功或已保存快捷键反推资格。设置没有独立enabled偏好开关。

捕获结果必须成为专用Appshot附件：metadata/screenshot/可选axText/completed按requestId及attachment generation合并；completed缺截图为失败，重复terminal和旧generation丢弃。AX不填主输入框。最终对象保留appName、windowTitle、bundleIdentifier、axTree、imageName、imageDataUrl、可选transition快照及图标，imagePath为null。预览默认截图，仅真实非空AX提供“查看文本”→“纯文本”；移除同时清理两者。232px专用卡及pending形态有静态依据，精确动画、官方配对图和原生焦点仍待验。

Windows双Alt为默认，可配置双Shift；首次说明接受与宿主权限不同，取消说明不捕获。目标必须沿同flight/origin锁定，不在开始捕获时另取新前台。普通自动路由有60秒最近交互判断；新Work会话要求真实access allowed；Mini路径限定macOS，不在Windows造同名替代入口。companion条件分派与其内部交付未恢复的边界分开登记。

- 内部请求/响应可与Electron不同，但必须保留真实目标、像素、可用文本及取消结果。请求有唯一ID；renderer不能提交任意HWND或输出路径，目标来自宿主的实际用户触发。
- 仅用HWND或PID不足以证明目标身份：需锁定进程创建时间、窗口生命周期以及捕获对象；目标销毁或身份不能确认时退役，不按复用的整数句柄重新绑定。
- 父进程指定私有输出位置，限制请求/响应字节数，校验实际图片、大小与请求身份；目标内容不进入诊断日志。失败或晚回不进入草稿。
- WGC不支持、拒绝、关闭、超时和损坏分别失败，不退回主屏截图。UIA无能力、超时、截断或部分文本如实返回；Classic ValuePattern已知4096限制保持登记，不承诺任意应用全文。
- 宿主是否允许图片成功/文本失败的部分结果，须按官方消费者合同核定；执行器不新增官方无依据的选项或窗口选择器。

### 开发与验收用例

| ID | 前提与动作 | 预期及证明方式 |
|---|---|---|
| AS04-01 | 自有固定窗口触发捕获 | PNG确为目标窗口，文本能力独立记录；复用真实WGC/UIA fixture并核图像及屏外哨兵 |
| AS04-02 | 捕获前取消、捕获中取消或超时 | 自有worker退出并被回收；不交付晚结果，不留下可被草稿引用的半成品 |
| AS04-03 | 目标关闭、进程退出或句柄复用 | 拒绝交付，绝不重绑定到新窗口；实际生命周期回归不足时保留未验 |
| AS04-04 | provider无文本、返回部分或卡住 | 不伪称全文；硬超时可终止worker，主应用仍可处理后续请求 |
| AS04-05 | 请求/响应过大、身份不符、图片损坏或越界输出 | 拒绝；仅清理本次私有文件，不处理用户任意路径 |
| AS04-06 | 捕获中切聊天、项目或关闭原草稿 | 只投递仍有效的原作用域；退役结果不进入新聊天 |
| AS04-07 | 改快捷键、注册冲突、重启 | 实际注册/注销与读回一致，失败回滚；注册成功不能仅由偏好保存推断 |
| AS04-08 | 宽窄窗、附件预览/移除、键盘和IME | 对照同版原始合同与同环境官方图；真实Tauri验证。缺官方配对图仍记视觉未验 |
