# 12B 安装后的连接准备闭环合同草案

日期：2026-11-03。状态：调研完成、实现前合同；12 整页未验收。只读检查了 12A 验收、`12-plugin-actions.md`、当前 `src/plugins.ts` 与 `SkillsMcpView.tsx`。本合同不重复 12A 的同插件写锁、目录读回、详情旧响应及目录显示更多。

## 确定的问题和优先范围

当前 `handleInstallPlugin` 在 `plugin/install` 返回后，只把 `appsNeedingAuth` 拼成一次 toast，随后刷新列表和技能。它不使用 `authPolicy`，不保留待连接应用，也没有从该结果继续连接的动作。插件详情仅列出连接器名称；应用目录也没有连接动作。对返回 `ON_INSTALL` 且含待授权应用的真实响应，用户会看到“已安装、需要授权”，随后没有继续完成准备的路径。

另外，`installPlugin` 把响应缺失的 `authPolicy` 默认为 `ON_USE`、缺失的 `appsNeedingAuth` 默认为空数组；当前已登记协议中这两个字段均必填。损坏或不兼容响应因此会被解释为无后续要求，出现假成功风险。

建议下一单元优先交付“安装写入成功 → 保留必需连接项 → 打开服务端提供的连接入口 → 重新读取真实连接状态 → 已准备/仍待连接/读取失败”的功能闭环。不要同时展开插件共享、创建、完整 HTTP 远程分类、浏览器扩展安装或市场管理重构。

## 实现合同

1. 严格校验安装响应的策略与待连接数组；未知策略、缺字段、坏应用 ID 进入可见的协议错误，不能默认无连接要求。错误表示“安装结果无法确认”；写操作可能已发生，重新读回再决定可否重试，不能无条件再安装。
2. 安装写入状态与连接准备状态分开。安装成功后仍按 12A 读取真实安装状态；待连接项不丢弃、不只藏在瞬时 toast 中。不得在连接失败时谎称插件未安装。
3. `ON_INSTALL` 有连接需求时展示持续可见的准备区域；单应用可进入该应用准备视图，多应用逐项展示。`ON_USE` 不强迫阻断使用，但保留服务器返回的连接需求和继续入口。两者的官方精确中文、布局、焦点与动效均待配对采证。
4. 只打开服务端明确返回的安全 HTTPS 安装链接；复用已有原生外链工具。不自行拼接认证端点、token、callback state 或 scope。链接缺失显示不可继续及重读入口，不编造可用入口。
5. 外链成功打开只转为等待验证。提供显式“检查连接状态”；若增加窗口返回检查，必须合并同一在途读取，避免重复写入/旧结果覆盖。关闭浏览器、取消授权、空列表和读取失败都不标连接成功。
6. 真实连接读回优先复用 `app/list` 完整分页及 `app/installed` 运行时快照。必须区分“目录可访问”“已安装 enabled”“runtime callable”三种字段含义；不能把其中任一个无依据等同完整 OAuth 成功。在已核实旧生命周期分支，可按候选静态合同识别 `isAccessible===true`；新生命周期、多账号分支未证实时显示“连接状态待确认”，登记差异。
7. 所有异步结果绑定当前项目、插件安装尝试及组件生命周期。A→B→A、卸载后晚回、关闭准备区后晚回不能重新打开界面、复活连接项或更新其他插件。
8. 准备完成后失效相关应用/插件/技能缓存，重读真实数据；不得用本地 patch 假装服务端已连接。现有写锁继续覆盖同插件安装操作，检查连接状态不能再触发 `plugin/install`。

外部 OAuth 链、官方 redirect/state 的生成与校验、回调恢复、新连接生命周期和多账号绑定当前**未完成取证**。能落地的服务端安装链接＋显式真实状态重读可作为有限能力实现，但必须在交付中标明它与官方自动回调恢复的差异，不能据此放行整页。

## 用例与验收

| ID | 操作 | 必须验证的结果 |
|---|---|---|
| PI01 | 真实结构 ON_INSTALL＋一个待连接项 | 插件真实安装状态读回；持久显示待准备应用，不显示全部就绪 |
| PI02 | ON_INSTALL＋多个应用、重复 ID | 每个唯一应用可继续，逐项状态明确；不能连接一个即整组成功 |
| PI03 | ON_USE＋待连接项/无待连接项 | 不擅自改策略；有需求仍可找到继续入口，无需求不制造弹窗 |
| PI04 | 缺字段/未知策略/数组坏项 | 不默认 ON_USE、不假成功；重新读取安装事实，不直接重复写 |
| PI05 | 服务端 HTTPS URL/缺失 URL/非安全 scheme | 正确外链；缺失和非法链接可见不可用；无凭空认证 URL |
| PI06 | 外链打开、取消、返回后检查 | 打开不等于成功；检查只读，不重装；仍未连接保留待处理 |
| PI07 | 真实读取报错、空/跨页目录、false→true | 错误可重试；完整分页不漏目标；只有有依据的真实状态转变才能改变准备结论 |
| PI08 | 项目/插件快速切换、关闭、卸载、晚回 | 旧结果不污染当前上下文，不重开准备区，不复活卸载插件 |
| PI09 | 重复点击检查/连接/安装 | 在途读取合并、原有安装写锁仍生效，无额外安装写入 |
| PI10 | 隔离临时本地插件安装→读回→卸载→读回 | 零真实用户配置改动，确认现有无应用插件路径不回归 |
