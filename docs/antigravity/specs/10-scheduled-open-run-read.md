# 定时任务页打开运行聊天

基准为 Windows Store 26.1103.4239.0，asar SHA-256 为 `fb47d6491dc3006b708cb1e14de479b882bf50f88b7daa81818f154c253266aa`。官方 `637352.87e88e539c.js` 84899 在打开本地任务关联聊天前写运行回执。 `810493.03dbae3a1d.js` 72646 对有聊天的条目走相同动作，没有聊天时打开任务详情。偏移以 UTF-16 从 0 计。已验证的片段与哈希位于 `.ref/parity/09/actual/09N-activity-run-read/read-hooks.json`。

「查看会话」继续走完整聊天加载，复用活动页的独立运行回执和导航守卫。任务页的聊天 ID 来自运行事件或调度器已持久化的最新记录，可直接发起回执，无需等待活动目录刷新。回执失败应显示错误，保留未读，聊天仍可打开。页面重新打开或重启后，使用调度状态已有的 `lastThreadId` 恢复最新一次运行入口。缺少身份时不创建入口。

验收验证实时记录和重启记录的目标、导航拒绝时无回执、打开一个聊天只影响对应运行、读取失败时无虚假回执，以及 Windows 原生持久状态。当前范围为定时任务页查看聊天动作，历史运行列表和任务详情布局另行对照。
