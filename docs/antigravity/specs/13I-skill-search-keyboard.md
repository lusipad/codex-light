# 13I 技能搜索的键盘操作

参考 Windows Store `26.1103.4239.0`。使用 13H 已核验的 asar 清单和原始条目。独立技能页 `604319.7947499c94.js` 的 `no0e` 在 UTF-16 偏移约 35,600–36,900 合并搜索结果并限制活动索引，在约 40,300–41,130 处理方向键、滚动和 Enter。查询变化将索引归零。参考顺序是建议、已安装、推荐。本阶段对齐当前产品已有的后两组。

1. 有结果时第一项高亮。上、下键遍历实际呈现的已安装与推荐卡片，到首尾时停止并将高亮卡滚动到可见区域，输入焦点仍在搜索框。
2. Enter 等价于点击当前卡片，保留各自预览入口。推荐安装按钮与键盘预览分离。输入法确认、空查询、空结果和管理页面不接管这些键。
3. 输入新查询重置高亮。结果数量变化按当前数量限制索引，键盘不会触发已消失的结果。卡片已安装后只占一个搜索位置。

`192666.161cacd23a.js` 的共享卡片约 31,800 处以 `bg-text/5` 表示高亮，焦点环单独处理。当前卡片保留各自背景，以 5% 文字色叠加区分活动结果。

用生产组件回放和隔离原生窗口核对。完整搜索分组、建议服务、官方运行时与同条件像素另验。
