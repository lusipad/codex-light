# 16.24A 浏览器限定纠偏

2026-11-03，修改前合同。原包参考哈希和定位片段在 `.ref/parity/16.24/reference/`，提取核integrity；固定asar含offline补丁，原生运行时gate和像素未验。

原包browser-use-settings通过in_app_browser gate与真实原生浏览器管理历史、下载、密码/站点权限、导入和扩展等，能力受主机和远程gate限制；不是CDP端口/无头/WebMCP本地表单。当前没有该原生浏览器服务；不探测真实浏览器私有配置、不自行开放调试端口。撤无效配置，明确能力缺口。

验收：旧无执行器控件及加载/保存字段消除；不删除用户旧偏好；不显示通用保存成功。仅保留真实可执行入口；无服务状态不能写成账号无权限、未安装或空列表。生产JSX回调/接线回归，受影响Composer与设置回归、完整标准检查/原生构建。官方真实原生权限/完整服务、同条件像素和用户验收另验。
