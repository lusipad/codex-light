## 修改前验收条件

1. 目录返回乱序的名单内外条目时，默认只呈现名单内且确实存在的条目，按官方顺序显示。缺少某项时不造卡片。空白查询恢复默认浏览。
2. 搜索匹配目录中的名单外条目。结果保留目录顺序，超过六项时仍全部显示。当前本地目录协议只提供完整描述，搜索本轮覆盖实际可读的原名和描述。
3. 默认候选七或八项全部显示。九项及以上先显示六项，按钮标签预告隐藏条目。展开后再次操作可收起。搜索与浏览切换后折叠状态重新初始化。
4. 仅当前呈现的已装推荐卡片从已安装总览去重。展开、收起及查询切换后仍能从一处看到已安装技能。读取真实预览与安装结果继续使用已有链路。
