## 已证结构与当前差距

- 官方文件编辑与变更均属于聊天workspace的内容标签。当前DiffDrawer默认固定四标签不等于官方默认组合；官方冷启动组合仍未知，不能换成另一组硬编码标签。
- 官方内容区水平排列正文与右侧文件树，文件树为border-l、左缘拖拽。默认宽250、最小200、最大父容器60%，均为逻辑尺寸，不冒充未知DPI下的物理像素。
- 普通树具有多根选择、筛选、适用的“已更改的文件／所有文件”折叠组；适用时提供“所有更改”。非Git目录不强造变更数据。
- 当前Files是路径栏、创建工具条、搜索、单层目录和预览的独立资源管理页；Changes目录清单纵向占据上方。下一批先纠正区域组织，保留既有真实文件/Git调用。
- 官方普通树选择与双击打开、变更树preview与永久标签有不同语义。文件切换和关闭须保护脏内容，不能仅替换textarea。
- Git刷新等动作应属于对应内容控制行，不能无条件复制到每个文件表头。
