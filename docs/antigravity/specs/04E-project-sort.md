3. 项目或所属聊天时间更新后重新计算；展开状态以ID保留，不依赖当前数组索引。
4. Tab可达，Enter/Space单次执行；排序不展开项目、不创建聊天、不持久写入。
5. 宽窗仅活动列有方向图标；680px以下时间列和按钮均隐藏，名称排序可用。
