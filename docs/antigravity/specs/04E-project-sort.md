## 验收合同

1. 首次显示按有效时间降序；同时间按名称及ID稳定排序，秒/毫秒样本显示与排序共用规范化时间。
2. 名称首次点击升序，再点降序；换回时间默认降序，再点升序。筛选不重置方向、项目集合不增删。
3. 项目或所属聊天时间更新后重新计算；展开状态以ID保留，不依赖当前数组索引。
4. Tab可达，Enter/Space单次执行；排序不展开项目、不创建聊天、不持久写入。
5. 宽窗仅活动列有方向图标；680px以下时间列和按钮均隐藏，名称排序可用。
6. 原项目创建、ID归属、同根多项目、展开、新聊天和兼容移动动作回归不退化。

修改前先补生产组件回归使现状失败。之后宽窄浏览器检查及原生焦点验证单列。当前没有官方同环境配对图，score=null；静态来源不能证明运行时gate或排序持久化，不新增未经证明的持久化逻辑。
