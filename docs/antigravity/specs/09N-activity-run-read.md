验收检查

1. 仅运行未读的空闲聊天开启「定时任务」后进入优先事项并显示未读。关闭筛选时从活动视图及批量范围排除，独立置顶与既有分页范围继续适用。
2. 鼠标或键盘打开该活动行后，写对应运行并重新读取调度状态。导航守卫拒绝时无写入。
3. 「全部标为已读」覆盖完整优先事项快照。计划任务先持久化运行回执，再按有效聊天修订号更新其聊天读状态。普通聊天继续独立处理。回执失败保留运行未读并显示错误，晚到运行仍未读。
4. 旧后端缺未读集合时不为已知计划任务猜测读状态。切换作用域后旧回执不更新新视图。通过离线原生任务验证回执和重启读回，未读标记复用现有图形。
