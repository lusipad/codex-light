# 10N 调度状态的版本兼容

10M 根据官方详情保存了没有聊天 ID 的失败。旧版 Rust 反序列化要求 `activityRuns[].threadId` 为字符串。该字段缺失时旧版会退回空调度状态，影响任务进度、已读回执和单次任务消耗标记。

写盘继续用旧版可读的 `activityRuns` 保存已关联聊天的记录。无聊天终态放入独立可选字段。新版读取两个集合，也读取 10M 写入原数组的无聊天终态，按原有顺序和上限合并。读写仍是同一个文件的原子替换。

验收用旧版结构解析真实写盘结果，检查任务状态、消费标记、聊天 ID 和已读时间。用新版再读取无聊天失败，检查排序及迁移前后的记录。旧版若重新保存文件，其不识别的历史字段可能被丢弃，需单独记录这一边界。
