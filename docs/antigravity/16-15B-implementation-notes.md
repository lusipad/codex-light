# 16.15B 实施记录

计划：[固定基准及验收合同](specs/16-15B-next-closure.md)。全App复刻目标保持active；本阶段不是只保存一个清理开关。

## 决策与假设

- 高置信：官方纯计划器使用JS localeCompare；本项目也在TypeScript执行同语义，避免Rust字节排序改变同龄候选顺序。原生仍负责身份复核及受锁删除，不信任任意渲染器路径。
- 高置信：偏好位于electron-persisted-atom-state四个原key；只支持真实local host，保留其他键，CAS与读回验证。缺失/非法原值读默认，不因读取而迁移重写。
- 高置信：自动删除必须快照成功；保留现手动settings-targeted例外，复用同一cleanup与删除锁。
- 队列、lease、身份与上游消费者已补固定证据并接生产；关联thread/attached归档恢复仍是独立未闭环范围，不猜定时器、不冒充整个归档系统完成。

## 偏离政策

继续处理清晰、可逆的实现；读取失败采取保留目标并登记保护增强。禁止在开发测试中清理真实用户工作树，所有删除/脚本测试使用UUID临时目录。不得以偏好保存或候选预览代替自动执行完成。

## 实施顺序

1. 补队列/触发/上游刷新证据，锁定真实消费者合同。
2. typed偏好、严格候选采集、纯计划器及黄金比较；验证WB01/03/04/05。
3. reason-aware受控删除；验证WB07且回归16.14C。
4. 队列、逐候选保护与生产触发，再设置UI；验证WB02/06/08/09。
5. 完整标准、全Rust、原生/视觉自验，记录未测项，阶段完成提交并视远程推送。

## 偏离 / 意外 / 待复核

用户交付约定：大阶段完成并验证后提交一版；检查远程是否分叉、是否包含无关改动后决定推送，不反复询问已授权的阶段提交。
