# 23E 会话分享准备与宿主事务

状态：内部底层限定范围本地自验和构建完成；完整分享页面仍开发中。完整分享入口、真实 HTTP、原生和像素验收尚未完成，未获用户验收。

修改前依据：[快照分享合同](../specs/23-share-thread.md)、[上传边界补证](../specs/23-share-upload-boundaries.md)、[本轮计划与实施记录](../runs/20261103-codex-share-implementation.md)。基准仍为带 offline 补丁的候选包，不代表干净发行版运行时。

## 本轮实现范围

- `shareThreadHistory.ts`：独立读取完整本地会话，不用 UI 最近页。paginated 固定 5/asc/full；其他本地模式完整 read；取消、身份失效、非法页、重复轮次或游标均拒绝部分结果。没有为读取历史 resume 会话。
- `shareSnapshot.ts`：六类白名单输出、输入清洗、路径/diff、duration、图片和 inline visualization 资产引用；不携带完整协议对象。未覆盖的复杂 Markdown 与旧 visualization 明确拒绝，不以自写简化解析冒充完整官方 AST。
- `shareRedaction.ts`：递归脱敏字符串值并保持键，合并区间，脱敏前后均检查 UTF-8 10MiB。资产字节不经过此脱敏器。
- `prepareShareThread.ts`：组合完整读取、候选收集、末64项/并发4、25MiB/100MiB逆序保留、资产引用、快照及脱敏；读取器作为明确依赖，必须执行来源权限、url_safe、流式限额。当前没有接入真实读取器。
- `chatgpt_service.rs`：固定申请目标/发布 POST、宿主持有 PUT target/manifest、组织网络策略、身份绑定准备事务、取消和发布未知结果处理。成功 URL 来自服务响应；测试使用合成 transport，不是真实分享服务。

## 明确差异及未完成项

- 当前分享菜单仍不可用，宿主新事务未注册 IPC，未接前端发布 UI。不能称用户已可分享。
- 真实 gate `4157559322`、accounts/check audience、工作区用户/组 principal、图片安全校验与有界读取、HTML资产读取、取消/discard UI 生命周期仍待接线。
- 快照 Markdown 保留无关原排版，官方 serializer 会规范化；复杂语法拒绝范围见转换源码/专项。官方旧 visualization marker、超大消息解码分段 fallback 未实现。
- 宿主资产上传目前串行，尚未复刻官方并发4上传；收集并发4已实现。单发发布、不带 cookie/认证的预签名 PUT、拒绝跳转及部分 URL 结构限制是保守边界，不声称全部等同官方。
- 未进行真实认证 HTTP、非空真实历史、链接权限读回、官方中文/布局、焦点/IME/原生或同条件像素验证。visual=not_executed，score=null。
- 无新增依赖、无提交推送。复用现有认证、取消、routing、完整协议类型与测试工具；没有新建通用网络代理或模拟分享 URL。
