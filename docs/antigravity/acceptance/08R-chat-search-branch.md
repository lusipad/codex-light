# 08R 聊天搜索分支命中自验

按[开发前规格](../specs/08R-chat-search-branch.md)，独立聊天搜索读已加载聊天的 `gitInfo.branch`，用现有字面匹配、高亮和导航。已有正文片段优先，标题命中不附加分支。空查询与其他搜索模式不显示分支预览。

- 生产搜索回放先复现分支独立结果缺失，修复后覆盖大小写、标题抑制、正文优先、按 ID 去重和导航，以及空查询与根搜索范围。125 项发布前端回放、TypeScript 和 Windows EXE、MSI、NSIS 构建通过。
- Store 自带 `codex-cli 0.167.0-alpha.3.2` 的隔离探针通过文件新增、移除、停止和空聊天页。本地分支命中使用已加载聊天字段，其非空情形另由原生夹具验证。
- 隔离原生 EXE 的 1442×914 和 949×866 窗口搜索 `repair-ui`，仅分支命中的「构建结果」显示并高亮 `feature/repair-ui`，标题行无分支副标题，正文响应到达后正文行只显示协议片段。方向键和 Enter 打开「构建结果」，`thread/read` 与 `thread/resume` 都读同一 ID。工作区显示 `main`，证实搜索副标题来自聊天自身元数据。
- EXE SHA-256 为 `28bf45648aaee6f325ad1234cbfa3e34d6ba2eb471d148061eb569bb420e4acc`。无模型轮次，截图、协议日志和构建记录位于 `.ref/parity/08/actual/08R-chat-search-branch/`。

本轮保留正文协议结果优先的既有合并次序。官方跨来源评分、非连续模糊匹配、真实账号数据与同环境像素仍待验。
