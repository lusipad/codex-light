# 09D 活动侧栏入口与优先事项菜单

依据[开发前规格](../specs/09D-activity-header.md)对齐活动按钮的可访问名称、优先事项标题、空态和批量已读入口。移除自建横幅及铃铛右键的收件箱跳转。活动选项复用 `ThreadActionsMenu`，批量写入复用现有 app-server 回执流程。

## 本地验证

- 生产组件回归先复现缺少活动选项菜单，修复后 13 组活动侧栏序列通过。覆盖未显示页的唯一未读项仍可启用菜单、全部已读后禁用、铃铛开关与右键。原有批量 revision、取消和归档回归继续通过。
- 首轮 Windows 原生测试发现，去掉右键跳转后会显示 WebView2 默认菜单。最终构建仅在活动按钮上拦截此菜单。复测右键保持首页，左键进入优先事项。
- 使用隔离 `CODEX_HOME`、WebView2 数据目录与真实 CLI 0.165.0。原生窗口显示 10 条并提供展开按钮。Escape 关闭菜单，Enter 可从原触发器重新打开。只读 SQLite 在取消前后都显示 12 条未读。选择「全部标为已读」后显示 0 条未读，仍有 12 条会话、0 条归档，未使用模型。当前列表保留，菜单项禁用，关闭活动后重开显示「暂无需要关注的聊天」。
- 117 项前端回放、TypeScript 检查、722 项 Rust 测试、通知适配器、发布元数据和 Windows EXE、MSI、NSIS 构建通过。原生使用最终 EXE，SHA-256 为 `f2f389a651fc06f6b41945235c2d2683bae97b18bc632898b4c61c677d7b806b`。测试应用已退出。证据位于 `.ref/parity/09/actual/09D-activity-header/`。
