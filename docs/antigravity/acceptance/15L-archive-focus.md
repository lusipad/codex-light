# 15L ChatGPT 会话取消归档焦点

基准为 Windows Store `26.1103.4239.0`。定位采用从零开始的 UTF-16 字符计数。

| 官方锚点 | 对照行为 |
| --- | --- |
| `678916.8bc60ed422.js` 7470–8150 | ChatGPT 会话在点击取消归档时捕获触发按钮，分别处理成功与失败。 |
| 同一 chunk 23430–24150、29140 | 成功后选后续可用按钮，再向前找；失败回原按钮。用户移动焦点则取消接力。 |

复用设置归档的现有写入、重读和账号身份校验。没有后续可用按钮时退回搜索、刷新或页内容器。云端任务、durable 和本地恢复继续使用各自原有动作。账号更换、离开设置或晚到响应不重新设置焦点。

专项回放验证向后、向前、失败、无候选回退、原来未聚焦、用户移开和身份失效。隔离浏览器用生产组件和内存宿主桥确认成功移到下一条会话、失败回原按钮、请求中移到搜索后保持焦点。共三个隔离请求。没有真实账号请求或写入。

原生云端动作和官方配对像素待验，用户验收待定。浏览器结果位于 `.ref/parity/15/actual/15L-archive-focus/browser/verification.json`。

TypeScript、发布元数据、113 项前端回放和 Windows EXE、MSI、NSIS 打包通过。未重跑 Rust 全量单测。GitHub Actions 最近的主分支作业仍因账户付款或支出限额未启动。
