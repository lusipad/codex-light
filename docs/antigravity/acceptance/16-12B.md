## 改动与复用

- `App.tsx` → `SettingsView.tsx` → `HooksSettings.tsx` 传真实已登记 roots：选中项目全部根保序去重，再追加其余 host roots 排序。空根不回退到服务默认目录；roots、连接和账号变化使旧视图失效。
- `hooksSettingsModel.ts` 按官方来源映射、真实 hook key 去重，保每项目 cwd、每插件 ID/null 身份和诊断；事件按首次出现顺序，组内按 displayOrder。来源索引显示配置、插件、项目、其他分区。
- `HooksSettings.tsx` 与专用 CSS 替换平铺卡片和筛选框：来源入口、居中详情对话框、事件组、折叠审阅、当前来源全部信任、启停和明确重读。进一步追踪纠正了早期资料“右侧抽屉”的推断：官方是居中 680 CSS px、最大 92vw 的对话框。
- 未信任/变更项显示关闭且禁用；受管项始终显示开启、只读，禁用包装可 Tab 聚焦并读出状态。原始完整命令、独立 MCP 字段、空 matcher、timeout、prompt/agent 类型按真实值显示。
- `hookState.ts` 复用既有 CAS 与读回，补信任前禁止启停、managed/raw key/来源/定义保护，以及每个异步边界的上下文检查。关闭或切换后不继续发后续写，也不接受旧结果；已送达写不冒充撤销。
- 复用原生 dialog 焦点约束、既有配置协议、公共按钮、Lucide 图标和真实本地文件打开 IPC。无新依赖、无 Rust 改动，不重建 Hook 执行器。
