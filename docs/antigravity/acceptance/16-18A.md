# 16.18A 存储页纠偏：待验收的限定增量

[规格](../specs/16-18-storage-settings.md) / [证据](../../../.ref/parity/16.18/verification.md)。

范围：撤销本地容量替代云端配额和危险缓存删除入口；显示云端服务尚未连接的真实能力状态。未接入官方云端usage、Library/Space管理、重试、升级/gate。整页为外部依赖阻塞，不能标为1:1通过。

验收：打开设置→存储，看到无法加载与未连接说明；无本地容量、虚假配额、一键清理、通用保存/刷新。已有本机会话/配置不应发生任何修改。专项核页面渲染及命令注销；最终检查/原生产物见证据。官方运行时、原生UI、像素未验。
