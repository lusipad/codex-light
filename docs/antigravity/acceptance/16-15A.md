# 16.15A 工作树目录待验

[修改前合同](../specs/16-15-worktree-settings.md)。本轮只完成本地主机目录设置链，整页仍在开发中。

1. 设置 → 工作树：目录留空为默认，非空 trim 后必须为本平台绝对路径；相对路径显示错误且保留输入。
2. 保存持久化后读回才显示成功。保存失败/读回不一致保留草稿，重复点击只提交一次，离页响应不写回组件。
3. 修改目录本身不创建、移动或删除文件；后续真实新建使用配置目录，工作树列表和项目移动归属解析消费同一配置。
4. 同时扫描当前配置与默认目录；仓库列表的托管判断按路径边界匹配，同名前缀相邻目录不能误认。
5. 撤下没有消费链的保留天数、软链缓存与自动提交控件，原 desktopPreferences 旧数据仍保留。
6. WT01–WT05由隔离真实Git/状态文件测试覆盖，WT06由生产组件回调回归覆盖。构建与完整检查结果见[证据](../../../.ref/parity/16.15/verification.md)。

未验与缺口：官方 host settings 的多主机作用域、自动清理/数量限制/删除前快照与恢复、上游刷新、完整官方控件样式、原生键鼠/DPI/重启与像素。切换自定义目录后更早的自定义目录不再全局扫描（仓库列表仍可发现其注册工作树）；存储统计尚只统计默认目录。扫描分支既有 owner git config/dirty 失败处理与符号链接行为仍须专项核查，不得用作自动清理安全依据。没有对真实用户工作树执行清理。
