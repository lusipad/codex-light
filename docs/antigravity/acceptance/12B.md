## 交付范围

- 安装响应严格校验必填策略、待连接数组、应用身份和链接类型，不默认 ON_USE 或无待连接项。
- 保留每个插件安装结果中的待连接应用，区分安装时/使用时策略；支持收起后继续连接。
  已安装插件的真实详情也提供应用连接入口，避免重新打开页面后只能重装。
- 仅使用服务端 HTTPS 安装链接，拒绝凭据、非法协议和控制字符，不构造 OAuth endpoint 或 state。
  复用现有原生 `review_link_open`。外链打开只显示等待检查。
- 检查走 `app/installed {forceRefresh:true}`，ID 每 100 个分组读取 `app/read`。
  仅方法明确不支持时退回完整分页 `app/list`；权限、网络、损坏响应均可见报错。
  目录访问、运行时 enabled/callable 分别展示，不把 runtime callable 当作本次 OAuth 回调成功。
- 同一组件合并在途检查，外链同步锁防重复；卸载/离页/新安装尝试使旧组件失效，
  旧结果不能刷新新项目，收起后的晚回不会自动展开。
- 安装结果无法确认时重新读取安装事实；读回失败保留待确认并阻止重装。
  市场目录缺字段/损坏不能默认为空；市场加载错误也不能证明插件不存在。
  完整读回成功才解除待确认，普通刷新及错误重试均可恢复。

复用现有 bridge、插件写锁、原生外链、样式类和缓存刷新，没有新依赖或 Rust 改动。
浏览目录已安装按钮按真实状态禁用，避免把连接状态检查变成重复安装。
