# 06I 分支对比的文件列表

沿用 [06C 基准](06C-split-alignment.md)。官方 `.vite/build/worker.js` 1219352–1220480 为分支比较解析合并基点，1221150–1222470 同时读取该范围的未跟踪路径，1222400–1223000 按请求路径及旧路径读取文件差异。偏移以零起始 UTF-16 字符计数。

验收覆盖工作区干净但分支有提交、分支两边分叉、重命名、单文件查看、未跟踪补丁、基准错误和迟到响应。仅存在于比较范围的已提交文件不提供工作区写入动作。

## 实现与自动验证

- 一次 Git 调用返回从合并基点到工作区的原始记录及对应补丁，并补入未跟踪文件。指定审查基点时优先使用该提交。文件路径使用 Git 的 NUL 分隔记录，避免按补丁标题拆解中文和特殊字符。
- 前端以同一结果生成列表和补丁，单文件查看不再触发第二次读取。只有工作区状态报告可写时，分支行才开放对应的暂存、取消暂存或放弃动作。
- Rust 全库 720 项通过，其中新增临时 Git 仓库验证分叉基点、干净工作区中的已提交文件、中文重命名、未跟踪内容、显式基点和缺失基点。115 项前端回归通过，涵盖单文件补丁、分支切换后的迟到响应以及现有审查发现定位。TypeScript、发布元数据和通知适配器检查通过。
