# 05C 脏文件预览关闭

日期：2026-11-03。限定范围本地自验、浏览器弹窗实测与构建归档完成；整页未验收。

修改前依据：[官方合同](../specs/05-file-conflicts.md)、[实施计划](../runs/20261103-codex-file-close.md)。

## 已实现

- 关闭脏文件时先真实保存；写入期间又有编辑则继续保存，直到dirty清除才关闭。
- 保存快捷键和关闭共享在途Promise；重复关闭只保留一个关闭意图，不并发写入或重复弹窗。
- 保存失败或磁盘冲突时才展示“放弃文件更改？”、“您对此文件所做的未保存的更改将丢失”以及“继续查看 / 放弃更改”。无关闭图标。
- 继续查看保留草稿；放弃仅清理该关闭意图对应的预览，不能关闭后来打开的文件。工作区变化、隐藏和卸载取消未决确认。
- 复用05B保存保护、现有dialog/compact样式，无新依赖。默认聚焦继续查看、Escape取消和焦点返回是已实现行为，尚未证明与官方一致。
