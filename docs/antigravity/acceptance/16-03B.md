- Composer/审批：发送、引导、排队、清稿、文件附加、速度/方案/推理强度动作由当前聚焦 Composer 消费；审批仅当前聚焦有效请求处理，不由全局 Enter 自动批准。未单独实现照片选择器，不开放 addPhotos 空消费者。

- 编号偏好：`primary-number-shortcut-target` 默认 tabs，侧栏 Alt+数字、工作台 Ctrl+数字；选 sidebar 后互换，帮助显示同步。无工作区/工作台时帮助隐藏对应不可执行动作；不能把工作台标签当侧栏聊天。

## 真实存储与并发

键位仍写独立 `CODEX_HOME/keybindings.json`。读时纯函数处理已证实 Windows 旧别名、dictation、recent→命令菜单与旧 tab/version 迁移；保留未知命令、未来 version 和附加字段，未来版本不当当前可执行绑定。单项修改只展开相关旧别名，nextTab/previousTab 写 version:1；清空为 null，恢复默认删除目标记录，全部恢复才写空数组。

宿主用精确 revision、同宿主共享锁和 Windows 同一独占文件句柄比较后写入，陈旧/外部修改不被整表覆盖；损坏或不可消费格式保留原文件并拒写。写后读回，跨窗口发送无原始内容的变更通知，其他窗口重新读取。原生菜单按窗口缓存，任一窗口录入时暂停，离页/关窗释放后恢复；不以单个页面 busy 代替跨窗正确性。

编号偏好是独立真实 `desktop.primary-number-shortcut-target` 版本化用户配置链，写后读取有效值，拒绝陈旧版本，不伪报上层覆盖后的写入生效。隔离协议探针已验证写/读/冲突和磁盘内容，零模型 turn；这不等于 Tauri 双窗口原生端到端。
