# 08L 独立聊天搜索分页

沿用 [08K 基准](08K-chat-search.md)。偏移为从零开始的 UTF-16 字符计数。

| 官方锚点 | 对照行为 |
| --- | --- |
| `515947.71d674afb6.js` 26529、27137 | 独立聊天首批展示 25 条，查询多取一条，并按宿主和游标继续读取。 |
| 同一 chunk 约 28850–30000 | 有额外候选或后续游标时显示更多，每次增加一批；同一游标不重复续读。 |
| 同版中文语言包 872520 | 操作为“显示更多”。 |

独立聊天复用已有查询缓存和 `thread/search`，空查询只扩展已加载历史。测试验证首批请求 26 条、仅展示 25 条、额外候选与游标续读、合并去重、失败保留并可重新点击、重复游标停止、旧查询的晚响应不改变当前列表。综合菜单和文件搜索沿用原分页范围。

空查询在本轮曾允许扩展已加载历史。后续核对官方渲染分支后，[08Q](08Q-chat-search-pinned.md) 将其改为置顶与最近两组共享 25 条上限，分页只在输入查询后出现。

本轮只覆盖本地主机。官方多宿主、ChatGPT 云端结果聚合、结果增量后的选中位置与滚动、同环境配对像素及用户验收待完成。

- Windows 隔离实测输入“测”后显示 25 条及“显示更多”。键盘触发后向 app-server 桥发送一次带游标的续读。夹具返回重复条目和重复游标，界面合并为 28 条，隐藏“显示更多”。Escape 关闭弹层，测试进程随后退出。
- TypeScript、113 项前端回放、专用 JSX 验证、发布元数据及 EXE、MSI、NSIS 打包通过。本轮未重跑 Rust 全量单测。
