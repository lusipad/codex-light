侧栏进入独立聊天模式，综合命令菜单提供切换入口。复用本地 `thread/search`、会话打开入口和焦点管理。测试覆盖空输入只列已加载会话、单字 RPC、25 条上限、迟到结果隔离和不混入文件或命令。综合命令菜单及文件搜索原有快捷入口继续使用原模式。

当前实现请求首批 25 条。官方多来源合并、分页探测（首批多取一条）、账号 gate 和完整快捷键配置待对照。本轮只接现有本地宿主。官方同环境像素及用户验收待完成。

- 初版 Windows 实测覆盖侧栏进入、单字搜索打开目标及综合菜单切换。验收中发现独立模式仍显示文件夹控件，修正后重新打包。最终窗口验证切换保留输入并移除文件范围，单字“测”通过 app-server 桥发出一次 `archived:false, limit:25` 查询，按 Enter 打开返回的目标会话。搜索响应为隔离协议夹具。
- 最终 TypeScript、113 项前端回放、专用 JSX 验证、发布元数据及 EXE、MSI、NSIS 打包通过。未重跑 Rust 全量单测。
