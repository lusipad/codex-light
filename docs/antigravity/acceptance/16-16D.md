## 实际交付

- 宿主两命令 `code_review_comparison_read`、`code_review_revision_file_read` 复用真实身份、gate、授权成员、固定HTTP操作、取消和网络策略。不接受渲染层提供账号或任意比较SHA。
- 首次读取并行获取fresh metadata/snapshot，head一致才取merge-base→head差异。opaque snapshotId绑定账号代次、PR、偏好和真实源码账号；最多保留32项，账号失效清空。切提交/读取文件复核账号和授权，保留固定旧快照，只有显式刷新替换。
- All PR changes与单提交选择已接；单提交必须属于原快照且有parent，root禁选。刷新成功回到all，普通失败保留旧快照和选中提交，失权清空；URL/scope变化、取消和晚响应不回填。
- 文件接口支持固定版本、受校验repo相对路径和null侧；成功/unavailable/错误分开，NUL和1MiB作为本机防御边界。完整文件呈现/上下文展开尚未接入，不能把接口测试通过当作完整文件阅读体验完成。
- 复用现有服务、表单token、Markdown隔离与只读差异容器，无新增依赖。没有启动私人审查、模型轮次或发布/合并PR。

## 验收与剩余范围

1. 使用本阶段原生构建，在有权访问的PR读取固定比较；记录三SHA与真实账号。服务端推进PR后切已有提交，应保持原snapshot；显式刷新成功才换新snapshot并回all。
2. 模拟网络失败，原比较与选择保留、错误可见；授权失效或账号/提供商变化后旧内容应隐藏；取消/快速切页不能回填旧数据。
3. root提交不可选；无完整commits响应不虚构列表。文件接口测试不代表实际完整文件展开已实现。
4. 官方运行时/同环境宽窄窗配对像素、Tauri GUI/IME、多窗口、真实账号HTTP及完整schema、用户验收未完成；无视觉评分或1px通过声明。
5. 私人review turn与真实源码工具、完整文件diff UI、专用侧面tab、inbox/search、GitLab MR/cloud仍待开发；不以本增量代替这些要求。
