在隔离目录内使用本轮构建：

1. 打开终端，多次切标签/调整窗口，确认各标签输出归属正确。
2. 在终端启动或持续输出期间隐藏面板，检查无已销毁 xterm 错误；重新打开验证输出回放。
3. 启动后迅速关闭标签，迟到的启动成功或失败不能再次写入原视图。
4. 与固定官方实测隐藏、关闭、重开流程；分别记录 PTY 存活、标签和输出保留、焦点及快捷键。
