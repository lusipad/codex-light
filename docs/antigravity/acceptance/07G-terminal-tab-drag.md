# 07G 拖动终端标签

沿用 [07F](07F-terminal-placement.md) 的 Windows Store 26.1103.4239.0。官方 `182735.bb2cb0d2af.js` UTF-16 偏移 7597265 为终端注册左、右、底部三个放置目的地。相邻的恢复与标题入口均以 sessionId 标识标签。官方通用工作面还支持独立面板分组和跨窗口拖动，当前实现范围为同一工作台内。

验收覆盖从标签正文拖到左、右、底部、拖出工作区或按 Escape 取消、普通点击与关闭按钮、两个标签的独立位置，以及原有文件拖入。拖动只在超过指针阈值后进入放置状态，落点只作用于发起拖动的标签。验收需要确认原终端进程和输出不变。

本轮以工作区内的可见放置区呈现三个目标。区域比例是本地实现选择，待官方同条件运行时配对。

## 原生核验

- Windows 构建产物为 EXE、MSI 和 NSIS，日志和 SHA-256 位于 `.ref/parity/07/actual/07G-terminal-drag/`。
- 隔离 Windows 窗口实测由底部拖到左侧、再拖到右侧。拖到侧栏不移动，拖到底部恢复底部。四次操作后终端标签 ID、实际 PowerShell 进程号和提示行均保持。
- 新建第二个底部标签后，直接拖动非活动的第一标签到右侧，第一标签成为活动标签。正常点击第二标签仍恢复它自己的底部位置。测试窗口已关闭。
- Escape、关闭拖动中标签和误触阈值由生产回调回放验证。Composer 原生路径、边界、DPI 和去重回归通过。系统文件拖入、触摸拖放、官方配对像素、独立分组和重启恢复未做原生验收。
- 117 项前端回归、TypeScript 和发布元数据通过。首轮前端套件因关标签夹具缺少新增拖放状态而失败，记录保留为 `frontend.log`。补齐状态和关闭取消断言后复跑通过，见 `frontend-final.log`。
