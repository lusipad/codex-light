# 本地工作台连续原生实测

基于 `e5fdf04` 产品源码及本次认证修复，使用临时 Tauri 配置构建原生 Debug 版。WebView2 调试端口绑定本机回环地址，应用使用独立 WebView 数据和 CODEX_HOME。测试结束后已关闭实例。构建 SHA-256 为 `a3cbb4e36ecf1eaa084b4651987985144d93f3778a39a1a19e8e79bb4d728dae`。

| 操作 | 验证结果 |
|---|---|
| 注册隔离 Git 仓库，创建并打开会话 | 真实 app-server 返回会话 ID，读回工作目录与隔离仓库一致，原生接续入口选中同一个 ID |
| 打开并保存 `journey.txt` | 文件树和真实编辑器完成操作，界面显示已保存，磁盘读回包含新增行 |
| 查看 Git 差异 | 变更面板显示该文件及新增行，独立 Git 命令核对为新增 1 行、删除 0 行 |
| 打开终端并运行命令 | 底部面板创建真实 Windows PTY，经原生 IPC 向同一会话写入命令，面板显示正确工作目录、同样的 Git 统计和成功标记 |

首次实测复现未登录侧栏认证错误。通用 app-server 桥拒绝 `getAuthStatus`，历史列表却依赖这个调用。修复增加专用宿主命令，固定禁止请求和刷新令牌，只投影认证方式。重建后重跑连续流程，未登录返回 null，误报消失，通用入口仍拒绝令牌请求。认证专项 10 组、TypeScript 和前端生产构建通过。

原始证据位于 `.ref/native-local-journey/72e73b85/`，重点为 `recheck-result.json`、`thread-fixed.json` 和 `fix-build.log`。本次用 WebView2 调试测试入口验证产品界面和原生桥，创建会话使用真实零模型轮次 RPC，终端命令使用实际 PTY 接口。物理鼠标与键盘、IME、首条模型消息、正式打包、官方视觉对照及用户验收仍未验证。远端 CI 和推送继续暂停。

## 工作树重开、保存冲突和 Git 索引

复用同一原生 Debug 构建，执行前核对二进制 SHA-256。产品源码为 `d090bcf`，新建独立 Git 仓库、CODEX_HOME 和 WebView2 配置。用实际界面操作，并用独立 Git 命令及磁盘读回核验。会话数据通过真实 app-server 建立，模型轮次为零。

| 用例 | 结果 |
|---|---|
| LW-01 创建工作树 | 从探索菜单进入工作树，按当前工作区创建。托管工作树出现在真实 Git 清单中，与源仓库 HEAD 相同，源仓库未跟踪文件已复制且内容哈希一致 |
| LW-02 重开工作树和会话 | 关闭原生进程并重启，在列表找到同一工作树，点击「在此启动会话」后 Composer 目标匹配。另建该目录的本地会话，进程再次重启后读回并打开原会话 ID，原生界面仍指向同一工作树 |
| LW-03 保存冲突 | 在工作树编辑 `journey.txt`，经独立进程修改磁盘文件后点击保存。界面提示冲突并保留脏稿，磁盘保留外部版本。切到变更页并返回，草稿仍在。夹具恢复原始磁盘内容后，保存原草稿并成功读回 |
| LW-04 暂存和取消暂存 | 在变更页使用同一文件的行内操作。暂存后只有该文件进入工作树索引，索引内容是外部版本。取消暂存后该文件仍有工作区差异，索引为空。未跟踪文件和主仓库索引均保持原状 |

三个相关脚本通过，分别覆盖工作树创建、文件保存及 Git 工作台。此次实测未复现需要修改产品代码的缺陷。保存冲突覆盖外部写入先于保存校验的场景，读盘校验到实际写入之间的并发窗口仍是已知限制。

证据在 `.ref/native-local-journey/3f8d7aae/`，包含 `create-worktree.json`、`reopen.json`、`thread-after-restart.json`、`conflict.json`、`draft-after-index.json`、`save-after-conflict.json` 及暂存前后的界面和 Git 状态。原生测试进程和回环端口已关闭。物理输入、像素及用户验收仍待单独验证。未推送，未跑托管 CI。
