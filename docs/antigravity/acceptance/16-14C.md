## 实现与复用

- 顶部操作读取真实环境，普通项目与工作树选择使用不同实际作用域；缺失配置保留路径和修复入口，不静默回退。平台过滤、最近名称顺序、主按钮及第1–9快捷动作保留原配置索引；固定版本宿主注册表已证实槽位1默认 `Command+Shift+D`，2–9无默认；Command保持Meta，不转换为Ctrl，Windows物理键触发仍待原生实测。
- 同会话、定义目录及固定 runId 共用动作终端；切换同根配置后重跑会停止旧进程树。每次请求另有唯一身份，原生重读选中配置、原文与索引，不信任 renderer 提供的命令或执行目录。
- TerminalDock 先装监听和渲染器，再调用专用执行入口；重跑新 generation，输出与退出码来自真实 PTY。接受请求不等于命令完成，失败不自动重放。窗口 owner 与普通 IPC 授权共用锁，防止跨窗口抢占。
- 删除在同一后端互斥内按快照→cleanup→重新验证身份→Git 删除→真实读回执行。force 不跳 cleanup；配置无法读取为 warning，实际脚本失败或取消阻止删除。保留目标路径、快照及已归档会话的部分结果。
- cleanup 复用原 runner，但不注入两项 setup 变量、不捕获保存环境差量。前端切页/卸载取消为保护增强，不冒充已验证的官方公开删除取消行为。未新增自主 keepCount 删除调度。
- 设置深链带真实工作区和配置身份；添加动作按原文 CAS 保存、读回，成功后才运行。工作树安全引用源仓库忽略配置时读写复用同一边界检查，不放宽通用路径限制。
- 复用已有 Git、配置存储、xterm 输出合并、Windows Job、按钮及图标；无新依赖。共享 Job 只增加运行中 PTY 进程附着，不复制 FFI。

## 适配限制与待验

- 动作专用终端仅支持实际 PowerShell/pwsh、cmd；WSL/GitBash 明确拒绝。动作 shell 禁用 profile 以先建立 Job 后才允许用户命令，属于已登记适配边界。非 Windows、远程 host 未实测。
- 同步 IPC 接受仅表示命令已发送，进程结果看终端；shell保持交互时单个命令结束不是shell退出。取消可停止进程树，不能回滚脚本已经产生的副作用。
- 真实测试均用可处置临时仓库和无害脚本；没有执行用户 setup/cleanup/actions、模型轮次或真实账号任务。浏览器使用私有 IPC 夹具，不能证明 native 集成成功。
