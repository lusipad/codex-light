1. 默认安装插件显示“由管理员安装”、按钮禁用；不可安装插件不能发安装请求。
2. 同插件快速连续点击只写一次；不同插件可独立写，失败可见且可重试。
3. 展开后马上收起详情，迟到读取不重开/填旧数据；切换项目同样失效。
4. 浏览可用远程与本地目录，刷新发送 forceRefetch=true；无对应账号能力时不伪造远程数据。
5. 完整目录超过50项时显示更多、搜索后段插件；安装/卸载成功重新读取真实状态，错误不得显示成功。
