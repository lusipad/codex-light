# 08U 聊天搜索同字段评分自验

按[开发前规格](../specs/08U-chat-search-score.md)，聊天搜索同字段比较由简化评分改为基于命中片段的评分，复用既有排序、片段高亮及会话导航。使用 UTF-16 评分位置，并拒绝大小写折叠扩展后超出原文的长查询范围。

- 隔离执行固定 asar 的官方匹配导出，合并去重后共 1,041 组样本，其中 163 组命中。命中、UTF-16 片段和数值分数均一致。回放保留大小写、跳词、路径、Unicode、长查询边界及生产排序用例。
- 原生 1442×914 窗口输入 `GRP`，较旧的 `Git Review Panel` 排在较新的 `git review panel` 前。949×866 窗口输入 `grp` 时顺序反转。改回 `GRP` 并按 Enter，读取和恢复均使用大小写精确命中的聊天 ID。无模型请求，隔离窗口已退出。
- TypeScript、125 项发布前端回放、Store 自带 CLI 搜索探针以及 EXE、MSI、NSIS 构建通过。最终 EXE SHA-256 为 `0f192ab8902a60a8aa2e0339db2fe980ff9cbda681b8a661674fee447db78a1a`。样本对照、回放、截图和协议记录在 `.ref/parity/08/actual/08U-chat-search-score/`。

任意输入的全面等价、真实账号多宿主结果及同环境像素待验证。本轮未重跑完整 Rust 单测。
