# 07F 终端停靠位置

沿用 [06C](06C-split-alignment.md) 的官方 Windows Store 26.1103.4239.0。官方 `182735.bb2cb0d2af.js` UTF-16 偏移 7596700–7598110 注册交互终端的 left、right、bottom 目的地，并以同一个 sessionId 序列化、恢复和渲染缩略图。终端工作面与后台只读输出独立。

本轮先落实当前活动会话在三个方向间移动。左侧和右侧为独立列，底部为独立行。每个标签保存自己的位置，切换回来恢复该位置。保留默认底部、原 PTY 和 xterm 实例，使用现有终端操作区提供键盘可达的切换入口。

验收覆盖三个方向、侧边调整宽度、底部调整高度、切换标签及隐藏重开，验证没有重复创建或关闭原 PTY，且聊天输入区保持可见。官方拖放、多个停靠分组同时显示和跨重启恢复仍为独立待办。

## 本轮验证

- 官方 asar SHA-256 与 06C 一致。停靠证据位于 `.ref/parity/07/actual/07F-workspace-terminal/official-placement.json`。保留本应用的底部默认值，侧边初始宽度 360 CSS px，最大宽度为主工作区的一半。
- 117 项前端回归、TypeScript、发布元数据和最终 Windows EXE、MSI、NSIS 打包通过。生产回调覆盖三个方向的拖动公式、尺寸上限和标签位置隔离。生命周期回放确认移动不会调用终端创建或关闭，也不会替换 xterm。
- 隔离 Windows 应用实测从底部移动到左侧和右侧，拖动两侧宽度及底部高度。聊天输入框始终可见，隐藏后占回原区域。隐藏重开、创建第二个底部标签、再切回第一标签，第一标签保留原右侧位置、输出和 PowerShell 进程。两轮测试窗口已关闭。
- 首轮发现深色原生下拉的未选选项对比度不足。最终包设置选项色并复验，三项均可读，键盘仍能选择且保留同一终端。日志及最终产物哈希在同一证据目录。
- 官方同环境像素、窄窗配对、系统输入法和用户验收仍待验证。最新 GitHub Actions 作业在 Windows 步骤启动前失败，远端 CI 待验。
