# 16.17A 真实外部导入待验

[合同](../specs/16-17-import-settings.md)。本批接通claude-code/cursor的app-server检测/导入链，整页未完成。

1. 设置→导入，点击检测：真实检测用户目录及当前工作区；每个来源失败分别显示，保留另一个来源的检测结果，不以缺文件假造成功。
2. 选择检测项后显示确认；取消确认或取消选择不提交。源项、cwd、provider可见。导入前再次检测，源项变化要求重新选择。
3. 写入只经externalAgentConfig/import，不再写customPersonaPrompt或覆盖desktopPreferences。claude-code默认source，cursor migrationSource:cursor与检测一致。
4. importId仅表示请求受理。提前注册通知并按ID匹配，缓存早到完成事件；无关/重复通知不能使别的任务成功。
5. 完成后逐项展示服务成功/失败；文件通过fs/getMetadata和fs/readFile读回，目录仅核存在，会话通过thread/read核身份。缺目标/读回失败单列；不存在所有目标语义已验证的笼统结论。
6. App级状态使离开设置后仍跟踪后台任务；提交前可取消，提交后无取消协议不伪装撤销。断连/超时标结果未知并在当前App会话阻止再次导入。
7. 完成后刷新配置、模型和会话列表。此刷新不等于已完成会话项目注册、无项目会话目录或官方import历史。
8. IM01–IM07前端回归与真实隔离CLAUDE.md→AGENTS.md→fs/readFile协议验证见[证据](../../../.ref/parity/16.17/verification.md)。源文件与原偏好哨兵保留。
