## 私有草稿的页面发布与读回

- 现有环境侧栏提供显式审核和发布确认。首次写入前读取权限、草稿修订、最新轮次和空闲状态，并检查本地待发回复、仓库应用。发布期间停用当前页的草稿编辑与回复。已保存发布回执的草稿通过列表的编辑入口恢复原会话。
- 复用原生发布命令。窗口同源锁防止本地重复发起，回执按账号、用户、配置、草稿、环境和线程分开保存。未知发起结果使用原幂等键，已知操作从查询继续。完成回执与环境读回的版本匹配后才显示已发布。
- 隔离浏览器以 1280×720 验证审核取消零发布、确认后依次一次发起/查询/完成，以及版本读回后的已发布状态。第一次夹具返回旧版本时停在核对状态，修正夹具后通过。记录见 `.ref/parity/22/actual/22J-cloud-publish/browser/`。
- 官方逐项提案审核、终态失败后的恢复动作、发布后新任务交接、共享草稿、真实账号与官方原生像素待验。当前侧栏确认使用已有项目组件。

## 发布失败的显式恢复

- 保存可验证的服务端失败分类。只有快照前失败和快照后失败显示“重试发布”。点击后重新查询同一操作，核对原草稿、原修订、账号及已完成轮次，再持久化新幂等键并开始。过期按钮、状态变化或审核修订变化均不会发起新操作。
- 旧回执可通过“核对发布状态”补齐分类。未知结果继续使用原有恢复链，其他失败保留失败提示。
- 回放验证两类可恢复失败、旧回执升级、错修订、过期操作及服务状态变化。1280×720 隔离浏览器验证先查询原失败、仅一次重试、两次发起使用不同键，成功后读回确切版本。截图和记录在 `.ref/parity/22/actual/22J-cloud-publish/retry-browser/`。
- 过期草稿的重新基准、云环境新聊天交接、真实账号和官方配对像素待验。
