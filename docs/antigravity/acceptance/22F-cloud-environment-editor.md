# 22F 云端环境编辑阶段记录

状态为开发中。[规格](../specs/22F-cloud-environment-editor.md)覆盖 F01–F07，本次实现原生草稿创建原语并修正无编辑权限的菜单。

- 官方原函数隔离回放 12 组、44 个精确锚点通过。Rust WinHTTP 回环候选覆盖交错收发、取消、关闭码、重复子协议头和不受信任证书，仍保存在证据目录，应用会话宿主待接入。
- 原生 `cloud_service_create_draft` 使用宿主身份、固定路径、无请求体 POST 和专用 600 秒传输。回执保留服务端 ID，线程为空和未知结果会阻止再次创建。网络策略在派发前后检查。同账号的已派发未确认项跨身份代次保留，进程重启恢复待接入。
- 独立审查发现网络策略检查缺失、通用 curl 超时与外层超时不一致、身份失效清除未知登记三项问题，均已修复并复核。九组原生专项回归通过，覆盖同配置并发、取消、future 丢弃、坏回执、HTTP 错误和前后身份校验。
- 官方 `KBn` 原函数 48 个权限向量回放通过，实际 React 组件回归 12 组通过。无编辑权限时隐藏编辑项，查看继续读取真实详情。可编辑用户暂时保留额外查看入口，编辑和删除链尚未完整接入。
- 浏览器采用明确本地桥和离线样本。1280×800、440×800 下无权限菜单仅有查看与禁用删除，Escape 返回原按钮，详情可读取，窄窗无横向溢出，控制台零错误。证据在 `.ref/parity/22/actual/22F-cloud-editor/browser/`。

首次窄窗截图输出为 440×275，与 DOM 测量不符，已保留并标记无效。重新打开固定窄视口后采集 `readonly-menu-narrow-recapture.jpg`，实际尺寸 440×800。该图仍是隔离样本，官方配对像素待采证。
