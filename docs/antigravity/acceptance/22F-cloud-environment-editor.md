## 发布失败的显式恢复

- 保存可验证的服务端失败分类。只有快照前失败和快照后失败显示“重试发布”。点击后重新查询同一操作，核对原草稿、原修订、账号及已完成轮次，再持久化新幂等键并开始。过期按钮、状态变化或审核修订变化均不会发起新操作。
- 旧回执可通过“核对发布状态”补齐分类。未知结果继续使用原有恢复链，其他失败保留失败提示。
- 回放验证两类可恢复失败、旧回执升级、错修订、过期操作及服务状态变化。1280×720 隔离浏览器验证先查询原失败、仅一次重试、两次发起使用不同键，成功后读回确切版本。截图和记录在 `.ref/parity/22/actual/22J-cloud-publish/retry-browser/`。
- 过期草稿的重新基准、云环境新聊天交接、真实账号和官方配对像素待验。
