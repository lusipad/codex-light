## 发布前外部文件打开复核

修复审查发现的完整入口缺口：明确文件请求新增 `previewRequestId`，从 Changes 显示 Files；调用原非 silent 读取，让失败可见；同一路径的新请求能够重试。请求按 cwd/连接/路径/序号消费，脏稿拒绝覆盖后不排队等待保存，已在编辑的同路径只重新显示。换连接也使旧编辑读取失效。

`verify-file-editor-lifecycle.mjs` 新增 FO01–FO05，执行真实外部 effect 与读取回调：从 Changes 打开、读取双失败可见、相同请求不循环但新序号重试、脏稿保留并提示、先后两次外部打开的晚到隔离。FO/FE/FC、递归树与类型检查均退出 0；主应用所有显式文件入口的序号传递与统一打包由主线程集成验证。本段仍不证明原生点击、物理 IME 或官方像素一致。
