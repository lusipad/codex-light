在隔离项目中执行：

1. 点击工具栏运行，在慢启动 shell 下确认命令在 PTY 创建后投递一次；不是以 180ms 推断。
2. 等待期间隐藏/重开，确认未发命令可继续；已发命令不再次输入。
3. 新建多个标签、调整高度、隐藏重开，确认标签、输出、活动选择与尺寸保留。
4. 模拟写入失败，检查错误可见且不自动重试；先检查终端是否已收到部分输入，再显式重试。
5. 切换项目后触发命令，应选择对应启动目录标签或新建。手动 cd 的实时目录检测未实现。
6. 关闭最后标签再打开，新 session 能正常创建；对比官方完整流程与键盘焦点。

自动回归不证明 shell 首个 prompt 已就绪，也不证明失败输入可以安全重放。浏览器回放因入口错误后 CDP 超时未完成，详见实施记录。
