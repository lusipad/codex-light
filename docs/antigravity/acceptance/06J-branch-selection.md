# 06J 分支对比的基准选择

基准沿用 [06C](06C-split-alignment.md) 的 Windows Store 26.1103.4239.0。官方 `182735.bb2cb0d2af.js` 在 UTF-16 偏移 7074510–7074700 按会话标识读取覆盖值，7075290–7076340 按当前仓库查询默认基准，7087140–7087720 合并覆盖值与默认值并在切换对比仓库时清空覆盖值。

本轮修复变更面板跨聊天和跨仓库串用基准的情况。默认值复用当前仓库 Git 状态，手动选择按聊天、仓库和连接隔离。审查请求的固定合并基点只传给发起审查的聊天和对应分支。

验收覆盖同仓库切换聊天、同名分支分属不同仓库、切回保留选择、默认分支刷新、过期审查目标、以及没有实际基准时的下拉选项。
