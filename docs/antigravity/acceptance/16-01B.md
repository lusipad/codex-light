在隔离应用状态/测试目录执行：

1. 打开设置，列表与实际安装目标对应；未安装编辑器不得出现。选择后离开/返回、重启再次读取仍相同；不得影响 perPath。
2. 用配置文件打开入口验证真实目标窗口/路径；选择文件资源管理器时定位文件，目录打开目录；系统默认无法关联时显示真实错误。
3. 检测 Git Bash/WSL 可用性；依次选择 Shell，创建新终端验证真实进程；Git Bash 为 login interactive。目标不可用不得冒充打开成功。
4. 先启动一个有输出的终端，改变全局默认再建标签；原标签进程和输出保持，新标签使用新值。终端局部选择可覆盖该次新建。
5. 保存失败/确认读取失败应有明确错误和重试，快速重复不能冲突；默认设置首次读取和卸载不可晚回填。
6. 回归命令注入就绪等待、错误重试、终端隐藏/显示保留及焦点/键盘/输入法。
7. 采集与官方同尺寸/DPI/缩放/主题/语言的宽窄窗口及原生菜单截图；无像素证据不得标视觉通过。
