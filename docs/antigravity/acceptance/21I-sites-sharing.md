## 当前实现与边界

- 管理入口不套用 URL 或域名的 owner/gate 条件。弹层读取真实共享策略、成员身份和独立首选链接；owner 判定来自绑定账号成员或邮箱，不采用站点目录 role、全局 userId 或 raw accounts 首项。
- 所有者可暂存官方允许的链接模式，再向固定 share_access 路径 PATCH。仅明确 JSON null、accepted 或 pending 属于有效响应；写后 GET 收敛，未知结果显式读取恢复，不自动重复写入。pending 的 workspace_all 保持来源要求的 custom 投影，父页面摘要也不能提前显示开放成功。
- 取消仅清草稿，成功保存保留弹层，完成才关闭；保存中仍允许 X/Escape 关闭。重开时回读晚到写入，离页及换账号后不应用旧数据或旧错误。独立链接读取失败保留已加载权限，不拼造 URL。
- 复用现有取消作用域、请求追踪、账号选择、剪贴板和站点 metadata/截图授权更新。无新增依赖；未开放邀请、成员角色修改或删除、团队搜索、个人资料展示及首次发布。
- 官方共享框使用 512px 与 48rem 断点；本项目根字号不同，按 768 CSS px 适配为宽窗居中、窄窗底部全宽面板。菜单依据补证的 j2n/E1.Content，420px、start 偏移 -5px、侧偏移 5px；portal 放在 native dialog 内，避免 top layer 外部节点不可交互。不是完整复用 Radix 碰撞引擎。
