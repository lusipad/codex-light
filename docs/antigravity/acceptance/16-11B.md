- 移除先完整枚举与policy预检，经用户确认后顺序卸载，每项真实读回并保留完成进度，最后再次核市场name/path/config source identity与最新库存，全部清空后才remove，再核配置和库存。关闭不撤销已完成结果，重试不重复已完成/未知项。
- module journal保留原scope的在途/未知计划，A→B→A和卸载后重开不会丢未知意图；旧scope回调只记journal，不污染当前UI。
- 宿主按实际plugin ID将安装/卸载/启禁跨窗互斥；安装先plugin/read解析真实ID，保留原写参数。多ID批次无半锁，不同插件允许并行；错误/取消释放。事件空payload仅重读，不广播配置/秘密。前置读取后的每次 RPC 前复核服务连接世代，改变时明确拒绝继续。
- 两个MCP入口统一复用16.10B组件，移除另一套整表/按空格拆参/误报连接的旧实现。保留技能来源、编辑保护、推荐完整安装与安装后连接准备。复用协议/主题/导航/宿主restart，无新依赖；当前管理页市场/应用的RPC诊断说明已移除。
