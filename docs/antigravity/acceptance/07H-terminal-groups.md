# 07H 独立终端分组

沿用 [07F](07F-terminal-placement.md) 的官方 Store 26.1103.4239.0。官方 `182735.bb2cb0d2af.js` UTF-16 偏移 2287520–2287900 根据目的地使用不同的工作面标签列表，7668800–7670360 分别维护右侧与底部的活动标签，7597265 为交互终端注册左、右、底三个落点。官方以 sessionId 区分终端。

验收覆盖左、右、底部同时显示、单组切换不替换其他组的内容、跨组移动与原 PTY 保留、从各组新建与关闭、每个方向调整尺寸，以及既有工作区命令目标、隐藏与重开。三个分组共享当前窗口的终端控制器，跨窗口及重启恢复另验。

## 实现与本地证据

- 单控制器按分组选择活跃标签，复用终端监听、真实 PTY、xterm 和输出缓冲。跨组移动时重挂现有 DOM。工具区和中断、清屏指向该组的当前标签；全局快捷键仍统一显隐。
- 首轮 Windows 原生验证同时显示三个 PowerShell 会话。把左侧标签移入已有右侧分组后，底部继续显示原提示行。右组切换、全局隐藏重开后，原三个 PowerShell 进程号一致。证据见 `.ref/parity/07/actual/07H-terminal-groups/shells-before-move.json` 和 `shells-after-move.json`。
- 首轮三组同屏时聊天区偏窄。最终调整侧边宽度上限，在可用空间允许时给聊天保留 420 CSS px。该数值为本地布局选择，官方像素仍需同环境配对。
- 最终构建复验三组同屏和左侧分隔条，右侧和底部保留各自输出，聊天输入区操作文字可读。两轮隔离窗口已关闭。最终产物哈希在 `.ref/parity/07/actual/07H-terminal-groups/final/installer-hashes.json`。
- 最终 117 项前端回归、类型检查和 EXE、MSI、NSIS 打包通过。专项包含各组独立选中、迁移原 xterm、单侧宽度隔离和同一个环境动作标签重跑的位置保留。未执行新的全量 Rust 单测。
- 三组密集布局下聊天标题栏仍可能截短，未完成窄窗配对、跨窗口、重启恢复及用户验收。远端 Windows CI 待恢复。
