原生验收需用隔离数据：

1. 首次加载后设置默认“按 Enter 键”；改选另两项即时影响首页与会话输入框，离开设置返回、退出重启仍生效。
2. enter 模式普通 Enter 发送；cmdAlways 普通 Enter 换行、Ctrl+Enter 发送；cmdIfMultiline 单行 Enter 发送，含实际换行后 Enter 换行、Ctrl+Enter 发送；长单行视觉折行仍按单行。
3. Shift/Alt+Enter 不发送；中文输入法选字 Enter 不发送。补全弹层 Enter/Tab 选候选，不能同时发送；空闲 Ctrl+Shift+Enter 不发送。
4. 运行中验证 enter 的 Ctrl+Enter、另两项的 Ctrl+Shift+Enter 进入现有 queue 路径；当前仅默认 steer 情况对齐，完整 queue/steer 偏好仍未实现。
5. 模拟存储拒绝后设置还原并显示失败；读回失败显示确认失败；首次读取未完成选择不可写；快速重复不能发出冲突写。
6. Windows 不显示防休眠项。设置 select 的 Tab、焦点、原生下拉 Escape、中文输入法实测后记录结果。
7. 在同客户区尺寸、DPI/缩放、语言、主题的官方/当前宽窄窗采集截图和几何差异；不得以自动检查替代视觉验收。

默认编辑器/终端与其他通用项、旧恢复出厂未覆盖新偏好、富文本 Enter 语义为剩余缺口。未测试项不得标为通过。
