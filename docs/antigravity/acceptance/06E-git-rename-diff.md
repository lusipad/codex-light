# 06E 选择重命名文件时显示成对差异

沿用 [06C 基准](06C-split-alignment.md)。官方 `.vite/build/worker.js` 1176060–1177140 保留已暂存重命名的 `path` 与 `previousPath`，1225190–1226140 结合旧路径读取并保留重命名头。偏移从零开始，以 UTF-16 字符计数。

选择重命名目标时同时传递 Git 状态中的旧路径与目标路径。验收覆盖纯重命名、暂存后继续编辑、特殊字符的字面匹配及旁路文件隔离。沿用 Git 检测的重命名和现有补丁展示；低于 Git 相似度门槛时的合成、成对索引写入另验。
