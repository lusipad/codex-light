# 16.14A 本地环境文件与动作待验

[合同](../specs/16-14-local-environments.md)。本批为文件/手动动作增量，未完成整个环境编辑器及官方生命周期。

1. 工作区内.codex/environments下现有TOML可选择，缺文件默认environment.toml；读取不创建文件。既有default.toml与无效旧内容保留，不自动迁移。
2. version/name/[setup]/可选cleanup/[[actions]]结构验证，平台与图标校验；无效结构不能保存为有效环境或运行。
3. 保存带预期原文版本比较、同目录临时文件替换及读回；文件外部变化显示冲突且保留草稿。当前进程写串行，外部进程在最后检查与替换之间仍有竞态窗口，不声称跨进程事务锁。
4. 草稿未保存/结构无效不运行；动作运行前重新读取并核对文件快照、索引和平台。有效命令进入真实PTY队列，排队后切工作区取消未发命令；命令结果看终端输出。
5. 重复点击单飞，保存失败保留草稿；重新读取或切文件需确认放弃草稿，离页/工作区变化旧回调失效。全局离页草稿保护尚缺。
6. Rust真实临时目录测试与LE02–LE04、TC01–TC08回归通过，未执行真实项目动作。原生鼠标/输入法/完整重启与像素未验。
7. 官方结构化表单/祖先发现/选择持久化/主机支持、worktree自动setup/cleanup和环境变量注入未完成。原始TOML编辑不是最终官方界面替代品。

已知读取差异：官方加载器会过滤名称/命令不完整的动作并将无效图标回退为空；当前原始编辑路径对这些条目报结构错误。需在后续结构化编辑/加载归一化中对齐，本批不将该分支标为一致。
