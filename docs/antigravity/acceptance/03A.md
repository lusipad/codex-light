原生验收步骤：

1. 在隔离工作区发起真实命令，观察首次出现时折叠；Tab 到摘要，用 Enter/Space 展开收起，焦点保持。
2. 展开运行中的命令，持续输出时保持展开，不提前显示成功。
3. 分别执行退出码 0、非零、拒绝与中断场景；核对真实 item/status/exitCode 与界面结果，缺失退出码不显示成功。
4. 同一 turn 至少两条命令，独立展开；查找折叠命令的输出，应展开匹配卡，搜索框保留焦点。
5. 宽窄窗口回归命令全文、输出滚动、卡片边界和焦点；与固定官方同环境同场景截图对照。

保留差距：工具/消息顺序、专用解析摘要、后台执行信息及其他工具卡见实施记录。浏览器生产组件回放和自动检查不能代替这些真实原生与官方对照步骤。
