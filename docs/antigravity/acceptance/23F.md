## 当前实现

- 主界面先读取真实 bootstrap 和 accounts/check；完整身份、gate 和账号结构均确认后才启用分享入口。未知、缺失或失败不会视为允许。弹窗打开后再次确认权限。
- `shareThreadSession.ts` 组合完整历史、受权限约束的资产读取、脱敏快照、宿主准备、发布和复制。服务返回的 URL 才能进入复制流程。
- `ShareThreadDialog.tsx/.css` 实现 520 CSS px 弹窗、个人公开范围、工作空间成员和群组搜索、自动/手动受邀范围、准备/发布/成功/失败/未知状态以及 IME、焦点返回和发布时禁关。
- `shareAssetReader.ts` 在服务明确判 safe 且宿主组织网络策略允许后读取远程图片；不带凭据、拒绝重定向、有界流读取并释放 bitmap。宿主本地读取从真实 thread/codex home 取得目录，不把 renderer cwd 当授权。
- `share_assets.rs` 对文件、祖先路径、符号链接和 Windows reparse point、大小、HTML basename/会话日期目录实施检查。IPC 读文件前核对完整真实身份，读后核对 generation。
- 宿主固定分享/权限/资源命令已注册，上传最多并发4；预签名目标和发布 manifest 留在宿主。发布结果未知不自动重发，复制失败保留 URL 后仅重试复制。

## 明确差异和未测项

- 预览为**脱敏后的安全纯文本和图片卡片**，没有官方完整 Markdown/图片内容与排版；不能称视觉复刻完成。官方预览与发布快照的脱敏时点也未证明等价。
- bootstrap 仅支持已确认完整快照格式，未实现完整 Statsig SDK 的缓存、live overlay、增量和 override 优先级；使用本产品真实元数据，真实服务接受性未验证。
- 本地图片根权限和提前限额比已证官方 reader 更严格。HTML 尚无真实 workspacesRoot 来源，未支持该分支。路径检查与打开之间的 TOCTOU 未消除。
- 继续保留 23E 的有限 Markdown/旧 visualization/超大消息 fallback 差异，以及真实非空、多页历史未验限制。
- 真实 gate/账号搜索、目标申请/上传/发布及链接读回未测；未为验收向外发布会话。
- 无同环境官方和当前 Tauri 配对截图，视觉 `not_executed`、分数 `null`；原生 modal/focus/IME/窗口关闭未测，构建不能替代。
- OS 深链接接收尚待开发；本单元不据此放行整页或宣称整个 App 完成。
