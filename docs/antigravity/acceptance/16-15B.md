## 实现与复用

- 四项偏好使用原 atom key，真实 local host、CAS、持久化读回；保留兄弟键和未修改的非法原值。设置实现关闭确认、保留数草稿与 blur/Enter、保存失败重试、独立上游开关和手动删除确认消费者。
- 候选排序使用生产 TypeScript 的真实 `localeCompare`，与冻结官方纯函数比较。保留数按 eligible 计算；记录来源为真实 managed 布局、Git 登记/common/backlink/私有 owner JSON 和 birthtime，不以普通列表的容错字段授权删除。
- 真实账户和连接世代绑定持久 automatic 队列。启动/连接/身份变化、创建/分配/手动删除及附件生命周期触发入队；同账号/host 合并与 revision，30 秒仅恢复已有任务，最多两项 active，失败退避及终态写失败恢复均由宿主管理。
- 清理准备由原生采集保护输入，前端仅执行已比对的纯排序；宿主保存 claim 与身份并验证返回候选。删除在既有锁内执行快照→cleanup→最终保护及身份复核→Git remove→真实读回。自动快照失败必须保留，手动 settings-targeted 例外保持独立。
- 每个目标重新确认账号、连接、偏好、置顶、登记项目、活动会话、私有 owner、目录身份、新生与 attachment generation。附件修改有独立 lease，不能在本客户端删除临界区新入；未知 attachment owner 保持三态，按固定官方仅 true 阻断，不伪造 false。
- 成功创建在释放 source lease 前登记 newborn，宿主在真实 thread/start 返回后为对应新生 Git 根确认 owner，再释放保护；子目录聊天同样解析完整 Git 根。窗口关闭、账号变化与前端卸载的取消按真实窗口/独立 token 处理，StrictMode 晚响应不能取消新一轮。
- 创建读取实际上游偏好，精确 fetch/refspec 和隔离 Git config，独立 skip 仅停刷新；主取消阻止创建，fetch 非零以缓存继续，异常可见。普通本地分支仅当上游单向领先时使用上游 ref，不移动用户本地分支；HEAD 保持官方 HEAD 语义。
- 复用现有存储、Git 锁、setup/cleanup runner、Windows Job、主题与原生 dialog；无新依赖。未复制整包 Electron 运行时代码，也未用前端“归档所有聊天”替代自动清理。

## 已发现并修正的问题

- 复核发现仅使用 thread.updatedAt 会漏官方聊天文件 mtime，导致真实输入排序错误；补 max(updatedAt, mtime) 与固定文件时间回归。
- 普通本地 main 刷新后仍从旧本地提交创建；追踪官方 starting-ref 解析，补仅上游单向领先时使用远端 ref 的真实创建回归。
- 成功创建后的 source→newborn 保护衔接、cleanup 期间保护变化、终态持久失败与单目标失败阻塞后续候选均补专项；不将早期通过覆盖修正后的源码。
- 进度事件改为所属 WebviewWindow 定向发送；预先 skip 等待宿主确认再创建，不依靠 IPC 顺序猜测。
- 实际浏览器暴露全局 dialog CSS 覆盖局部宽高及默认黑字，保留失败图并修复后重验。详见 [UI 记录](../../../.ref/parity/16.15/actual/16-15B/ui-verification.md)。
- 固定时钟复核补充成功轮次仍有合并 revision 时的退避重置：成功清除旧失败次数，下一次失败从30秒开始；最终 queue 专项2/2退出0。

## 明确限制与偏离

- owner 读取失败保留、创建运行期暂保护同仓库其他工作树为本项目保护增强，不能写成官方严格等价。取消不回滚已运行脚本或已经成功删除的前序目标。
- 本客户端附件 lease 可互斥；外部 CLI/其他客户端不共享原生锁，最终协议核验到 Git 删除间仍无跨进程事务，不能宣称已消除所有外部竞态。
- 当前范围是本地 automatic 清理；thread/attached 队列中的 archived_worktree→detach→恢复/undo、远程 host 与云端分支未完整接线，外来队列记录保留，不假装全归档恢复完成。
- explicit remoteRef 创建没有当前 UI 入口；精确本地 ref 只验证适用路径。真实账号认证、真实网络故障、官方运行时、原生 GUI/IME、同环境官方配对像素及用户验收均未完成。
- 浏览器为私有 IPC 夹具，只有临时 Git/无害脚本测试执行了删除或进程控制；未启动新构建去清理用户真实工作树。独立 lint 未配置。
