## 来源与实现

再次核验固定 Store 26.1027.3384.0 完整 asar SHA-256 为 `6fbedf054a8d8cafaf5c745b40aa59176512e106e0bd6308275ae123b60fd074`。18 项原始资源、78 个 UTF-16 锚点及中文合同之外，新增工作面几何与完整资源解析函数取证，位于 `.ref/parity/19/actual/19E-images/reference/`。静态实现不证明真实账号 gate 或线上响应。

- `imagesData.ts` 保留首个样式组替换、稳定分类、历史 first-id 与空中间页；当前 pages 的 archived/blocked 拒绝优先，完整刷新可恢复。这项合并安全规则属于明确适配。
- `imagesClient.ts` 复用真实只读桥和身份快照，分别读取目录与历史，首批 25 不传 after，续批 20 带游标；条件权限/config 未确认时不发受限读取。`has_updates===true` 是本项目支持边界，不宣称官方必填。
- Rust 宿主只接受固定操作及身份派生路径。metadata 登记 opaque 资源授权，区分 role、request、身份与代次；renderer 不能提供任意下载 URL。补网络策略、取消、晚到拒绝、下载中撤销与跨域去认证。8MiB、每响应 1024 和全局 4096 授权上限是 Tauri 适配限制；全局满时淘汰旧授权，刷新可恢复。
- `ImagesView` 接入真实目录、分类、三种 presentation、独立加载/错误、历史 tab/section 分支及实测高度的 `ImagesHistoryMasonry`，复用 `LibraryPagination` 哨兵。草稿仅本地保存，发送禁用，不生成假结果。
- 缩略图预览支持方向键、Escape 与关闭后焦点返回。分页 metadata 出错即撤销旧图授权并保留文字；重试完整刷新首批，再继续分页。这是恢复适配，不冒称官方重试完全相同。

## 我的图像大图读取

- 复用现有宿主授权，只从历史响应的普通原图指针或原图 URL 读取。相册仍读取缩略图，打开才读取独立原图。同一个 URL 兼作两者时复用该授权。独立缩略图失败不会关闭已打开的原图。归档或阻断状态撤销同一图像的两类授权。
- 新增前端回归从缺少原图选择器失败，到覆盖原图来源选择、打开前零读取、缩略图失败隔离及关闭取消。Rust 专项覆盖普通指针、真实返回字节、外域无凭据及归档撤销。
- 1280×800 和 640×800 隔离浏览器实际解码不同的缩略图和原图，详情无横向溢出，Escape 回到原卡片。隔离 WebView2 另通过鼠标打开、实际解码和 Escape 关闭，系统可访问性焦点仍待核对。证据见 `.ref/parity/19/actual/19E-images/browser-original/` 和 `native-original/`。
- 普通原图指针返回准备中时，按官方间隔重查同一资源。传输夹具先复现缺少 URL 的错误，再覆盖重查成功、取消后零重查及最终外域不附凭据。
- 继续沿用 8 MiB 受控图像上限。共享会话指针、下载、编辑、真实账号和同环境官方像素仍待验收。

## 大图预览翻页

- 「下一张」在已读批次末尾续取一次历史。空批次保留当前图，新的可预览图像会在同一次打开的预览内选中。普通分页保留已读授权；新拒绝状态立即关掉受影响的预览。传输失败仍撤回旧图授权，再由历史页重试。
- 回归先在末尾按钮禁用处失败，修后覆盖单次发起、空页、真正末页、关闭后重开同一图以及被拒绝后解除底层禁用。隔离浏览器从第 8 张跨过空页到第 9 张，Escape 回到最初的第 1 张卡片。证据在 `.ref/parity/19/actual/19E-images/preview-pages/`。
- 在独立 WebView2 夹具用原生右方向键复核空页留在第 8 张、续页进入第 9 张，Escape 正常关闭。系统可访问性焦点只报告 WebView 容器，卡片回焦通过结果仍限浏览器。生产账号和配对像素仍待验收。
- 对确定发生在资源登记前的暂时性续页失败，保留当前原图和游标，并按官方文案在预览内提示再次点击「下一张图像」。结构、权限或授权状态不明的失败仍撤回旧授权。隔离浏览器验证 503 后第 8 张仍可见，重试同一空页后再到第 9 张。证据见 `.ref/parity/19/actual/19E-images/preview-retry/`。原生故障分支和真实 HTTP 仍待验收。

## 原图下载与保存

- 原图解码后启用「下载图像」，直接传入当前已验证的字节。复用原生保存对话框、取消和写后读回。文件名来自标题或本地化时间，按实际字节确定扩展名并清理不适用的 Windows 名称。
- 专项回归覆盖未解码禁用、重复点击、取消无成功、旧图错误隔离及原生焦点返回。既有生成图片保存继续使用同一宿主命令。
- 隔离 WebView2 实测中文默认名、取消零写入和 PNG 确认保存，读回 24,875 字节与原图完全一致，与缩略图不同。随后修复对话框返回时的意外刷新，并在最终夹具复验原生取消后预览仍打开。证据见 `.ref/parity/19/actual/19E-images/native-save/`。
- 真实账号、配对像素及 GIF 帧导出仍待验收。普通 AVIF 的格式识别已通过单测，原生对话框的实际保存样本为 PNG。
