原生验收在隔离目录执行：

1. 连续打开 A/B，检查最终选中文件；目录变化触发刷新时开始输入，草稿不应被晚到读取替换。
2. 编辑、保存、保存期间继续输入；保存完成后新内容仍有未保存标记。重复快捷键应只有一次在途写入。
3. 模拟写失败，确认草稿保留并可重试；保存后重新读取磁盘核对提交快照。
4. 脏预览切文件/关闭应明确提示先保存；干净关闭后旧请求不得恢复预览。
5. 与固定官方对照完整编辑和关闭流程、宽窄布局、键盘和像素。
