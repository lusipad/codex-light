在隔离项目操作：

1. Ctrl+P 搜索文件：结果只显示文件。再从 Ctrl+K 或侧栏打开，应回到综合搜索。
2. 搜索 `/goal` 并选择：进入现有目标动作，不向终端输入 `/goal`。
3. 选择 insert 类指令：写入 Composer 草稿；运行/测试等项目快捷命令继续进入终端。
4. 中文输入法选字期间 Enter、Escape、方向键和 Tab 不执行命令或退出；结束输入后普通按键生效。
5. 相同查询词切工作区，旧结果不得短暂成为新工作区可选结果。
6. 打开后马上关闭，不应在 40ms 后重新抢焦点。
