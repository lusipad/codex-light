# 16L 编辑器上下文窗口用量自验

按[开发前规格](../specs/16L-context-usage.md)，设置 → 常规 → 编辑器新增默认关闭的用量开关。偏好复用原有桌面存储和开关，读取确认后更新界面。编辑器用量基于当前聊天的 `last.totalTokens / modelContextWindow`，标题栏原有用量与速率诊断继续提供独立入口。

- 生产回放覆盖开关存储与失败、缺失及无效数值、零值、夹紧、50% 文案边界、切换聊天的快照隔离、Tab 可聚焦及 Escape。发布回放最初发现两处旧回调夹具还在提供旧 setter，更新夹具后保留原有断言。
- 初版隔离原生 EXE 验证开关默认关闭，打开后接收本地协议夹具的 20k/80k 最近用量与 260k 累计用量。编辑器显示 25%，Tab 展示说明，Escape 关闭。切到第二条聊天后，第一条的晚到用量不会出现在第二条。
- 最终隔离原生 EXE SHA-256 为 `b11174f52c1447c96c39fc1f11e0118aec64285ed15acbad90f171df9401c130`。重启恢复开关，39,600/80,000 的通知在 1442×914 和 949×866 窗口均显示 50% 已用。关闭开关后在磁盘读回 `false`。两个进程均已退出，协议日志无模型轮次。
- 类型检查、125 项发布前端回放及 `npm run tauri build -- --ci` 通过，生成 Windows EXE、MSI 和 NSIS。构建、截图、夹具与核验记录保存在 `.ref/parity/16.01/actual/16L-context-usage/`。

真实模型通知、原生听写与物理 IME、官方同环境像素、窄浮窗及用户验收仍待验证。本轮未重跑全量 Rust 单测或标准协议探针。
