## 实现范围

- 宿主固定服务地址、认证与身份世代，完整分页读取已安装库存。读写分别使用 CODEX / CONNECTOR_SETTING SKU；写入真实 raw ID、无正文 POST，写后完整读回。
- CLI 与账号服务独立加载和错误呈现；同 raw ID 去重并保留 CLI 执行来源，同名本地插件不消失。服务市场不参与本地市场移除。
- 启禁、卸载遵循实际策略；未知策略保留原值并限制变更。缺少旧目录 remote_plugin gate 不伪装成 HTTP 拒绝，也不强开目录资格。
- 未确认送达后只读核验；取消、账号切换、晚到结果隔离。原生宿主按 raw ID 对本客户端远程写互斥，覆盖前置读取、写入及读回。
- 服务变更确认与本地 skills/apps/MCP/插件刷新分别呈现；刷新失败持续警告，可重读而不重复 POST。
- 复用既有认证 transport、插件列表、公共按钮、运行时刷新及宿主锁，无新依赖。旧本地/市场回归保留，仅适配新增依赖。

## 保留限制

- 未访问或修改真实账号插件；远程服务实际资格、响应样本、组织策略仍未实测。
- 原生 GUI、多窗口交互、中文输入法、官方同场景宽/窄截图和物理像素差异未验证；没有官方配对基准，不给视觉通过分。
- 宿主锁只覆盖本客户端相同 raw ID 的远程操作；CLI 复合 ID、本客户端之外的 CLI 和服务端操作不共享事务锁。读回不是服务端原子事务。
- 未确认意图保存在当前 renderer 的模块 journal，能覆盖组件重开/账号往返，不能声称进程重启或其它窗口共享持久 journal。
- 服务元数据已保留，但服务专用完整详情、远程 host、安装和 OAuth 等不属于本阶段已交付范围。
- 状态为限定阶段自验、待用户验收；整 16.11 与整个 App 均未验收。
