# 07I 按组隐藏和恢复终端

沿用 [07H](07H-terminal-groups.md) 的官方 Store 26.1103.4239.0。`602117.ae4416017a.js` UTF-16 偏移 29038 明确隐藏底部面板保留标签，29486 与 29638 分别注册底部显隐和终端启动命令。`182735.bb2cb0d2af.js` 7669800 附近分别处理右侧和底部的显隐。取证清单位于 `.ref/parity/07/actual/07I-terminal-visibility/official-anchors.json`。

验收覆盖隐藏一个分组时其他分组继续显示、恢复同一个真实终端、隐藏组持续接收输出、工作区操作能显式恢复目标，以及关闭最后一个可见标签时仍能访问其余会话。

当前通过现有「终端操作」恢复隐藏组。全局显隐快捷键保持已有行为，官方命令分流和标题栏启动器另行对照。

## 本地自验

- Windows Tauri 隔离构建中，右侧与底部各运行一个真实 PowerShell。隐藏右侧后底部提示行仍可见，通过底部「终端操作 → 显示右侧终端」恢复原右侧标签和提示行。隐藏前与恢复后的两个进程号一致，见证据目录的 `shells-before.json` 与 `shells-restored.json`。
- 反向隐藏底部后，右侧继续显示。隐藏最后一个可见分组，再用 Ctrl+` 恢复右侧。关闭右侧最后一个标签会自动显示仍在运行的底部标签。隔离窗口已关闭。
- 专项回归验证隐藏状态仍接收输出、恢复复用 xterm 和 PTY、工作区命令先显示目标组、环境动作重跑保留位置。前端完整回归中的常规设置测试也覆盖新终端显示底部。
- 类型检查、发布元数据、117 项前端回归、Windows 通知适配器、Rust 全库 722 项及 EXE、MSI、NSIS 构建通过。产物 SHA-256 记录在证据目录的 `installer-hashes.json`。
