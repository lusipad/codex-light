原生待验步骤（等价官方场景重复执行并记录OS弹窗/声音，不能仅检查命令返回）：

1. 打开同会话主/独立窗口，设unfocused。聚焦任一可见窗口完成任务，应无系统提醒；切到其他应用后完成，应只有一次。
2. 切always，保持子窗口聚焦完成，应只有一次；切off则不提醒。none声音下提醒仍存在。
3. 发出真实审批/提问：聚焦相同可见聊天应抑制，聚焦不同聊天允许；解决请求后不得迟发。
4. 保留子窗口并关闭主窗口，在子窗口继续触发新通知；切换焦点重复前三项。核对当前已知收件箱限制，不能把系统通知通过当作收件箱通过。
5. 反复关闭其他子窗口的同时完成任务，确认剩余窗口不因已销毁句柄而丢提醒，错误日志无未解释项。
