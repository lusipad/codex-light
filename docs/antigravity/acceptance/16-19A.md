# 16.19A 已归档聊天设置：待验收

[规格](../specs/16-19-archived-chats-settings.md) / [证据](../../../.ref/parity/16.19/verification.md)。范围是本机归档真实生命周期统一，非整页1:1验收。

1. 设置→已归档聊天，应与独立归档页显示同一真实列表；完整分页后本地搜索，失败显示重试，重连刷新。
2. 取消归档后列表重读、侧栏更新；留在管理页，点查看才打开聊天。
3. 取消永久删除零写；拒绝/不支持时条目保留并提示错误，成功才移除。
4. 快速点击不重复提交；离开设置后旧响应不回填；两入口共用App处理器及refreshToken。
5. 无通用配置保存/刷新/成功横幅。官方云端/多主机/项目筛选/批量、原生确认框/键盘/焦点和像素另验。

真实删除仅在隔离CODEX_HOME临时会话测试，不动用户历史。当前构建与命令结果见验证记录。
