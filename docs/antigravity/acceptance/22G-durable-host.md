# 22G 原生云端会话宿主阶段记录

状态为开发中，本地自动检查已通过。[规格](../specs/22G-durable-host.md)承接固定版本的 22F 取证。本阶段提供原生固定 `model/list` 入口和持久连接，尚未启用页面编辑入口。

## 实现与证据边界

- WinHTTP 传输迁入产品，连接由独占线程持有。请求与通知按连接及身份隔离，初始化一次，请求 ID 关联乱序响应；取消、超时、断线结束相应等待。
- IPC 不接受任意地址、凭证或 RPC 方法。原生宿主读取凭证，在模型读取前后核对身份和应用网络策略；明确注销及凭证过期退役匹配连接。
- 审查发现旧请求误停新槽、认证失效保留旧槽、迟到通知越过退役边界及退出清理依赖循环引用四项问题。实现增加条件退役、当前连接准入和最终应用退出清理。前三项补专项回归，最终退出路径的热连接实测仍待完成。
- Windows 回环服务只监听私有本地端口，自启动并清理；测试证书仅用于拒绝不受信任 TLS。联合用例实际经过 Manager、WinHTTP、完整初始化能力、attestation 不可用回执、并发模型读取、逆序响应、通知及关闭。70KB 测试游标仅用于内部传输边界，IPC 仍限制为 2048 字节。
- 官方原函数回放重新核验 4 份文件、44 个锚点、12 组行为；产品初始化能力与回放输出一致。证据沿用 `.ref/parity/22/actual/22F-cloud-editor/reference/`，本阶段日志在 `.ref/parity/22/actual/22G-durable-host/verification/`。
