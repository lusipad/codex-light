## 实现与复用

- 真实共享策略、绑定账号成员/邮箱决定所有者权限；独立处理已有编辑者、查看者、外部邮箱与群组条件，不用目录角色或单一 gate 代替授权。已有编辑者降级/移除的菜单不统一要求新编辑者开关；写前仍遵守来源 `admins_only` 拒绝规则。
- 成员升降角色即时提交；移除先独立确认。桌面确认宽 512 CSS px，窄于 768 CSS px 为底部面板；成员菜单按内容宽度并靠触发器末端，不套用链接模式的 420px 菜单。
- typed 宿主固定 share_access 路径与操作类型，成员/群组必须显式提供可空 role，缺少 role 不得隐式删除；群组不能升编辑者。外部邮箱移除保留原文，专用操作不开放邀请。
- 复用现有身份作用域、取消与请求追踪、共享写锁、错误处理、metadata/截图授权更新和剪贴板。无新增依赖；工作区权限只在来源条件满足时按绑定账号读取。
- 保留原始 null/accepted/pending ACK；额外 GET 核实角色或目标消失才完成。pending、未知与读回不匹配均显式恢复，恢复只 GET，不自动重放 PATCH。额外 GET、原生 dialog 层级与本地菜单边界算法是已声明适配，不声称完全恢复官方运行时。
- 确认打开后捕获目标标签和角色，过期策略刷新后重新核对，防止按旧说明提交。保存中保留禁用 X/取消，阻止 Escape 与外点关闭；正常取消返回对应触发器。
- 查看者/群组移除说明沿用真实缺译 defaultMessage；编辑者说明使用已定位中文。未用旧的“将无法再访问”文案代替来源。
