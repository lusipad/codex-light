# 16.04A 通知分类与本地偏好增量待验

[官方合同与用例](../specs/16-04-notifications.md) · [实施与证据](../runs/20261101-codex-notifications.md)

使用本批构建，在隔离 `CODEX_HOME` 和测试工作区操作。不要用正在工作的真实项目触发命令审批。

1. 打开设置→通知，缺省显示“仅在未聚焦时”；启用权限通知、启用问题通知为开启。更改任一项，离开、返回、退出重启后确认独立值仍在。
2. 把轮次完成通知改为“从不”，在另一个聊天触发真实审批或问题：完成提醒关闭，权限与提问提醒分别由各自开关控制。
3. 依次设置“仅在未聚焦时”和“始终”，分别在应用聚焦、最小化、切到其他应用时完成真实轮次，比较系统弹窗与声音。窗口聚焦时，当前可见聊天的审批／问题应抑制，后台聊天仍可提醒。
4. 声音改为“无”，失焦时完成轮次：系统通知仍出现，应用音频不播放；再切回“默认／经典”，试听和真实通知使用相同声音设置，连续触发不重叠。
5. 同一完成事件重复到达不应重复提醒。审批／问题请求在发送前解决时不迟发；复用请求 ID 但 generation 不同不能串用状态。
6. 用隔离的不可写存储验证保存错误和回滚；写入成功但读取确认失败时保留新值并提示，恢复读取后“重新读取”恢复真实状态。
7. “发送测试通知”只验证提交路径；须实际观察 Windows 通知中心是否收到。系统关闭通知时、系统免打扰时的行为另记实测，不以按钮返回当作可见通知通过。
8. 采官方与当前同语言、主题、DPI、缩放、客户区尺寸的宽窄截图；比较控件、文字、菜单、焦点和错误布局。未完成配对截图前不评分。
