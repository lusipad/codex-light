## 实现和自验

- 在「常规」的集成终端 Shell 下方放置两个选项，沿用现有桌面偏好的保存后读回流程。官方这一行位于底部面板设置之后，且写入期间采用乐观显示。当前应用尚未接入该布局门控，选中态以读回结果为准。
- 打开终端和新环境操作读取最新桌面偏好。终端由实际请求创建，首开右侧不生成底部占位会话。读取失败或遇到旧配置的未知值时回落到底部。Ctrl+J 固定使用底部。
- 隔离 Windows 构建从设置页选「右侧」，私有状态文件读回 `right`。首次按终端快捷键只启动一个 PowerShell，再按 Ctrl+J 出现独立底部终端。退出重启后，预置环境操作在右侧输出 `placement-fixture-ok`。将标签移到底部后重跑，标签 ID 和位置保持。设置改回底部后，下一次普通终端打开在底部，已有右侧会话仍显示原标签及提示行。
- 专项覆盖落盘失败、无效值拒绝、确认读回、新旧动作取消、关闭最后一个标签及目标选择。117 项前端回归、722 项 Rust 全库测试、通知适配器与 EXE/MSI/NSIS 打包通过。构建哈希及首次启动的单进程证据在证据目录。
