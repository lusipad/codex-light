# 06F 重命名的取消暂存

沿用 [06C 基准](06C-split-alignment.md)。官方 `.vite/build/worker.js` 1394770–1396290 将 `previousPath` 纳入选中范围，核对变更版本后撤销该条暂存补丁。位置为从零开始的 UTF-16 偏移。

当前客户端对重命名目标单独执行取消暂存，旧路径的删除仍留在索引中。选择重命名条目时，以后端当前状态核对成对路径，在同一次索引更新中恢复旧路径和目标路径。

验收覆盖旧路径恢复、目标移出索引、工作区改名及后续编辑保留、无关暂存项隔离、过期重命名提示和索引锁失败。

状态核对和索引更新是两条 Git 命令。成对路径在同一条 `git reset` 中更新，由 Git 持有索引锁。核对与写入之间同一对路径被其他进程改写的情况留待验证。

## 回归

- 真实 Git 测试先复现取消暂存后仍留下旧路径删除。修正后，两端同时更新，工作区的改名和编辑保留，无关暂存项不受影响。错误路径对与索引锁用例确认失败时索引保持原状。
- TypeScript、717 项 Rust 测试、115 项前端回放、Git 生命周期及发布元数据检查通过。
- Windows EXE、MSI、NSIS 构建通过。原生点击重命名行的「取消暂存」后，Git 读回仅 `keep-staged.txt` 留在暂存区，旧路径的索引对象与 HEAD 一致。工作区的旧文件仍不存在，改名后的文件和编辑哈希保持一致。
