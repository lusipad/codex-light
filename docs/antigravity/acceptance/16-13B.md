## 改动与复用

- GitSettings 新增官方两项六行指令编辑器，3000ms 去抖、手动/Ctrl+S/卸载 flush，按 key 串行保存并实际读回；保存失败保稿，旧失败不覆盖新稿成功状态。使用宿主全局偏好，未虚构 config.toml 字段。
- git.rs 只读真实 index / tracked HEAD diff、PR head/base/merge-base 与文件列表，不混入 untracked，不 stage。客户端按官方纯函数黄金样本构造上下文，指令实际从保存状态读取；宿主先按 UTF-16 截上下文，再包完整官方提示。
- 新专用 git_message_generation 宿主通过真实 model/config、ephemeral thread、read-only、never、low 和 outputSchema 生成；限定模式/字段/长度，只接受合法 completed 结果。专用路由隔离用户时间线/审批，owner+operationId 取消，超时、重连、晚到与 finally 清理。
- DiffDrawer 删除按文件名固定生成及空消息 `update ...` 旁路。独立生成只填表；空消息提交和缺项 PR 等待真实生成，失败/取消/草稿变化均不继续 Git 写入。换项目/连接/关闭/卸载使旧生成失效，晚到不覆盖手工输入。
- 复用现有 Git 写入链、桥接、偏好存储、主题及组件，不新增依赖；不改官方安装、用户配置或真实账号数据。

## 未验证与适配边界

- 未运行真实模型、账号任务、Git 提交/推送/PR 创建；fixture 和线程参数探针不能证明生成质量、实际零工具调用或全部权限生效。请求工具被宿主拒绝不等于模型从未尝试调用。
- 两版本共同适配使用 sandbox/sandboxPolicy，没有同时发送 named permissions，也未发送旧版本不支持的 runtimeWorkspaceRoots；不可宣称与官方所有运行时权限字段完全一致。
- 模型选择复用实际配置与目录，尚未接入官方远程 evaluation 对 ephemeralGenerationModel 的覆盖，未将固定 Store seed 当作所有账号通用能力。
- PR Git 范围采用真实 merge-base→tracked working adapter，尚未证明等同官方底层 review-patch handler；Git 多次读取不是原子快照，外部修改仍可改变范围。未实现官方 diff-too-large 的全部底层错误分支。
- 最终 Tauri GUI、IME、窄窗、原生生命周期、官方同条件截图与逐像素比较尚未验证，缺参考图不填虚构视觉分数。设置整页其余分支前缀、合并方式、reviewDelivery/gate 仍属后续合同。
