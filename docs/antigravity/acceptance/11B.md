# 11B 工作树关联会话、真实删除与快照恢复

日期：2026-11-03。修改前依据：[删除合同](../specs/11-worktree-removal.md)。
证据目录：`.ref/parity/11/actual/11B/`，静态依据：`11B-research/manifest.json`。

## 本轮范围

- 获取全部未归档会话及真实持久置顶列表，置顶项单独读取；关联包含工作树子目录。
  加载或读取失败保持禁删。执行前重新读取置顶，不能只信页面快照。
- 在任何归档前校验完整、已登记、非 primary 的真实工作树身份；拒绝错误仓库、
  相对路径、子目录、符号链接和 Windows junction/reparse 路径。
- 顺序执行真实 `thread/archive`，回读归档列表确认，再调用删除；
  不经过既有吞掉归档错误的包装器，也不添加 CLI 不支持的 cleanupWorktree 参数。
  部分归档成功后失败会保留事实并提示，不能伪称回滚或删除成功。
- 使用临时 Git index 保存 tracked 修改/删除及非忽略 untracked，
  保存 HEAD 或带 HEAD 父提交的 synthetic commit，写独立 snapshot ref。
  从该 ref 使用 detached worktree 恢复，真实文件字节、未推送提交与索引均有回归。
- 前端共享同目标在途 Promise，页面同步锁阻止连击，切项目晚到结果不污染新上下文；
  后端同路径操作互斥。主工作树身份来自 Git 登记，不能按 activeWorkspaceRoot 判断。
- Git 删除成功后重读登记和目录状态才返回成功；提供真实恢复 IPC。
  本轮没有完整快照查找或恢复页面。

复用现有 bridge、会话协议、Git 命令执行与 Tauri spawn_blocking，无新增依赖。
快照不会保留 ignored 文件，也不保证恢复 staged/unstaged 的原始分区。

## 明确差异与未验项

- 候选 asar 含 offline 补丁，不是已确认干净发行基准；没有官方运行时配对证据。
- 按候选 `settings-delete-targeted` 例外，快照失败仍可继续 Git remove，
  返回 `snapshotRef:null` 和明确 warning，不声称可恢复。
  Git remove 失败不会采用任意递归删除兜底，与候选 force 分支存在差异。
- 后端重复请求返回在途错误；官方静态链复用 Promise。
  前端单窗口共享在途 Promise，跨进程互斥与外部 Git 并发不在本轮保证范围。
- 置顶使用本项目现有真实持久 pin 服务；尚未完整对齐官方 app-server pins gate。
- 尚未配置独立 lint。完整关联会话归档加 Tauri 删除的端到端、原生确认框/焦点/
  文件占用、官方中文及配对像素比较未验。没有视觉改动，不产生虚构视觉分数。
- 整页 11 和整个 App 均未完成，用户尚未验收。
