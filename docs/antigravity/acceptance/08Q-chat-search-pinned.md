# 08Q 独立聊天搜索的置顶与最近列表

沿用 [08K 基准](08K-chat-search.md) 的 Windows Store `26.1103.4239.0`。以下位置为从零开始的 UTF-16 偏移。

- `654172.b64b14661b.js` 139660–140165 的 `hv` 按已保存的置顶顺序取存在的聊天，其余按活动时间倒序，两个组共用结果上限。
- `515947.71d674afb6.js` 28800–29120、35560–37400 将空查询分为置顶和聊天组，空查询分支不渲染「显示更多」。中文语言包 `1561.0f4c0bdc0f.js` 871783 给出「已置顶聊天」。

验收覆盖置顶保存顺序、失效 ID、去重、时间排序、合计上限、空查询不走分页、输入后回到匹配结果，以及通过组间键盘跳转打开实际聊天。
