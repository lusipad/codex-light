# 16.13A Git偏好真实消费待验

[合同](../specs/16-13-git-settings.md)。本次三个偏好增量，不代表完整Git设置或用户验收。

1. 默认git-review-mode=full、always-force-push=false、draft=true。每个键独立本地保存并读回后才改变共享状态，失败保留前值并禁用消费者直至重新读取；重复操作单飞。
2. 禁用Git差异后Changes仅显示本轮，不发git_diff/git_log_commits/git_commit_diff；设置未读完也不得先发Diff请求。晚到旧Diff被忽略。本轮内容从真实turn/diff或fileChange记录取得，不用Git文件状态清单决定是否为空。此约束限Changes差异来源，App原有Git状态读取不在本批禁用范围。
3. 始终强制推送传forceWithLease=true到提交并推送、推送和顶栏推送；仍仅由用户推送动作触发。启用时无法在推送面板取消该参数；关闭后可在当前推送面板显式选择。
4. 新建PR默认draft=true，用户仍可在提交PR前更改；开关保存不会发起PR。自动检查只验证参数，未向外部仓库推送或创建PR。
5. 撤下无消费者的旧默认主分支/GPG/Conventional/忽略空白/自动暂存设置表单；旧数据保留。分支前缀、提交/PR指令、PR合并偏好尚未实现，保持缺口。
6. GT01–GT03和GL01–GL06、FE01–FE06、RA01–RA09通过。原生键鼠/重启手测和同条件像素未验。
