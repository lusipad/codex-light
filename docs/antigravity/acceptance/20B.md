# 20B GPTs 认证只读目录与详情

状态：限定切片自验中，未用户验收；不代表 GP02/GP03 全量或整页完成。修改前合同见 [20 GPTs](../specs/20-gpts.md) 与 [共享认证桥](../specs/chatgpt-service-bridge.md)。

GptsView 使用宿主脱敏身份和固定 gpts_discovery/category/detail 操作读取真实返回资源，替换 20A 永久未连接状态。仅成功且形状合法的目录响应可以进入空态；未登录、权限、频率、网络及协议失败有独立错误与重试。过滤 snorlax 项目资源；分类按真实 cursor 追加、按 ID 去重，单飞且失败保留已有列表，空页带 cursor 最多补一页。详情使用真实 ID，不回退示例内容；对话写链未接通，不以普通提示词冒充 Start chat。

页面监听宿主身份失效并取消旧读取、清空旧列表与详情。离页/取消后的晚到成功和错误均不能覆盖新状态。详情使用 dialog 关闭/Escape 与触发按钮焦点返回回调；生产回调夹具不是原生焦点实测。

验证：scripts/verify-gpts-service.mjs 执行生产 TSX，覆盖 loading/error/retry/empty、畸形响应、403/429 错误状态、真实卡片/snorlax、分页单飞/保留/去重/空游标补页/分类错配、详情真实 ID/404/重试、关闭和焦点回调、身份失效与离页晚到隔离。scripts/verify-chatgpt-service.mjs 执行生产 helper，覆盖浏览器实际 profile、稳定设备标识、脱敏身份/requestId 校验、取消前/进行中/晚到、中文错误分类；未读取真实凭据或执行外部 HTTP。

范围缺口：搜索/mine/workspace 全部 gate、about 权限、创建/发布/迁移、GPT 真实会话身份及持久化仍未完成；只读 HTTP 在真实账号下、原生交互和同条件像素均未验证。官方基准 asar 带已知 offline 补丁，不能称干净发行版。视觉状态 not_executed、score:null。
