## 实现

- 应用使用 Tauri 原生菜单，沿用现有菜单事件与已确认偏好保存流程。事件按发起窗口标签分发。没有选择时不发出保存请求。
- 首轮原生测试中，按钮区可打开原生「✓ 底部面板」，空白拖拽区的右键则打开 Windows 系统菜单。聊天标题栏改用 Tauri 左键拖拽处理，WebView2 继续接收右键。主窗口仅补充已有独立聊天窗口使用的拖拽权限。
- 聊天标题栏的双击最大化和还原交由同一条 Tauri 路径处理，避免旧回调重复切换。
