# 16.07A Codex自定义指令待验

日期：2026-11-01。[修改前合同](../specs/16-07-personalization.md) · [本轮记录](../runs/20261101-codex-personalization.md)。

在隔离CODEX_HOME与本批Tauri构建中执行：

1. 个性化显示“自定义指令”与“编辑 Codex 自定义指令”入口；原有自创语气/代码风格/角色不再出现。不操作旧TOML字段或迁移旧desktopPreferences。
2. 打开编辑器，读取本机Codex home/AGENTS.md的原始文本；不存在时创建空文件。初次加载失败显示错误和重试，未读取成功不能保存。
3. 修改后保存才可用，Ctrl+S和Ctrl+Enter保存；中文IME选字和keyCode229不保存。重复点击只写一次，成功以实际磁盘读回为准。
4. 取消直接放弃；返回时有修改则先提示，继续编辑保留原稿，放弃后回概览并恢复入口焦点。切换设置分区后返回，编辑草稿仍保留；应用级路由离开与关闭窗口需另验未保存保护。
5. 将全局AGENTS.override.md设为非空，页面提示覆盖；空白override不提示。保存只写AGENTS.md，不改override或项目文件。
6. 原文换行/空白保留；清空后文件变空，不复活旧偏好中的指令。新会话实际加载文件；已有会话的更新语义不在本轮推断。
7. 外部改同一文件后保存，提示冲突且保留编辑草稿，不覆盖外部内容；读取/写入失败不得显示成功。可先复制草稿，再取消并重新打开读取最新文件。
8. Tab/原生dialog焦点/Escape/返回焦点、退出重启、原生窗口关闭、宽窄窗口在Tauri实测；官方和本批按同DPI/主题/语言/客户区尺寸配对采图。

PI01/PI02 Rust隔离磁盘测试、PI03–PI05生产JSX回调和PI06真实新会话消费链探针通过仅覆盖限定功能。没有官方原生/视觉与用户验收，不记整页1:1通过。ChatGPT指令/记忆、远端主机、多账号和产品gate仍未实现/未验证。
