在隔离数据目录验证：

1. 延迟历史读取，同时接收完成/审批/自动化事件；读取结束后新事件仍在，同 ID 只一条。
2. 读取期间标记已读、删除或清空，迟到历史不得撤回操作；全部已读后新到事件保持未读。
3. 空历史正常加载；非法历史项不破坏列表，最多恢复 100 条。
4. 读取失败应显示重试，未知历史期间不回写空列表；重试成功后新事件和历史合并。
5. 连续操作已读/删除并重启，核对落盘快照；模拟磁盘失败，显示保存错误，后续成功写可恢复。
6. 单独对照官方实际 Activity 入口、数据源和状态，不能拿 Pages 提及通知证明本地列表一致。
