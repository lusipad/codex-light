# 16.16A 代码审查本地偏好待验

[合同](../specs/16-16-code-review-settings.md)。整页仍在开发中，本轮不表示云端Review agent或私有PR工作台已完整实现。

1. 设置 → 代码审查：真实读取审查链接目的地和个人指令；原有自动审查/阻断严重级别/glob假策略控件已撤，desktopPreferences历史字段保留。
2. 链接目的地选择代码审查标签页或默认浏览器，保存后读回；旧github/in-app-browser等值保留，需显式选择可支持目的地。
3. 指令修改3秒后自动保存，保存按钮/Ctrl+S立即保存；IME组合期间快捷键不提交；离开设置时flush，失败草稿保留在App级共享状态，返回可重试。文字输入在写入期间禁用是当前与官方交互差异，尚需修正。
4. 写入合并electron-persisted-atom-state的独立键，不覆盖其他atom/偏好。磁盘失败、未知字段、错误类型拒绝，清空指令写真实空值。
5. PR列表“打开链接”按偏好进入已有详情或调用系统HTTPS打开。该详情不是完整官方PR标签页；普通本地review不消费个人指令，PR入口请求会附带当前已读回的个人指令。读偏好失败或离页取消不启动审查，不回退main分支。
6. 现有PR分支审查仍欠官方固定PR head/merge-base快照与private findings schema，不能把本次指令消费当整个PR审查已一致。云端个人/仓库策略、GitLab/provider gate和MCP嵌入UI未完成。
7. 原生鼠标/键盘/IME/完整重启与像素未测；测试和打包见[证据](../../../.ref/parity/16.16/verification.md)。
