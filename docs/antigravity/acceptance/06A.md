请在隔离 Git 仓库验收：

1. 快速切文件、diff 模式及仓库，最后选择应保持正确；旧请求的失败不能覆盖新 diff。
2. 连续触发提交、提交并推送、推送，确认同一时刻只执行一条写链。
3. 提交期间修改说明，原提交成功后新输入保留；失败说明可直接重试。
4. stage 期间切仓库，旧链不继续提交；已发出的操作不会被撤销。
5. 提交成功而推送失败后，独立推送不产生第二个提交。
6. 中文输入法组合输入不提交，普通 Ctrl/Cmd+Enter 有效。

真实往返、官方对照、当前构建原生操作和像素均未执行；stage/unstage/discard/PR 的其他异步入口也未由本批覆盖。
