复用当前会话待审批列表、差异视图与审批面板的响应链。额外根目录只参与文件预览路径解析。回放覆盖不同轮次、不同项、不同请求类型、匹配根目录、请求移除和终态优先。未确认自动审核拒绝、可视化专用分支和原生键盘动作对照。

- 在隔离 Windows 程序经 app-server 桥发出带匹配项的审批请求。对应卡片显示文件名和统计，展开有独立短滚动预览。点击“拒绝”后桥仅收到一次 `{"decision":"decline"}`，审批面板消失，后续事件显示“已拒绝”。测试文件哈希不变，关闭窗口后进程退出。
