# 16.05A 模型目录与入口纠偏待验

日期：2026-11-01。MC01–MC06 自动回归不等于本表实测通过，整个模型／智能体设置未验收。

[范围与来源](../specs/16-05-model-catalog.md) · [本轮实现](../runs/20261101-codex-model-catalog.md)

在隔离 `CODEX_HOME`、测试工作区和对应原生构建中操作：

1. 设置侧栏不再出现“提供商与模型目录”；旧入口到达“智能体与模型参数”，不出现生成示例模型和自定义 Provider 表单。原有提供商配置文件不应被该导航操作改变。
2. Composer 打开模型菜单，按运行时目录显示模型名，名称中的连字符等保持原样。隐藏模型和审核专用模型不作为普通选择。
3. 服务返回多页时，最终目录包含后续页结果；真实服务当前样本不足以覆盖所有账号，应使用受控 fixture／隔离服务补充测试。空结果不沿用先前目录。
4. 服务断开后刷新模型，错误可见，已有目录不假装刷新成功；恢复服务并“重新读取”后错误清除。快速连续刷新，晚到旧响应不应覆盖新目录。
5. 对 ID 与 model 不同的受控目录，选中后菜单保持正确状态，thread/start／turn/start 参数使用 model，推理强度和速度只来自该模型能力。真实模型执行需在已授权的测试账号范围核验；本轮探针没有执行模型轮次。
6. 更改真实配置后，设置保存回调依次刷新配置与模型目录；若原选中模型消失，退回可用默认；空目录清除旧能力。完整设置作用域和托管覆盖由 16.06 继续验收。
7. 验证 Tab／方向键／Escape／焦点返回、中文 IME，采官方与当前同环境宽窄截图并逐控件比较；没有成对截图不生成评分。
