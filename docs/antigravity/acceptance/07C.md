## 已实现的用户结果

1. 两个事件监听都注册成功后才创建或附着终端；失败显示错误，不启动不可观察的会话。
2. 快照和实时输出共享 generation 与解码后 UTF-8 字节水位。早到、重复、乱序事件按连续范围合并；不按文本内容去重。
3. 中文、emoji 与 ANSI 跨读取块流式解码，EOF 决议不完整尾部；回放最多 128KiB，按字符边界裁剪。它不是无限输出恢复。
4. 会话注册和初始快照早于 reader 启动。同 ID 并发创建只产生一个进程，旧 generation 不能清理新实例。
5. 子进程结束后关闭 ConPTY、排空输出再发退出事件。保留有界快照至关闭标签，但进程资源已释放、写入失败。
6. xterm 初始化回放用真实解析回调完成就绪；期间禁止输入回写。清理视图会释放等待者，晚到解析不会重新启用已销毁视图。保留 07B 命令只发一次和隐藏保留标签的行为。

本项目 generation/字节水位是 Tauri 数据正确性机制，不能表述为已还原官方传输协议。当前候选 asar 含 offline 补丁，详见合同。

## 原生待验步骤与限制

在隔离项目中运行对应本轮构建：

1. 打开终端，立即输出中英文与 emoji 并退出，确认首尾、控制字符与退出提示顺序。
2. 连续输出编号时切标签、隐藏/重开并调整大小；检查输出归属与屏幕恢复。真实 resize 的 VT 重绘允许重复原始字符，但最终屏幕不应重复渲染旧行。
3. 从工具栏运行命令，启动期间隐藏/重开，确认命令只投递一次；关闭最后标签后新建，确认旧会话已关闭。
4. 与固定官方发行版本在相同 DPI、主题、语言、客户区尺寸下逐步对照，并采集原生焦点、复制粘贴、IME、快捷键和视觉证据。

未证明首个 shell prompt 就绪、全部 Shell 编码、跨应用重启恢复、全部输入来源分类、完整键盘/焦点、官方生命周期或像素一致。初始化回放阶段本项目禁用全部 stdin，官方静态代码区分用户输入与 terminal-generated 输入，该细节仍需运行时对照。没有同条件截图，因此 visual 为 `not_executed`、score 为 null；没有用户验收。
