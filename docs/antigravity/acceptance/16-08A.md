# 16.08A 账号快照待验

日期：2026-11-01。本批不实现登录/退出，不代表完整官方账号页面。[规格](../specs/16-08-account.md) · [本轮记录](../runs/20261101-codex-account-snapshot.md)。

1. 未登录时只读account/read，额度与用量不可用，不伪造统计；读取失败显示错误。
2. 开始刷新清除旧身份、额度、用量；请求顺序为身份→并行额度/用量→身份核对，再一次接纳同一快照。
3. 前后身份不一致时整次读取失败；额度accountId与当前已知ID不符时额度被丢弃并报错，成功用量可保留。单项读取失败不清除同批其他成功结果。
4. 控制晚响应：先发请求A再发B，B成功后A不能覆盖；离开账号页/卸载后不得接受晚响应。
5. account/updated通知立即清旧值并重新读取，迟到的订阅在离页后释放；后续旧通知不再刷新。
6. 账号页没有公共“保存更改”，不应通过只读页面保存其他分区草稿。
7. 在原生登录账号/切换账号实测身份、额度与时间单位，断网与恢复、Token刷新、退出、窗口重启；进行官方与本批配对截图。

AC01–AC04生产helper/SettingsView回调与AC05真实隔离未登录协议只覆盖有限合同。缺乏稳定身份的账号/ABA切换、后端未带accountId的usage身份不可完全证明；已登录真实额度、登录/退出、官方分区/完整图表、原生和像素仍待验。
