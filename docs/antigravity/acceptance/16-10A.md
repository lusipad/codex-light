# 16.10A MCP运行状态待验

[合同](../specs/16-10-connections.md)。本批仅替换错误的在线测试，不代表完整连接配置/OAuth页通过。

1. 配置列表称“已配置”，不因enabled就说已连接；点击“读取状态”调用mcpServerStatus/list，定向serverName并处理全部分页。
2. 仅runtimeStatus=connected才显示已连接；starting/disabled/failed/cancelled/需要认证等准确区分。缺runtimeStatus显示目录已读取但连接未知。toolsError不能显示连接成功。
3. 服务失败/无返回/重复游标明确错误；同服务器重复点击一次请求，离页或换工作区晚响应被丢弃，重新进入可重试。
4. 不执行任意command --help、不发no-cors HEAD来代替MCP握手。
5. 真实隔离stdio fixture握手/发现工具已自动验证；原生进程/认证/外部远程服务、完整CRUD/config作用域、OAuth与官方同条件截图仍未完成。
