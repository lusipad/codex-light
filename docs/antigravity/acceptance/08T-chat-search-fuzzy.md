# 08T 聊天搜索缩写自验

按[开发前规格](../specs/08T-chat-search-fuzzy.md)，独立聊天搜索使用词边界及连续片段判断缩写，并用同一匹配结果高亮分支。复用既有字段优先级、协议正文、分页和按聊天 ID 选择。

- 在隔离 JavaScript 上下文运行固定官方 asar 中的匹配导出，记录 438 组匹配和片段数据。当前实现的命中与否及 UTF-16 片段全部相同。覆盖路径分隔符、驼峰、中文、Emoji、数字、通配符及反例。发布回放保留其中 17 个固定样本和代表性相对排序检查。
- Windows 隔离 EXE 在 1442×914 和 949×866 窗口输入 `ru`，在 `feature/repair-ui` 分别高亮 `r`、`u`。正文结果到达后保留协议片段，标题结果仍排在前面。输入 `rpr` 显示无匹配。回到 `ru` 后用方向键与 Enter 打开分支结果，日志中的读取和恢复均使用目标 ID。无模型轮次。
- TypeScript、125 项发布前端回放、官方 CLI 隔离搜索探针和 Windows EXE、MSI、NSIS 打包通过。EXE SHA-256 为 `7f9f0d9a00c10a1e4403f5d742d160a738c1bbb263606de1db4c7ba7366335ca`。取证、回放日志和截图位于 `.ref/parity/08/actual/08T-chat-search-fuzzy/`。

本地评分优先考虑前缀、词边界和片段紧凑程度。官方数值评分和全量相对次序仍未证明等价。多宿主、真实账号与同环境像素待验。本轮未重跑完整 Rust 单测。
