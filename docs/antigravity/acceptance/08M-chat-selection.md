# 08M 聊天搜索分页选中位置

沿用 [08K 基准](08K-chat-search.md)。固定 Windows Store `26.1103.4239.0`，偏移为从零开始的 UTF-16 字符计数。

官方 `515947.71d674afb6.js` 28344 将当前查询和结果数传入选中位置处理器，61440–62990 的 `Nkeb` 在点击更多前记录已有项。结果增加后，选中第一条新出现的可用项，并居中滚动。

复用搜索结果 ID 和既有键盘选择。分页时同一个会话从本地候选变为协议命中仍保留身份。先显示额外预取项、后收到远端页时保持原选中项。页面失败可在原位置重试，查询范围变化后丢弃旧选择。上下方向键和组间跳转将目标行滚到视野内。

生产回放覆盖重复结果、异步追加、清理旧选择、保留重试项和方向键循环。
