# 23E 分享实现计划与实施记录

依据：[分享合同](../specs/23-share-thread.md)。本轮接续 23D，不修改已记录的验收结论。

## 需要优先核对的决定

- 保留官方完整历史读取合同：metadata → `thread/turns/list`，每页 5、asc、full，直到无 cursor。不得上传当前 UI 的部分历史。信心高；协议实测如返回不同形状，先记录再适配。
- 保留官方白名单快照语义，采用本项目 TypeScript 独立实现，不复制官方打包代码。信心中；导入清洗函数与资产安全规则仍需追证。
- 上传与发布必须是宿主固定操作，预签名目标由宿主持有；身份、取消、未知发布结果必须显式处理。信心高；不开放任意 URL 上传。
- 上传、发布、安全策略或账号能力尚未实现/验证时，分享入口保持不可用，不将局部实现写成完整分享。

## 假设与偏离策略

现有连接只支持当前本地 host；不猜测远程 host 的路径权限。官方候选包带 offline 补丁，仅用于静态合同。新增边界检测可以拒绝不完整输入，但不能返回截断历史并继续分享。保守处理和未覆盖项记录在下方，不制造成功结果，不新增依赖。

## 执行顺序与验证

1. 补查快照导入函数、远程图片与 PUT 策略；记录定位和缺口。
2. 实现完整历史读取，验证多页顺序、参数、取消、重复 cursor、失败及不完整数据。
3. 实现白名单快照转换，验证字段排除、路径/diff、图片替换、duration 和输入清洗；不能还原的语义明确列出。
4. 确认上传边界后再接宿主事务与 UI；服务端分享 URL 是唯一成功依据。
5. 运行专项、类型检查、标准检查，记录实际结果。原生与同条件像素测试缺少证据时保留未验证。

## 实施记录

### 决定

- 独立历史读取与快照转换先用真实生产函数的合成数据回归验证，不执行付费模型 turn 或公开发布。
- 官方原函数补证：本地 `historyMode !== "paginated"`（包括缺失）使用第二次 includeTurns:true；已据此实现，cwd 可为 null。保留取消与历史模式变化拒绝。
- 不开放 IPC 和分享菜单，先验证转换/脱敏/宿主事务。真实 gate、受众身份、来源读取和 UI 生命周期必须齐备后再接线。

### 偏离

- Markdown 未引入新依赖；当前实现有限语法，对复杂/旧 visualization 拒绝，保留无关文本排版。不能声称等同完整官方 AST。
- PUT 拒绝重定向和额外结构风险；发布单发，408/409/5xx/无效成功响应或网络结果未知禁止重发。这些是保守实现边界，官方允许401刷新重放，不将本实现称为完全等价。
- 资产收集并发4，宿主资产上传当前串行；上传并发4留待下一接线轮。

### 发现

- inject_items 是模型上下文，真实0.159.2/0.165.0分页不呈现为用户历史；手工回放事件亦未得到可见分页。失败探针证据保留，真实非空/多页读回未验证。最终探针限定验证上下文不制造历史、notLoaded不被resume、零模型turn。
- 脱敏器与固定官方独立纯函数在100个合成基础样本及变体对照通过，只覆盖启发式字符串规则，不处理资产字节。
- 独立审查发现已发布缓存未绑定受众，可把旧public URL当作invited结果；现绑定access与排序principal集合，变更拒绝，复制重试只复用同受众URL。
- 独立审查发现snapshot维度及显式图片引用未交叉检查上传资产；现认证前拒绝悬空引用，sentinel和字面文字保留。没有以字符串扫描替代Markdown解析。
