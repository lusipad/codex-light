# 23F 分享接线计划

依据：[23E](../acceptance/23E.md)、[分享合同](../specs/23-share-thread.md)、[上传边界](../specs/23-share-upload-boundaries.md)。目标是接通真实准备、上传、发布与复制，不把内部函数测试计作用户可用。

## 优先决定

- 先核实 gate、accounts/check 与工作区受众合同，不用个人 plan 猜分享权限。信心高；实际 gate 不能读取时保持未验证，不伪造允许值。
- 宿主只暴露固定分享命令，预签名 URL/headers/manifest 留在宿主。信心高。
- 资产来源遵循官方 URL 安全服务与本地 thread/path 权限。未知来源不能开放为任意文件/网络代理。信心高；静态取证若证明不同允许范围，先记录再适配。
- UI 使用真实 preparing/prepared/creating/ready/error/unknown 状态。关闭取消未完成请求；复制失败只重试复制，已发布关闭不撤销；不能悄悄重复发布。信心高。

## 执行与验证

1. 补 gate/受众/官方UI与本地资产合同，明确缺证。
2. 固定 url_safe 与并发4资产上传；生产 transport 回归。
3. IPC及前端取消、晚到prepare清理、身份失效、manifest不可替换回归。
4. 资产读取和分享弹窗接线，验证真实回调状态、键盘焦点和退出生命周期。
5. 聚焦回归、标准检查、全量Rust和当前源码构建；真实服务/原生/像素缺证保持未验。

## 实施记录

### 决定

- 延续已授权开发，不执行公开发布、付费模型turn或读取真实凭据来生成验收结果。

### 偏离

本轮预览采用脱敏快照的纯文本/图片卡片，没有假装完整官方 Markdown 和图片预览；细节记入 23F 差异。完整 Statsig SDK 与真实 workspacesRoot 尚无实现依据，保持保守未支持。
