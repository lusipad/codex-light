## 5. 关键工作面的动作合同

下面是开发必须覆盖的任务骨架，不是凭空指定官方布局。最终控件、文案、菜单和动画由G1同版取证填写；官方不适用的动作写依据，不能擅自新增。

| 单元 | 必须走通的操作序列 | 状态/失败/呈现重点 |
|---|---|---|
| R2 插件 | 打开目录→搜索/筛选/分页→详情→安装→连接/授权状态→可用→启禁→管理/卸载→重开 | 本地/账号/项目身份、管理员/默认安装边界；取消零错误写入；未知安装结果先读回不重复写；授权回调不冒充成功；每个主要弹层、返回及焦点 |
| R2 技能 | 推荐/已安装→预览→安装/打开定义→编辑/保存→在草稿试用→取消/删除 | 来源与路径/作用域、旧详情隔离、脏稿保护、文件真实落盘、试用不自动发模型 |
| R3 电脑操控 | 进入设置→读取主机/应用/权限→按官方方式启用或连接→选择可操作对象→隔离无副作用动作→观察结果→停用/取消 | 未支持/未安装/无权限/服务断开必须分开；动作由真实工具执行；焦点/坐标/多屏及敏感边界；离页/关闭释放资源 |
| R3 Appshots | 官方入口/快捷键→目标窗口→像素/适用文本→预览或附加到草稿→取消/清除→重启读回偏好 | 遮挡/最小化/目标关闭/捕获失败；屏外文本与像素分开；快捷键生效和注销；不把主屏截图冒充窗口语义 |
| R3 浏览器 | 读取连接/实例→打开或选择目标→按官方管理历史/下载/扩展/站点状态→执行可逆操作→重连 | 先确认Windows实际支持的管理项；browser生命周期/会话归属/权限；不以CDP字段保存代替宿主连接 |
| R4 Sites | 列表/搜索→创建草稿→编辑→预览→保存/恢复→获授权后发布→读回真实URL/版本→重开；再跑设置/共享 | 站点/Work会话/账号身份；自动保存时序、失败与未知发布回执；无权/管理员限制；数据库/日程按官方能力；删除/转让须单独边界 |

R1的每条能力矩阵至少写：`capabilityId、官方产品/平台分支、gate、request/response/event、执行器位置、权限、配置作用域、真实消费者、探针结果、阻塞与恢复条件`。没有来源的接口不允许进入产品实现。

## 8. 每单元的取证与交付格式

沿用现有整页资料，不新建重复台账。规格`docs/antigravity/specs/<编号>-whole-*.md`；结果`docs/antigravity/acceptance/<编号>-whole-*.md`；证据`.ref/parity/<编号>/whole-page/`，含reference/actual/diff和manifest；实施决定/偏离/意外随做随写`docs/IMPLEMENTATION-LOG.md`和单元记录。历史小阶段只做证据索引。

G1前必须填写以下内容，禁止先开发再补官方预期：

- **区域树**：窗口/标题栏/导航/内容/滚动容器/工具栏/菜单/弹窗/提示；位置、层级、可见条件和空/加载/错误/正常状态。
- **双向控件表**：`controlId、官方role/name/state、显示条件、位置/尺寸/token/图标/字体、hover/focus/selected/disabled、tooltip、来源锚点、本项目对应、差异`；既查缺少，也查多出。
- **动作表**：`actionId、前置条件、输入/鼠标/键盘/IME、状态前后、请求/通知/持久化、可见结果/动画时序、焦点、取消/失败/重试、testId、证据`。时序不知道就待采证，不编毫秒数。
- **状态机**：适用的加载/空/正常/保存/运行/取消/错误/未知结果/无权限/断开；标转换与幂等约束。
- **基准**：版本/build、包hash、平台/产品模式/账号gate、语言/主题/客户区/DPI/缩放、数据集、时钟/动画时点。资源许可不明确时不直接搬资产。
